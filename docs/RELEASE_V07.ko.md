# 스텔알피지 V0.7 · 모험과 성장

기본·2차 직업의 성장과 전투 원화를 통합하고, 던전에서 발견한 것들이 다음 탐사·연구·제작으로 이어지도록 확장한 Windows 64비트 테스트 빌드입니다.

## 주요 변경

- 기본 능력치를 **위력·활력·견고·신속·정밀·특화**로 개편했습니다. 기존 20직업의 공격·회복·자원 특색에 특화를 연결하고 치명타 중복 판정을 정리했습니다. 이전 5스탯 투자점은 한 번 반환하며 레벨·스킬·재산·층 진행은 보존합니다.
- 기본 외형의 기술 모션 236자세, 플레이어 코스튬 30종의 승인된 대기·피격 87자세, 기존 몬스터 48외형의 192자세를 연결했습니다. 실제 시전·공격·회복에 맞춰 자세가 바뀌며 발 위치, 시선, 원화 경계색을 보정했습니다.
- 스킬 이펙트 18종·108프레임과 탐사 물체 24상태를 적용했습니다. 이펙트는 실제 공격 방향과 시간에 맞추며 몬스터의 위험 예고를 가리지 않도록 표시합니다. 원화 처리 캐시 110장을 사용합니다.
- 스킬 지도를 통합 3계열로 정리하고 선택한 스킬의 공격 방식과 강화 수치를 함께 표시합니다. 생성·능력치·도감·인벤토리의 새 스탯 명칭과 계산을 맞췄습니다.
- 던전 시야와 벽 뒤 가림, 발견한 분기의 전진 지름길, 땅 위 흔적으로 읽는 선택 단서를 연결했습니다. 자연동굴의 반복 구조물을 줄이고 유해 장식을 드물게 배치합니다.
- 소음 경계·유인, 적 조사와 도감 연결, 화면 밖 위험 표시, 유인 돌·올가미 덫·화염병을 추가했습니다. 역할별 적 무리, 중단 가능한 회복, 갑피·겹 보호막·정면 방어에 서로 다른 공략을 적용했습니다.
- 개인 단서·탐사 사건·선택 정예 도전·지역 위험도·공유 출발 조건을 추가했습니다. 연구로 제작법을 열고 필요한 재료의 탐사 목표를 찾을 수 있습니다. 길드 평판 등급, 금화/평판 보상 선택과 정산 표시를 연결했습니다.
- 협동에서 쓰러짐·강제 이탈 시 남아 있던 개인 효과를 정리합니다. 마지막 생존자가 이탈한 경우 첫 참여자 제거 화면부터 보스를 초기화하고, 살아 있는 동료가 남으면 전투를 유지합니다.

## 다운로드

- `StelRPG-V0.7-Windows.zip`: 압축을 모두 푼 뒤 `StelRPG.exe`를 실행합니다. `StelRPG.pck`를 같은 폴더에 둡니다.
- `StelRPG-V0.7-Database.zip`: 관리용 SQLite·JSON·스키마·조회 예시·새 스탯 및 원화 등록 설명입니다. 게임 실행에는 설치할 필요가 없습니다.
- `SHA256SUMS.txt`: 두 ZIP의 무결성 확인용 해시입니다.

기존 게임을 종료하고 **이전 saves 폴더를 백업한 뒤** 새 빌드로 복사하세요. 저장 외피 v7은 유지하고 능력치 이관 버전 2를 사용합니다. 새 저장을 이전 클라이언트로 되돌려 읽히지 말고 필요하면 이관 전 백업을 사용하세요.

친구와 협동할 때는 **모두 V0.7로 교체**해야 합니다. 협동 프로토콜은 16이며 이전 클라이언트의 참가는 거절합니다. 방장 포함 최대 6인 직접 주소 접속, 기본 UDP 24554를 사용합니다. 자동 매칭·자동 중계·방장 이전·원정 재접속은 아직 제공하지 않습니다.

## 후속 범위

이번 배포로 전체 벤치마킹이 완료되는 것은 아닙니다. 신규 몬스터 40종·원화 20종의 전투/드롭 연결, 제작·보관 확장은 V0.7.1에서, 탐사 보급·정보 UI·원정 재접속 및 보스 상태 연출은 V0.7.2에서 순차 진행합니다. 설계 또는 미승인 원화를 이미 적용했다고 집계하지 않습니다. **3차 전직·전용 궁극기는 보류**합니다.

검증의 실제 실행 범위와 미확인 항목은 [V0.7 배포 검증](VERIFICATION_V07.ko.md)에 기록합니다. 외부 회선 장시간 협동과 장기 경제·직업 조합 체감은 로컬 자동 검사와 구분합니다.
