# V0.5.2 전투 범위와 조준

몸통을 클릭해도 공격이 빗나가는 주원인은 조준 좌표였다. 몬스터는 발을 기준으로 위쪽에 그리지만, 마우스는 바닥 좌표로 역변환했다. 높이 335px인 보스의 몸통을 누르면 발보다 수 칸 뒤를 향하게 된다. 실제 렌더링 사각형과 회전·배율·좌우 반전을 등록하고, 그 안을 가리키면 해당 몬스터의 발 좌표를 조준한다. 겹쳐 보이는 경우 앞에 그려진 살아 있는 몬스터를 선택한다. 빈 바닥은 기존 자유 조준을 유지한다.

피격 반경은 일반 1.0–1.35칸, 정예 1.4–1.65칸, 보스 2.15칸이다. 몬스터의 이동 충돌이나 공격 사거리를 늘리지 않는다. 발사 방향의 반대편에 있는 적과 벽 뒤의 적은 계속 공격에 맞지 않는다. 넓어진 몸체가 옆 통로까지 걸치는 상황에서도 투사체의 폭발, 상태 이상, 관통 횟수 차감이 벽을 통과하지 않게 했다.

| 공격 종류 | 변경 |
|---|---|
| 검사 회전, 궁수 화살비, 마법사 서리 및 일반 장판·폭발 | 기본 반경 40% 증가 |
| 번개 | 기본 반경 50% 증가 |
| 점멸 착지 공격 | 기본 반경 35% 증가 |
| 2차 직업 장판·폭발 | 기본 반경 40% 증가, 최소 3.5칸 |
| 원소술사 장판·폭발 | 위 기준에서 추가 10%, 최소 3.85칸 |
| 덫·원거리 연사 범위 | 최소 2.8칸 |
| 회전·브레이커 주변 강타 | 최소 3.2칸, 실제 전방위 판정 |
| 단검·권격·집중 강타·집중 처형·근접 연격 | 기존 공격 반경 유지 |
| 일반 공격 및 투사체 | 기존 무기 사거리 유지 |

반경 조정은 `skill_reach.gd`에서 기본 프로필에 적용한다. 이후 랭크, 장비, 특성 보너스를 적용하므로 성장창의 수치, DB의 랭크 프로필, 실제 공격이 같은 값을 사용한다. 타격당 피해, 기력 소모, 재사용 시간, 차지 시간과 한 번의 시전이 사용하는 무력화 총량은 바꾸지 않는다. 광역기는 한 번에 맞히는 적이 늘고, 집중 공격과 원거리 사격은 기존 역할을 유지한다.

바닥의 얇은 범위선은 이펙트가 가진 실제 반경을 등각 투영한다. 기존 효과의 47px 환산과 185px 제한 때문에 생기던 축소 표시를 없앴다. 월드 원의 수평 반경은 `48 × sqrt(2) × 반경`, 수직 반경은 그 절반이다. 장식 효과의 입자 수와 큰 불꽃 크기는 제한하면서 접촉 범위선은 실제 넓이를 표시한다.

검증 진입점: `python tools/run_hidden_check.py combat_reach_v052`. 기존 몸통 조준 실패의 재현, 피격 경계의 안팎, 회전·반전된 렌더링 좌표, 앞뒤 조준, 벽·옆 통로의 투사체, 실제 광역 추가 표적, 타격 횟수, 보스 무력화 총량, 20개 직업 프로필 및 범위선 투영을 확인한다. 최종 통과 여부는 통합 검증 보고서에 기록한다.

클라이언트는 `_input`으로 전달받은 논리 뷰포트 좌표를 보관하고 매 입력 틱마다 현재 카메라 역변환을 적용한다. 마우스를 움직이지 않은 채 화면이 줌되거나 이동해도 조준 좌표가 화면과 일치한다. `combat_reach_visual_v052 graphical`은 실제 `main`의 입력 전달, 몸통 렌더링 범위, 전면 표적 선택, 근접·투사체의 유효/무효 사거리와 세 광역기를 확인한다. 2026-09-10 집중 검증은 109개 항목, 실패 0건, 1920×1080 캡처 7장을 기록했다.

햇살 마을 수련장은 `(29,24)`에서 크기 `15×16`칸이며, 거대 허수아비는 `(37,30)`에 고정한다. 이 영역에서 기존 공격·스킬·직업 자원과 보스 무력화를 연습한다. 허수아비는 당기기·밀치기로 이동하지 않고 즉시 체력을 복구하며, AI 공격과 처치 보상은 발생하지 않는다. 표시 피해는 치명타·방어·무력화 보정을 거친 실제 피해다. 마지막 기술은 시전 예산의 기술 ID로 식별한다. 수련 기록은 저장하지 않으며, 초기화는 기록·기술 대기시간·진행 중인 자기 공격을 지우고 기력을 채운다. 장비·배운 기술·경험치·금화는 보존한다. `training_ground_v052`의 2026-09-10 집중 검증은 42개 항목, 실패 0건이다.

실행 파일 검증은 `tools/test_export_v01.py`의 기존 절차에 여섯 화면을 추가한다. 설정과 그 안의 키 변경, 120칸 가방의 교체 능력치 비교, 실제 훈련 후 월드/기록, 별실 부티크를 독립 저장 폴더에서 연다. `export_capture_v052.gd`는 이 검증용 화면 이동과 런타임 증거만 제공한다. 허수아비의 실제 텍스처·300px 그리기 범위, 필요한 리소스의 PCK 포함, 미출시 V0.6 두 에셋 폴더의 제외와 영속 데이터 보존을 실행 파일 안에서 확인한다. 실행 파일 검증 결과는 해당 버전의 `artifacts/export-check-*.json`에 기록한다.

추가 경계 검증에서 죽은 적을 휘둘러도 룬이 증가하는 문제를 확인했다. `hit()`는 실제 피해가 받아들여졌을 때만 참을 반환하고, 기본 공격의 직업 자원은 이 결과로 지급한다. 처치한 마지막 타격과 불멸 허수아비의 정상 타격은 성공으로 유지한다. 상태 이상·표식·아군 지원·관통 횟수도 유효 타격에만 적용한다. 거절된 표적은 투사체를 막거나 폭발시키지 않는다. 폭발은 주 표적에 실제로 맞은 뒤 그 표적을 제외한 주변에 한 번 적용하여 주 표적 중복 피해를 방지한다. `qa_combat_v052`에서 사망·벽·보스 초기화 전 공격, 마지막 타격, 근접·직접 투사체·폭발·관통, 상태 지원, 수련 자원과 장비/능력치를 포함한 고정 피해 기대값을 확인한다.

장판의 반복 타격과 지연 시전도 같은 유효 적중 조건을 따른다. 리셋 전 공격을 거절한 보스에게 감속·기절·출혈·표식·당기기가 남거나, 몰아침·연무·즉결 준비 및 아군 지원이 발생하지 않게 한다. 반격과 소환수 명령의 상태 이상도 실제 타격이 필요하다. 연쇄는 거절된 표적을 다음 연결의 출발점으로 삼지 않는다. 이미 지불한 시전 비용과 대기시간, 시전자 이동, 실제 방어 성공에 대한 자원은 유지한다. `qa_skill_rejection_v052`에서 실제 장판 생성과 지연 시전, 정상·처치·리셋 거절 경로를 함께 확인한다.
