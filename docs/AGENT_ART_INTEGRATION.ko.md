# 에이전트 작업물 런타임 통합

3차 전직과 미구현 궁극기는 반영하지 않는다. 원본은 보존하며 미리보기·ZIP·사용하지 않는 후보 이미지는 실행 배포물에 넣지 않는다. 이 문서는 반영 범위이며, 검사 결과와 미완료 범위는 `docs/qa/agent-integration-20260913.json`에서 별도로 기록한다.

## 원본과 실제 사용

- 직업 모션: `game/assets/skill_motions_v06/catalog.json`의 기본·2차 직업 19장/76동작/304포즈 중 현재 스킬의 행동 유형에 대응하는 59동작/236포즈를 실제 연결한다. 도적과 시프는 외형을 공유한다. 실제 시전 준비·방출·복귀 시간을 사용하고 취소·피격·회피 시 중단한다. 코스튬과 수동 외형은 보존한다.
- 몬스터: `game/assets/monster_motions_v06/catalog.json`, 기존 전투 정의와 대응하는 48외형/192포즈. 이동 방향과 실제 공격 준비·타격·복귀 상태를 사용하며, 지원 회복을 공격 포즈로 표시하지 않는다. 개체 수·배치·보상은 바꾸지 않는다. 신규 20종 원화 및 40종 전투 설계는 이 수에 더하지 않는다.
- 스킬 효과: `game/assets/attacks/catalog.json`, 확정 18효과/108프레임/37개 스킬 바인딩. 자체 제작 ImageGen 원본이며 예비 6효과와 지원 모드로 바뀐 `runesword_a02`에는 연결하지 않는다. 적 위험 예고 아래 레이어, 시야 마스크, 최대 224px 제한을 사용한다. 이동형 효과는 실제 타격 방향과 일치한다.
- 코스튬: `game/assets/costume_v06/runtime.json`, 검수된 플레이어 코스튬 30종의 대기·피격 87포즈. 원본 30장을 사용하며 걸음·공격·회피 등은 검수된 기존 V04 동작으로 유지한다. NPC 전용 3종을 플레이어 코스튬에 추가하지 않는다. 구매권과 직업 제한을 보존한다.
- 탐사 오브젝트: `game/assets/exploration_objects_v06/catalog.json`, 채집물·보급품·상자 12종의 사용 전후 24상태. 기존 위치에 개인 수령 상태별로 표시하며 개체 수나 구조물을 늘리지 않는다.

각 원본 SHA256은 해당 카탈로그와 DB의 `art_files`에, 실제 사용 대상과 프레임은 `art_assets`·`art_uses`에 기록한다. 제작 정본·검수 후보·실제 사용을 구별한다. 직업 모션의 몸높이와 사신의 신발 기준 발 보정값은 `calibration.json`을 실행 리더와 DB에서 함께 사용한다.

## 능력치 및 검토 수정

DB 담당의 확정 6스탯 구조와 기존 저장 변환을 런타임·생성 화면·성장 화면·전투 계산에 연결한다. 세부 정책은 `docs/CHARACTER_STATS_V2.ko.md`를 따른다. 치명타는 공통 계산 뒤 한 번만 판정하며 자동 플레이도 새 능력치에 투자한다. 예정 특수 옵션이나 3차 직업을 활성 기능처럼 표시하지 않는다.

## 투명 배경과 성능

원본을 바꾸지 않고 빌드 단계에서 패딩된 RGBA gzip 110장을 만든다. 런타임은 네이티브 디코딩 후 시트와 프레임을 캐시하며 매 프레임 픽셀을 순회하지 않는다. 보라색 원화는 좁은 마젠타 범위로 알파만 보정하고, 녹색 오염은 투명 배경에 닿은 1px 외곽만 제거한다. 기존 셰이더의 재처리를 막는 오른쪽·아래 투명 1px 패딩을 유지한다.

## 별도 남은 범위

신규 일반 몬스터 전투·드롭 정의, 제작 재료/조합 DB의 실제 경제 연결, 장비 전용 특수 스탯, 크기 등급 정책, 보스 패턴 추가 효과, 구조 후유증은 설계 또는 별도 연결 작업이다. 원화 납품이나 설계 DB 인수만으로 실행 완료로 집계하지 않는다. 강화 미확정 조건과 3차 전직 런타임 반영은 보류한다. 초기 인수 당시 그래픽 디자인의 신규 산출물은 없었다. 이후 `docs/design/raid_presentation_v02/README.ko.md`의 첫 조우 A+C/재조우 A 정책과 거대 생물 반전 구상이 전달됐다. 생물·지역·보스 ID 선택과 전투 전장 설계가 남아 있어 콘셉트 두 종을 승인된 전투 원화로 적용하지 않는다.
