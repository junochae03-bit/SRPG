# 직업 스킬과 장비 작명

사용자 요청: 직업 특색이 드러나는 스킬트리와 장비 이름을 작성한다. 메이플스토리·로스트아크는 직업별 어휘와 기술 동작의 작명 참고로만 사용하며 이름을 그대로 복제하지 않는다.

범위: 원기술610·별자리900의 표시명, 직업별 무기200·계열별 방어구/장신구300 기본 조합의 표시명. 등급2500조합은 동일 기본 장비의 등급 변형이다. ID·전투 효과·수치·드랍·착용 조건은 변경하지 않는다.

1. [완료] 명칭 카탈로그와 변경 전후 목록 작성. 스킬1510·장비500개의 고유 이름, 한국어 표시와 길이 검사 통과.
2. [완료] 원기술·별자리·장비 생성/기존 장비 정규화에 연결. 명칭 전용 검사9542개에서 원기술 수치·조건과 기존 장비 ID·강화·옵션 보존 확인.
3. [완료] 장비872·스킬트리6622·DB5305개 회귀 통과. tools/build_database.py 생성 및 --check 통과. 기존 제목 화면·V06 파일은 보존. 커밋·게시·클라이언트 재빌드는 수행하지 않았다.

검증 명령은 GODOT_EXE 지정 후 `python tools/run_hidden_check.py content_names`, `equipment_v02`, `skill_build_v04`, `database_v04` 및 `python tools/build_database.py`, `python tools/build_database.py --check`다. 명칭 검사는 전체 verify_v01.py에도 등록했다.
