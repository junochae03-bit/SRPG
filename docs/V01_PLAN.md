# V0.1 성장·소지품·마을 시설 개선

사용자 요청은 읽기 어려운 스킬 트리와 약한 랭크 성장, 가방·장비 UI, 마을 거래·상호작용 화면의 전면 개선이다. 색만 칠한 박스 UI를 금지하며 완성본은 V0.1로 지정 GitHub에 커밋·병합·푸시하고 실행 파일을 첨부한다.

| 단계 | 구현 | 확인 |
|---|---|---|
| 스킬 성장 | 실제 시전과 표시의 공통 계산, 피해·범위·타격·회복·버프의 랭크 강화 | skills_v01의 실제 시전 1,026개 검사 |
| 성장 UI | 이름·랭크 카드, 연결 경로, 검색·필터·스크롤, 현재→다음 비교, 투자/배치 | ui_v01, visual_v01 |
| 가방 UI | 그림 프레임·가죽 슬롯·캐릭터 받침대, 7부위/60칸, 착용 비교 | inventory_ui, ui_v01, 실제 렌더 |
| 마을 시설 | NPC 5명·작업대 6종 원화, 상품·조합식·전후 결과·거래 확인·반응 | ui_v01의 비용/자원/실제 결과 및 세 원정 이동 검사 |
| 출시 파일 정리 | 사용 파일 참조 추적, 출처/해시/GDD, Windows 내보내기와 휴대형 저장 | verify_v01, test_single_run, test_export_v01, Git 스테이지 검증 |

최종 실행 결과는 [검증 기록](../VERIFICATION.md)과 [검증 데이터](VERIFICATION_V01.json)에 둔다. 장비·저장 스키마와 노드 ID는 유지한다. 기존 저장은 복사본만 검사하고 개인 저장, 엔진, 추출 원본, 미사용 시안과 임시 파일은 Git에서 제외한다. 실행 패키지는 GitHub V0.1 릴리스 첨부로 제공한다.
