# 발견으로 열리는 전진 지름길

2026-09-13. 탐사의 보상을 전리품뿐 아니라 이후의 이동 경로에도 연결한다. 일반 던전의 전체 면적이나 모든 곁방을 도는 요구를 늘리지 않는다. 유용한 통로가 맞는 지도에서 두 번째 도구 비밀방을 작은 지름길로 교체한다. 기존 무료 비밀방과 주 경로·적 배치는 보존한다.

## 플레이 흐름

근처에서 바람이 통하는 봉인을 발견한다. 발견 전에는 지도와 상호작용 목록에 나오지 않는다. 가까이 가면 앞 구역으로 연결되는 이점과 보유한 탐사 도구 수를 표시한다. 도구 1개로 개방하면 실제 통행 가능한 지형이 생기고, 내부의 개인 보물을 회수한 뒤 반대편으로 진행할 수 있다. 보물 회수 후에도 길은 그 층에서 계속 유지된다.

통로를 열었다고 목적지 전체를 밝히지 않는다. 기존 시야와 탐사 기억을 사용하며, 개방에 따른 지도 변경 번호가 지형·시야 캐시를 갱신한다. 양쪽 입구에는 작은 잔해와 가까이 있을 때만 보이는 `열린 지름길` 표시를 둔다. 기존 그림을 재사용하고 새로운 장식 스프라이트는 추가하지 않는다.

## 생성 기준

- 일반층마다 최대 1개이며, 쓸모 있는 통로가 없으면 원래 비밀방을 유지한다. 레이드 전장은 제외한다.
- 내부 작은 공간 반경은 2칸, 통로 폭은 3칸이다. 개방 시 추가되는 셀은 최대 150개로 제한한다.
- 실제 통행 셀의 8방향 최단 경로를 비교한다. 모서리를 가로지르는 이동은 제외한다. 양쪽 입구 사이의 거리가 10칸 이상이면서 25% 이상 줄어야 한다.
- 해당 지점에서 수문장까지 가는 경로도 6칸 이상 줄어야 한다. 단순히 먼 곁방으로 새 연결만 만드는 후보는 제외한다.
- 시작 위치 주변 8칸과 수문장 주변 10칸을 침범하지 않는다. 기존 첫 비밀방과 겹치지 않고, 수문장 처치에 따른 다음 층 개방 조건을 유지한다.
- 생성 검사에서 후보 지형은 별도 탐색 그래프에만 잠시 적용하고 되돌린다. 실제 던전의 셀은 플레이어가 개방하기 전까지 바꾸지 않는다.

지도 경로 계산에는 [Godot 4.6 AStarGrid2D](https://docs.godotengine.org/en/4.6/classes/class_astargrid2d.html)를 사용한다. 위 수치는 격자 최단 경로 기준이며 연속 이동의 모든 가능한 궤적이나 탐사 재미를 수학적으로 보장한다는 뜻은 아니다. 생성 작업은 층을 만들 때 수행하며 매 프레임 반복하지 않는다.

## 협동·DB

기존 호스트 권위의 비밀방 동작을 사용한다. 서로 다른 플레이어의 동시 개방과 같은 요청 재전송에도 총 도구 1개만 소비한다. 발견과 열린 지형은 파티 공유, 보물은 개인별 1회다. 동일 시드의 지도에 개방 상태를 적용하면 모든 참가자가 같은 지형을 얻고, 서로 다른 순서로 두 비밀방을 열어도 결과가 같다.

멀리 떨어진 참가자도 개방 변경 번호와 시야 상태를 갱신한다. 생성 방식이 달라진 클라이언트가 섞이지 않도록 협동 프로토콜을 8로 변경했다. 저장 형식은 7을 유지한다. 원정 도중의 늦은 합류·재접속은 아직 구현되지 않았으며 현재는 마을에서만 참가할 수 있다. 새 미러의 열린 지형 복원 검사를 실제 재접속 완료로 세지 않는다.

DB에는 `metadata.exploration_shortcuts`와 `metadata.exploration_shortcut_source_rules`를 기록한다. 관련 구현은 `exploration_shortcuts.gd`, `hidden_rooms.gd`, `exploration_panel.gd`, `main.gd`다. QA팀은 네 실제 캡처와 코드를 검토했고, DB 관리는 생성된 정본을 읽기 검수한다.

## 검증 범위

모델은 개방 전후 거리·면적 상한·기존 지형 보존·보호 구역·실제 이동·시야·소유·중복 요청·개방 순서를 검사한다. 일반층 전체 90개×3시드의 270개 지도 중 103개에 유효한 지름길이 생성됐고, 8,777개 검사를 통과했다. 추가 셀은 표본 최대 88개, 양 입구 간 단축 거리는 최소 11.07칸이었다. 해당 기기에서 층 생성 시간 중앙값은 22.09ms, 95백분위는 26.93ms였다. 이는 모든 시드의 생성 시간이나 탐사 재미를 보장하는 값이 아니다. 실행 결과는 `docs/qa/exploration-shortcuts-verification.json`에 보관한다.

시각 검사는 `shortcut-sealed.png`, `shortcut-opened.png`, `shortcut-treasure.png`, `shortcut-forward-exit.png`의 실제 1920×1080 화면으로 비용·행동·텍스트 잘림·지형 갱신·탐사 기억을 확인한다. 화면 확인을 위해 해당 테스트에서는 전투를 정지시킨다.

실제 6인 ENet 검사에는 네 참가자의 중복 개방 요청, 멀리 남은 참가자의 수신, 전체 1개 도구 소비, 이후 여섯 명의 이동 입력으로 새 통로 통과가 포함된다. 외부 회선 장시간 전투와 반복 탐사 재미 평가는 별도 미확인 사항이다. 구역의 목적과 사건 반복을 줄이는 후속 작업, 나머지 선택 벤치마크는 계속 남아 있다.
