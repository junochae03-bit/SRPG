# 직업 확장 인게임 적용

2026-09-09 · Godot 4.6 · 기존 저장 스키마 5 유지

## 사용 방법

마을에서 **K → 직업 선택**. 기본 직업은 전사·마법사·궁수·도적·격투가다. 30레벨에 같은 계열의 2차 직업을 선택한다. 60레벨부터 기존 스킬의 강화 노드를 배우며, 직업이 다시 분기하지 않는다. 최대 레벨은 100이다.

| 기본 직업 | 30레벨 전직 |
|---|---|
| 전사 | 탱커 / 검사 / 마검사 |
| 마법사 | 소환술사 / 원소술사 / 치유사 |
| 궁수 | 저격수 / 헌터 / 탐험가 |
| 도적 | 시프 / 사신 / 도박사 |
| 격투가 | 인파이터 / 브레이커 / 무도가 |

각 2차 직업에 액티브 12개, 패시브 6개, 기존 액티브를 강화하는 3차 노드 12개를 등록했다. 새 직업의 액티브·패시브는 최대 5랭크, 3차 강화는 1랭크다. 3차는 대응 액티브 3랭크와 해금 레벨을 요구한다. 기존 기본 3직업의 150노드와 3랭크 성장은 유지한다. 새 기본 도적·격투가는 입문용 액티브 각 1개로 시작한다.

배운 액티브 가운데 **Q / F / V / C / Z / X 여섯 개**를 장착한다. Q도 장착 슬롯이며 별도의 무료 일곱 번째 기술이 아니다. 같은 스킬을 다른 슬롯에 배치하면 이전 슬롯에서 빠진다. 재사용 시간은 스킬 ID에 귀속된다. 장착 변경과 초기화는 마을에서만 가능하며 직업 변경 시 SP를 돌려받는다.

좌클릭은 평타, 우클릭 누르기/떼기는 차지 강공격, Space는 기본 대시다. 외형이 코스튬으로 고정되어 있다면 I에서 기본 외형과 자동 아바타를 선택해야 직업별 새 스프라이트가 보인다.

## 전투 연결

- 탱커: 아군 합류, 보호막, 정면 가드, 방벽, 도발. 도발 지속 중 AI의 대상 선택을 유지한다.
- 검사: 자신에게 공격력·공속·치명타 확률·치명타 피해 버프. 보스·엘리트 보정과 연속 적중 보상.
- 마검사: 실제 평타 적중으로 룬 획득. 룬 사용 기술은 시전 시작 때 룬을 소비한다.
- 소환술사: 소환 편성, 소환수 공격·공속·방어 버프, 회복·귀환·명령. 적의 범위 공격에 소환수가 피해를 받는다.
- 원소술사·저격수: 준비 시간, 시전 중 이동 제한, 피격 중단과 투사체/광역 공격.
- 치유사: 아군 회복·재생·버프·보호막·감속 정화.
- 헌터: 사냥개 동행, 덫·출혈, 주인 소유 전리품 자동 회수. 전리품 패시브는 드롭 발생 확률만 보조한다.
- 탐험가: 근거리 채찍 광역, 속박·기절, 로프 이동. 기본 공격에 활 투사체를 사용하지 않는다.
- 시프: 투척 평타로 표식, 표식 대상 순간이동, 6종 약화와 대응 아군 버프.
- 사신: 사슬 견인/접근 성공 후 차지 없는 강공격권. 보스는 견인 대신 접근한다.
- 도박사: 중복 없는 52장 덱, 실제 카드 교체·버림·셔플, A의 1/11 처리, 17~21 정산 배당, 홀드·컷 카드·주사위. TAB으로 카드 또는 컷 후보를 선택하고, 컷 후보는 평타 입력으로 확정한다.
- 인파이터: 짧은 거리 2충전 대시, 빠른 평타·연타와 몰아침.
- 브레이커: 긴 쿨·긴 거리 대시, 정면 패링·반격권, 기세를 소비하는 묵직한 차지 강타.
- 무도가: 짧은 단일 대시, 돌진·다단 발차기, 서로 다른 기술 적중으로 연무를 쌓아 마무리에 소비.

### 브레이커 피격 기세

피격 기세는 **각 피격 순간부터 2초 동안 선형 감소**한다. 새 피격은 이전 기세의 수명을 갱신하지 않는다. 공격/패링의 일반 기세와 별도로 기록하고 합계 상한 100을 공유한다. 차지 시작 때 피격 기세를 먼저 소비하고 일반 기세를 사용한다. 소비량을 스냅샷으로 고정하므로 차지 중 감소나 취소로 이중 사용·환급되지 않는다. 소비량에 비례하는 짧은 보호막이 붙는다. 마을에서는 기세를 비운다.

## 이번 구현과 원안의 차이

이 버전은 현 지상 전투 시스템에 맞춘 통합판이다. 원안의 공중 추격, 경직 게이지, 세밀한 입력 예약, 일부 조건부 3차 연계를 그대로 재현한 완성판은 아니다. 해당 3차 강화는 현재 피해·범위·거리·지속·방어 보정으로 작동한다. 게임에는 실제 적용되는 설명을 표시하고 원안은 `design_upgrade_text` / `design_description` 및 `docs/design/`에 보존했다. 숫자는 플레이 테스트용 초기값이다.

100레벨에서는 직업별 마스터 보조 효과가 자동 발동한다. 기존 9직업은 역할별 5초 버프, 도적·격투가 계열은 정산·강타·몰아침·마무리 등에 연결한 보조 효과를 사용한다. 원안의 모든 조건부 마스터 연계를 재현한 것은 아니다.

장비 아이템 유형은 기존 검/활/지팡이 등의 능력치 체계를 재사용한다. 전직의 기본 공격 판정과 외형은 직업 정의를 따른다. 새 무기별 독립 드롭·제작 계통은 이 변경에 포함하지 않는다. 스킬 아이콘도 기존 아이콘을 재사용한다.

## 자료와 검증

- `game/data/jobs/catalog.json`: 전직, 해금, 랭크, 스킬 및 강화 데이터.
- `game/scripts/job_combat.gd`: 자원·시전·연계·소환·상태 이상.
- `game/assets/jobs/`: 원본 스프라이트·이펙트와 셀/발 위치 메타데이터. 원본 이미지 픽셀은 변경하지 않고 런타임 AtlasTexture와 크로마 셰이더로 읽는다. 화면상 기준 몸높이 112를 기존 캐릭터와 공유한다.
- `game/tests/jobs.gd`: 180종 액티브 실행, 성장/장착 게이트, 기세·패링·덱 보존·사슬·디버프 버프, 직업별 저장 복원 검사.
- `game/tests/visual_jobs.gd`: 실제 OpenGL 화면에서 스킬 창과 새 직업 외형 캡처. 헤드리스 더미 렌더러용 검사가 아니다.

```sh
godot --headless --path game --editor --import
godot --headless --path game --script res://tests/jobs.gd
godot --path game
```

Windows 기존 V0.1 배포 파일은 이 소스 변경으로 갱신되지 않는다. 최신 소스로 재빌드해야 한다. 실제 화면 검증은 Linux 소프트웨어 OpenGL로 수행했으며 Windows 실행 파일 검증은 수행하지 않았다.
