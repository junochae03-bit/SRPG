# 소음 유인과 적 조사

2026-09-13. 탐사 중 내 행동에 반응하는 적과 발견한 대상의 전투 정보를 연결한다. 전체 벤치마킹 목표의 일부이며 함정·투척물·재접속 완료를 뜻하지 않는다.

- 소음은 통행 가능한 타일을 따라 전파한다. 공격 8칸, 강공격 12칸, 스킬 10칸, 달리기 6칸이며 울리는 공동에서는 +3칸이다. 소리를 최근 9초 안에 들은 생존 적은 파티 전체 합계 4마리까지만 예약한다. 이미 전투에 합류한 청취 적도 집계하며, 사망·시간 만료 때 예약을 반환한다. 시야로 직접 접근한 적의 수까지 제한하는 규칙은 아니다.
- 소음 발생자는 1.1초 동안 짧은 경계 안내와 실제 통로 전파 외곽선을 본다. 외곽선은 현재 시야 안에서만 표시한다. 본인 pulse만 전송하고 반응한 적의 수·ID는 보내지 않는다. 같은 pulse와 지형에서는 경계 계산을 재사용한다.
- 살아 있는 적의 실제 스프라이트 위에 마우스를 올리면 이름·레벨·등급·현재 체력·공격 형태·상태를 표시한다. 공격 형태는 런타임 패턴에서 가져오고 기존 튜토리얼 보스의 원형 공격 및 레이드 돌진을 포함한다. 훈련 허수아비는 제외한다.
- 처치마다 별도 식별자로 맵 내부 시체 기록을 보존한다. 같은 적의 중복 처치는 중복 기록을 남기지 않으며 재생성 후 처치는 새 식별자를 받는다. 맵별 최대 64개 기록을 유지하고 새 맵에서는 초기화한다. 전용 시체 그림 대신 가까운 8칸 안의 최대 3개에 작은 조사 표식을 표시한다.
- 호스트가 생존·비이탈 파티원의 현재 시야 반경과 벽·모서리 차폐를 검사해 보이는 시체만 snapshot에 포함한다. 시야 컨텍스트를 캐시하고 복제한 데이터를 반환한다. 기존 살아 있는 적 전체 전송 구조는 이번 시체 필터와 별개다.
- 조사 창은 시야 상실·지도 변경·사망·메뉴 진입 시 닫힌다. 창으로 마우스를 옮길 수 있도록 1.4초 여유를 두고 창 위에서는 유지한다. 상태 아이콘에는 이름 툴팁, 8개 초과 시 +N과 나머지 이름을 제공한다.
- 도감/드랍 버튼은 실제 몬스터 ID와 층, 레이드는 고유한 `raid:층` ID로 기존 도감에 연결한다. 조사는 전리품 판정·지급·저장 상태를 바꾸지 않는다.
