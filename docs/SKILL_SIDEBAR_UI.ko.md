# 스킬트리 계열 선택 UI

기존 스킬 구성과 규칙을 보존한 UI 변경입니다. 현재 캐릭터의 초상화·직업·실제 포인트, 왼쪽 5개 계열, 오른쪽 사각 아이콘 트리를 표시합니다. 실제 선행 깊이를 기준으로 단계마다 최대 3열로 배치하며 선행 조건이 아닌 연관 점선은 제거했습니다. 선택·습득 가능·습득 완료·잠김·랭크·액티브를 구분하고 기존 습득·회수·초기화·장착·검색·경로 탐색을 유지합니다.

검증: skill_tree_ui_v04 11876건 통과. 1510개 노드의 가독성, 계열 이동, 실제 클릭, 선행 경로, 투자·회수 등 기존 회귀 포함. 처음 전체 계열 표시를 기대한 3개 조건만 첫 계열 선택 조건으로 갱신했습니다. 초기 화면 캡처도 실패 없이 완료했습니다. 캡처: artifacts/v04-tree-sidebar-initial.png 및 artifacts/v04-tree-large-warrior.png.

DB 재생성 후 이전 커밋과 JSON 비교에서 metadata만 변경됐으며 스킬 등 모든 본문 테이블은 동일합니다. 최종 소스의 해시와 런타임 목록을 재생성했습니다. 밸런스·규칙·개인 저장을 변경하지 않았습니다.

QA팀과 DB 관리에 인계 메시지를 보냈으나 두 작업 모두 계정 사용량 한도로 실패했습니다. 따라서 독립 QA·DB 인수 완료로 간주하지 않습니다. 전체 게임 회귀 및 릴리스 빌드 검사는 이번 범위에서 수행하지 않았습니다. V0.5.4 릴리스와 설치본은 그대로입니다.
