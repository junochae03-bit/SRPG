# 스텔알피지 V0.6 · 친구와 탐사

V0.5.4 이후의 협동·던전 탐사·HUD 개편과 QA 원본 21개 개선을 묶은 Windows 64비트 테스트 빌드입니다.

## 주요 변경

- 방장 포함 최대 6인 주소 접속 협동. 공동 층 이동·구조·개인 전리품·확정 저장을 연결했습니다. 개인 메뉴를 열어도 협동 세계는 계속 진행됩니다.
- 일반 던전을 80×80으로 확대하고 갈림길·순환로·생태권별 공간 규칙을 적용했습니다. 10층마다 별도의 레이드 전장을 사용합니다. 단서와 도구로 여는 비밀방은 파티가 함께 개방하고 보상은 개인별로 받습니다.
- 좌상단 개인/파티 상태와 하단 스킬 6칸을 정리했습니다. 좌하단 능력치·스킬·가방 탭은 세부 능력치·직업 아이덴티티·소모품 슬롯을 표시합니다.
- 스킬 지도를 큰 아이콘과 가로·세로 스크롤로 탐색합니다. 액티브를 구분하고 같은 상세 영역에서 선행 투자·강화를 이어갑니다. 20직업의 다섯 방향 빌드를 미리 보고 적용할 수 있습니다.
- 회복·마나·공격 강화 물약을 1~4 슬롯에 등록합니다. 상점·연금술·목표 재고 제작·저장을 연결했습니다. 마나 물약은 현행 자원인 기력 60을 회복하고, 공격 강화는 물리·마법 공격력 +20%를 30초간 제공합니다.
- 캐릭터 표시 크기와 원거리 공격 방향·발사점을 보정했습니다. 등록 90개 렌더 경로의 연속 공격과 회복 자세를 확인했습니다.
- 몬스터 피격 범위, 광역 공격 범위, 회피 거리, 소환수·늑대, 무기별 효과음과 피해 숫자를 개선했습니다. 보스 무력화 성공은 6초, 종료 후 재무력화 잠금은 60초입니다.
- 시설의 중복 NPC 소개 영역을 제거하고 거래 품목·비용·결과를 명확히 표시합니다. 인벤토리 정렬·비교, 버프 시간, 레벨별 초상 테두리와 글자 가림을 정리했습니다.
- 장비·스킬·드랍·시설·소모품·캐릭터 표시 규칙을 최신 DB에 반영하고 DB 관리팀에 인계했습니다.

## 다운로드와 실행

- `StelRPG-V0.6-Windows.zip`: 전부 압축 해제한 뒤 `StelRPG.exe` 실행. `StelRPG.pck`를 같은 폴더에 둡니다.
- `StelRPG-V0.6-Database.zip`: 관리용 SQLite·JSON·스키마·조회 예시·설명서. 게임 실행에는 별도 설치할 필요가 없습니다.
- `SHA256SUMS.txt`: 두 ZIP의 무결성 확인용 해시입니다.

이전 게임을 종료하고 기존 `saves` 폴더를 새 빌드 폴더에 복사하면 이어할 수 있습니다. 배포 ZIP에는 개인 저장·검사용 저장·제작 원본·미사용 V0.6 에셋을 넣지 않습니다.

친구와 플레이할 때는 시작 화면의 **친구와 모험**에서 방을 열거나 방장 주소로 참가합니다. 기본 UDP 포트는 24554입니다. 외부 네트워크는 공유기·방화벽 설정에 따라 연결 가능 여부가 달라집니다. 자동 매칭·자동 중계·방장 이전·끊어진 원정 재접속은 구현하지 않았습니다.

## 범위와 검증

전체 소스 검사 **116그룹·490,283항목**, 실제 Windows EXE의 이동·전투·저장 복원·전직 15종·코스튬 30종·생태권 10종·100층 보스 검사를 통과했습니다. 실제 6개 로컬 ENet 프로세스의 접속·초과 접속 거절·거래·퇴장 저장도 확인했습니다. [배포 검증과 파일 해시](VERIFICATION_V06.ko.md)에 범위를 기록했습니다.

다른 가정 간 장시간 협동, 직업별 장기 밸런스, 다인 전투 음향의 주관적 청취는 남아 있습니다. 전체 벤치마킹 후속 기능과 별도 제작 중인 V0.6 원화를 모두 완성·연결했다는 의미는 아닙니다.
