# 캐릭터 표시·발사점 교정 — 2026-09-13

현재 등록된 90개 렌더 경로(직업 기본 20, 지정 아바타 37, 코스튬/NPC 33)를 점검했다. V06 미등록 원본·ZIP과 기존 래스터 원본은 수정하거나 런타임에 합치지 않았다.

## 화면 크기 교정

유랑 사수는 `costume_v04:pink-bunny-hoodie`이며 정지 frame 15의 두피~발 기준은 225 원본 픽셀, 화면 몸 단위는 112픽셀이다. 머리 장식·돌출 귀·무기는 몸 높이에 포함하지 않는다. 헬멧은 두개골에 붙은 부분의 정점을 사용했다.

90개 정지/공격 비교에서 작게 표시되는 전직 3종을 실측해 실제 표시 크기를 교정했다. 나머지 경로의 원화 등신 자체를 변경했다는 뜻은 아니다.

| 외형 | 원본 정점 y / 발 y (frame 4, 시트 좌표) | 기존 높이 메타데이터 | 교정 전 화면 몸 높이 | 교정 후 |
|---|---:|---:|---:|---:|
| 저격수 sniper | 402 / 632 | 263 | 97.95px | 112px |
| 사냥꾼 hunter | 403 / 619 | 258.5 | 93.59px | 112px |
| 탐험가 explorer | 407 / 624 | 273 | 89.03px | 112px |

정점은 원본에서 육안으로 한정한 헬멧 색상 구간의 12픽셀 이상 지지 행으로 확인했다. 정점 선택 허용오차는 원본 ±4px다. 계수는 각각 `230/263`, `216/258.5`, `217/273`; `character_presentation.json`에 기록했다. 동일 외형의 모든 모션에 고정 계수를 적용하므로 스케일이 자세마다 다시 계산되지 않는다. 발 피벗은 기존 월드 지면에 고정되고 발사점도 같은 배율로 변환된다. 런타임 픽셀 스캔은 없다.

일부 리코 공격 교체 프레임은 정지 프레임과 원본 픽셀 밀도가 다르다. 기존 per-frame `body_height`를 시트 공통 높이로 대체하면 약 2배 크기 튐이 발생하므로 보존한다. 머리/몸 등신의 원화 차이를 무리하게 늘이거나 줄여 왜곡하지 않았다.

몸 단위는 `CharacterPresentation.BODY_PIXELS=112`로 중앙화했다. 소환술사 동료는 그 2배인 224픽셀, 사냥꾼 동물은 112픽셀이다.

## 방향·발사 동작

- 기본 공격의 실제 피해/투사체 발생 시점에 일반 발사 frame 6을 바로 표시하고 frame 7 회복으로 이어진다. 실시간 표시 길이는 약 .22초를 유지한다. 강공격은 frame 10을 사용한다. 4프레임 레거시 아바타는 기존 공격/회복 인덱스를 유지한다.
- 공격 도중 커서를 반대로 움직여도 해당 공격은 발사 때의 방향을 유지한다. 다음 공격은 새 방향을 사용하고, 회복 종료·피격·회피·다운·충전·다른 스킬 전환에서는 이전 방향 고정이 해제된다.
- 기본 마법사의 강공격 frame 10은 원본 손이 왼쪽 위를 향한다. 이 프레임만 원본 방향 -1을 적용하고 다른 프레임은 +1을 유지한다. 모든 원거리 그림을 무조건 뒤집지 않는다.
- 90개 경로에 연결되는 원본 프로필에 일반/강공격 발사점을 기록했다. 손/무기 끝을 육안 대조한 화면 좌표이며 원화에 박혀 있는 장식 효과 전체가 새로운 발사점이라는 뜻은 아니다.
- 섬광과 투사체는 동일한 발사점에서 시작한다. 투사체는 화면 이동 120픽셀에 걸쳐 기존 높이 70픽셀의 피격 표시 평면으로 이어진다. 판정 위치·방향·속도·피해량은 변경하지 않았다.

- 전체 갤러리: `runtime/character-runtime-gallery/phase-{0..3}-page-{00..03}.png`. phase 0=일반 발사, 1=회복, 2=강공격, 3=대기. 노란 원은 발사점, 수평선은 지면이다.

- 실제 메인 장면 좌우 발사: `artifacts/combat-polish-v053/1338437/projectile-{ranger,mage}-{left,right}.png`.
- 실제 장면 검사 기록: `artifacts/combat-polish-v053/1338437/report.json`.
