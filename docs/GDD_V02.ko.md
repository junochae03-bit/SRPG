# 스텔알피지 V0.2 · 심층 던전 탐사

기존 개인용 싱글 플레이에 MMORPG식 직업·장비 성장과 레이드 공략 구조를 적용한다. 네트워크 서버나 다른 플레이어와의 동시 접속은 구현하지 않았다. 밝은 카툰 판타지 분위기와 기존 15개 전직의 자원·전투 방식을 유지한다.

## 모험 흐름

꽃바람 숲에서 적 5마리를 처치하고 R로 햇살 마을에 도착하면 튜토리얼이 끝난다. 첫 장비는 I의 연습 장비 받기로 얻는다. 이후 마을은 안전한 거점이며 전투는 1~100층 던전에서 진행한다. 마을의 원정의 문에서 E를 누르면 생태권별 10개 층과 입장 조건을 확인할 수 있다.

각 층은 연결된 방과 통로, 일반 적 21마리, 엘리트 1마리, 최심부 수문장 1마리로 구성한다. 10층 단위의 수문장은 레이드 보스로 바뀐다. 수문장을 처치하면 다음 층이 해금된다. 출구에서 E로 다음 층에 진입하며 주변 전리품 줍기를 우선한다. R로 귀환하고 마을에서 해금한 층을 다시 탐사할 수 있다. 입장 최소 레벨은 `max(1, 층수−7)`이다. 재입장 시 적이 다시 배치되며 한 탐사 안에서 처치한 적은 부활하지 않는다.

| 층 | 생태권 | 레이드 보스 |
|---|---|---|
| 1–10 | 뿌리 내린 동굴숲 | 뿌리의 문지기 |
| 11–20 | 수정 광맥 | 광맥의 심장 |
| 21–30 | 잠긴 회랑 | 침수 성채의 파수기사 |
| 31–40 | 포자 정원 | 균사의 군주 |
| 41–50 | 잿불 용암굴 | 용암 심장 거인 |
| 51–60 | 빙하의 균열 | 영구빙의 지배자 |
| 61–70 | 버려진 기계도시 | 철의 지휘관 |
| 71–80 | 황혼의 수림 | 황혼의 고목왕 |
| 81–90 | 성운의 공동 | 별을 삼킨 거상 |
| 91–100 | 뒤틀린 마력핵 | 심연의 왕 · 아스트라 |

동굴 안의 마력이 별개의 생태계를 만든다는 설정이다. 지형의 고정 좌표를 기준으로 바닥·균열·수정과 색을 바꾸며 시간에 따른 수풀 깜빡임을 만들지 않는다. 일반 18종·엘리트 3종·보스 3종의 기존 원화를 조합한다. 10개 보스는 이름·능력치·패턴 구성이 다르며 모두 별도의 원화를 가진 것은 아니다.

## 능력치와 전직

최대 레벨 100, 레벨당 능력치 3점과 SP 1점. 경험치는 `120 + 80L + 25L²`로 증가한다. 포인트는 K에서 직접 투자하며 마을에서 초기화한다.

| 능력치 | 실제 효과 |
|---|---|
| 힘 | 1당 물리 공격력 +2 |
| 내구 | 1당 물리·마법 방어력 각각 +2 |
| 기술 | 스킬 재사용 시간 감소: `40% × T/(T+60)` |
| 민첩 | 공격 속도 증가 `65% × A/(A+60)`, 이동 속도 증가 `30% × A/(A+60)` |
| 마력 | 1당 마법 공격력 +2 |

능력치 계산에는 개방된 장비 옵션도 포함한다. 기본 공격력은 `18 + floor(1.5×(L−1))`에 해당 능력치·장비·패시브를 더한다. 마법사 계열과 룬검사는 마력, 다른 계열은 힘을 주 공격력으로 사용한다. 내구는 생명력 스탯이 아니다. 기본 최대 생명력은 `120 + 18×(L−1)`이고 갑옷·패시브가 추가된다. 방어에 따른 피해 감소는 `DEF/(DEF+80+2L)`, 상한 70%다. 물약은 기본 60 + 최대 생명력의 20%를 회복한다.

전사·마법사·궁수·도적·격투가의 5계열과 30레벨 전직 15종을 유지한다. 정면 방어, 룬, 소환수, 카드, 기세·반격, 연무 등 직업별 자원을 유지하며 기술·민첩의 점감식으로 무한 가속을 방지한다. 장착 액티브는 6개다. 스킬 상세의 현재/다음 수치는 장비 옵션과 능력치가 적용된 실제 계산을 사용한다. 기존 노드 수는 총 610개이며 이번 버전에서 새 노드를 추가하지 않았다.

## 장비와 전리품

무기·머리·상의·손·하의·신발·장신구의 7부위, 소지품 60칸, 모든 아이템 한 칸. 무기는 **현재 직업 전용**이고 방어구·장신구는 **1차 계열 공용**이다. 시프 무기는 사신이 사용할 수 없지만 도적 방어구는 시프·도박사·사신이 공유한다. 전직 시 맞지 않는 장비를 가방으로 옮길 공간이 있어야 전직이 완료된다.

| 등급 | 테두리 | 옵션 개방 | 추가 효과 |
|---|---|---|---|
| 일반 | 회백색 | 없음 | 추가 옵션 없음 |
| 레어 | 파랑 | +2 | 능력치 1종 |
| 유니크 | 보라 | +3 | 능력치 1종 |
| 에픽 | 금색 | +4 | 스킬 효과 1종, +8% |
| 레전드리 | 주황 | +5 | 스킬 효과 1종, +12% |

레어·유니크 능력치 옵션은 `3×등급번호 + 2×장비단계`다(일반=0, 단계=0~9). 에픽 이상은 위력·회복·보호막, 사거리·범위, 지속시간·지원 효과 중 하나를 강화한다. 해당 성질이 있는 스킬에 적용되며 같은 계열 옵션의 합산 상한은 +48%다. 옵션은 강화 전까지 잠겨 있다. 기존 기본 강화 보너스와 추가 옵션은 별개로 적용된다. 대장간은 최대 +5 강화와 옵션 재련을 제공하고 일반 장비는 재련할 수 없다.

직업 무기 20×10단계, 계열 방어구·장신구 5×6부위×10단계로 총 500개 장비 기본 조합을 사용한다. 외형은 직업 무기 아틀라스 및 기존 부위 원화를 공유한다. 장비 단계는 층의 10층 구간을 따른다. 상점에서는 현재 직업의 일반 장비만 판매한다.

몬스터별 기존 독립 드랍표를 유지한다. 일반 적·엘리트의 장비는 유니크 이하이며 **에픽 이상은 10층 단위 레이드 보스에서만** 나온다. 보스는 일반 드랍에 더해 아래 확률로 장비 1개를 확정 드랍한다. 해당 확정 장비의 조건부 등급 확률이며 처치당 전체 드랍 개수를 뜻하지 않는다.

| 보스 층 | 유니크 | 에픽 | 레전드리 |
|---|---:|---:|---:|
| 10 / 20 / 30 / 40 | 75% | 25% | 0% |
| 50 / 60 | 62% | 38% | 0% |
| 70 / 80 / 90 | 62% | 34% | 4% |
| 100 | 62% | 26% | 12% |

## UI와 저장

우측 아래 Q/F/V, 그 아래 C/Z/X로 3×2 스킬 배열을 만든다. 기본 공격·강공격·회피의 HUD 버튼은 제거하며 입력은 그대로 유지한다. 양피지·가죽·금속 프레임을 유지하고 직업별 무기 15개와 상호작용 손을 같은 화풍으로 제작했다. 퀘스트 안쪽 여백, 전직 선택 글자, 5종 능력치 설명과 장비 요구 조건의 줄바꿈을 조정했다. 일반 적은 최소 92px, 기존 대비 약 1.3배, 엘리트는 기존 대비 1.12배로 조정하며 보스는 335px의 큰 크기를 유지한다.

세이브 버전은 6. 이전 4종 능력치 투자는 전액 반환하고 새 능력치에 다시 배분한다. 기존 장비는 이행 당시 직업·계열에 맞춰 착용 정보를 채운다. 기존 모험은 튜토리얼 완료로 처리하고 던전 진행은 1층부터 시작한다. 이후에는 해금 층·완료 층·각 레이드 처치 횟수를 저장한다. 재시작하면 안전한 마을에서 이어한다. 기존 슬롯 원본은 검사에 사용하지 않으며 복사본으로 이행을 검증한다.
