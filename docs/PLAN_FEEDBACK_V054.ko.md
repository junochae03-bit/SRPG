# V0.5.3 이후 피드백 작업

이 문서는 당시 배포 작업의 기록이다. 2026-09-13 QA 원본 21개 전체 재대조 및 후속 구현 상태는 [QA_FEEDBACK_21.ko.md](QA_FEEDBACK_21.ko.md)를 기준으로 확인한다. 아래의 미구현·최종 검증은 해당 과거 시점에 한정된다.

2026-09-11 사용자 구현 재개 승인. 공통 사용량 잔여 1% 부근에 검증된 변경을 커밋·main 병합·푸시한다. 배포 V0.5.3과 개인 저장은 보존한다. 대형 밸런스 설계의 미확정 값, 궁극기·MP·카드 덱 규칙은 이번 구현에서 제외한다. 작업 중인 V06 에셋은 별도 보존한다.

1. 구현·개별 검증 완료: 도적·시프 기본 공격의 원거리 판정을 단검 근접 판정으로 정합화했다. 근거리 적중·원거리 불발·기존 직업 회귀를 확인했다.
2. 미재현: 원거리 반대 방향은 확인한 기본 외형에서 재현하지 못했다. 원본별 방향을 확인하지 않은 일괄 반전은 하지 않는다.
3. 구현·개별 검증 완료: 허수아비 마지막 유효 타격 후 임시 10초가 지나면 측정 기록만 초기화한다. 쿨타임·자원·빌드는 보존한다.
4. 구현·개별 검증 완료: 스킬 툴팁·착용 장비 우선·가방 정렬·이동·소환수·능력치 표시를 개선했다. 최신 전체 게이트와 QA 검토를 수행하고 DB 관리에 인계한다.

체크포인트는 각 단계의 실제 검사와 QA 인수다. 별도 사용자 재승인은 요구하지 않는다. 신규 릴리스나 설치 갱신은 전체 배포 검증 없이 수행하지 않는다.

## 현재 진행

- 도적·시프의 단검 근접 판정, 허수아비 자동 만료(임시 10초), 퀵슬롯 실제 효과 툴팁·룬 비용, 대장간 착용 우선, 가방 정렬을 구현했다. 가방 정렬은 종류→등급→이름 순이며 소지품과 착용 상태를 보존한다.
- 스킬트리는 모든 계열을 기본 표시하는 세로 패널로 변경했다. 랭크 0부터 표시하며 휠·스크롤바 탐색, 선행·강화 버튼을 제공한다. 기존 1510개 노드의 조건·관계는 보존한다.
- 추천 메뉴는 기존 핵심 선택까지의 성장 경로 안내다. 완전한 직업별 장착 빌드 프리셋은 아직 아니다. 저레벨·부족한 SP에서도 미래 경로를 읽을 수 있으며 실제 투자는 기존 조건을 유지한다. 코드·UI 회귀를 추가했다.
- 원거리 기본 궁수/저격수 시트는 우향이며 기존 반전식과 맞는 것을 확인했다. 문제의 실제 사용 외형·동작 조합은 아직 재현하지 못했으므로 일괄 반전하지 않았다.
- QA 의견으로 룬 설명 중복을 제거하고, 관련 스킬 버튼의 가로 스크롤 공간을 52px로 확장했다. 툴팁 수치는 hover 시 계산한다.
- 최신 밸런스 정정 인수(구현 보류): 탐험가 초기화는 모든 궁극기 제외. 마검사 최대 룬은 최종 13, 확률·2개 획득 노드 수치는 미확정. 기존 19룬 설계는 폐기한다.
- 도적·시프 카탈로그는 기존 저장 장비 ID를 유지한다. 기본 공격 구성의 bow→sword 전환으로 무기 계수 0.92→1.0(약 8.7%) 및 근접 범위 보너스가 적용된다. 단순 외형 변경이 아니며 근거리 적중·먼 거리 불발·직업 회귀를 검증한다.
- 가방 정렬의 추가 회귀는 일시정지한 실제 세션에서 120칸을 정렬하고 자동 저장 파일의 배치, 재접속 후 배치·장비 수량을 확인한다. 정렬 직후 장비 전체 인스턴스도 보존한다. feedback_v054 273개와 job_ui 1581개 검사가 통과했다.
- 전체 게이트의 첫 재실행은 job_ui가 이전 직접 자식 버튼 구조를 기대하여 중단됐다. 새 스크롤 컨테이너 내부에서 related_id로 정확한 선행 버튼을 찾아 신호 연결과 이동을 검증하도록 수정했다. 전체 재실행 결과를 별도로 기록한다.
- 사냥꾼 늑대 원화 4프레임을 적용하고, 기존 소환수의 잘못된 행 경계를 수정했다. 프레임 알파 16/255 초과 몸체 경계로 발 위치와 계열별 크기를 정규화했다. 늑대 112px, 소환수 224px 기준이며 이동 방향 반전과 늑대 대기·걷기·타격 자세를 실제 상태에 연결했다. 생성 원본은 보존하고 미사용 시안은 업로드하지 않는다.
- 마검사 등 자홍색 배경의 초상화는 렌더러 색 키와 일치하는 몸체 경계를 캐시해 배경 여백이 얼굴 크기를 줄이지 않게 했다. HUD 성능 회귀 869개가 통과했다.
- Space 회피 거리는 기본 3.77, 전직 3.52, 브레이커 4.8 월드 단위로 늘렸다. 소모·무적 시간·충전·재사용 규칙은 기존대로다. 마지막 프레임의 이동량 손실을 없애고 0.18 단위 충돌 검사로 긴 프레임의 벽 관통을 막는다. 20직업 × 3프레임 간격의 거리·벽 회귀를 추가했다.
- 인벤토리에 17개 항목의 능력치 창을 추가했다. 장비 포함 기본 스탯·공격력·방어력·생명력·기력·실제 기본 공격 간격·민첩/기술 기여·치명타를 표시한다. 공격 간격은 실제 전투와 같은 함수다. 치명타는 기존 두 독립 판정의 합성 확률과 발생 가능한 배율 범위이며, 대상·스킬별 피해 배율 전체를 대표하는 DPS는 아니다.
- 마검사의 현재 보유 룬을 캐릭터 발 주변에 표시하고 충전 게이지 영역을 피했다. 메뉴·일시정지에서는 숨긴다. 룬 최대치 신규 설계는 여전히 보류 상태다.
- 초상화 캐시 키에 Atlas 영역과 여백을 포함했다. 등록된 42개 외형에서는 충돌이 재현되지 않았으나, 같은 텍스처의 서로 다른 영역을 쓰는 합성 회귀에서 재현하고 수정했다. HUD 성능 회귀 911개가 통과했다.
- 좌상단 HUD에 유지 중인 효과 아이콘과 남은 초를 표시한다. 캐릭터 머리 위 중복 표시를 줄였으며 만료·사망 시 즉시 숨긴다. 실제 1920×1080 화면에서 금화와 겹치지 않는 것을 확인했고 HUD 배치 412개 검사가 통과했다.
- 피해 숫자는 굵은 폰트·윤곽선·세로 색 변화로 표시하며 치명타는 더 큰 빨간색이다. 최대 80개 노드를 재사용하고 최근 유효 타격을 우선한다. 실제 타격 화면, 풀 상한·재사용·옵션 끄기·만료를 포함한 마을 회귀 54개가 통과했다.
- QA팀은 추가 렌더러·상태 아이콘·초상화 캐시 변경에서 새 P0/P1을 발견하지 않았다. 이는 읽기 전용 코드 리뷰이며 독립 플레이 검증은 아니다.
- 전체 게이트 중 튜토리얼 시험의 엔진 상대 시간 폴더명이 과거 실행과 충돌했다. 실제 이전 저장 파일 생성시각을 확인하고 시험 경로를 Unix 시각·프로세스 ID·상대 시간으로 분리했다. 성장·보상 1197개 재검사가 통과했다. 개인 저장은 수정하지 않았다.
- DB 관리가 원본 의존성 정규식에서 `.gdshader`가 `.gd`로 잘리는 오류를 발견했다. 확장자 경계를 보장하도록 수정하고, 온전한 셰이더 추적·원본 해시·후속 의존성 회귀를 추가했다. 갱신한 DB는 관리 담당의 읽기 검사와 1579개 휴대 DB 검사를 통과했다.
- 389484개 전체 게이트 통과 후 원거리 표시를 추가 개선했다. 실제 화면에서 화살이 발밑에서 출발하는 것을 확인해 기본·습득 투사체의 표시 높이를 28→70px로 맞췄다. 화살촉·깃·잔상, 마법탄 중심·잔상과 0.14초 발사 섬광을 추가했다. 피해·속도·방향·충돌 좌표는 바꾸지 않았다. 궁수·마법사의 좌우 실제 공격 캡처와 읽기 전용 렌더링 회귀를 포함해 전투 표현 213개가 통과했다. 이 추가 변경을 포함한 최종 게이트를 다시 수행한다.

## 아직 구현하지 않은 항목

- 완전한 직업별 장착 빌드 프리셋과 전체 캐릭터 비율 조정은 이번 변경에 포함하지 않았다. 원거리 외형별 정밀한 손 위치와 연속 모션 검사는 남아 있다.
- 신규 물약 자원, 직업 자원·대형 밸런스의 미확정 규칙은 보류한다. 이후 QA가 사용자 원문을 확인한 보스 무력화 성공 시 6초 기절과 종료 후 60초 잠금은 확정 요청으로 구현했다. 요구량 2.5배 및 낮은 공격력 직업 보정 상한 1.65는 개발 조정값이며, 실패한 무력화 검사 후 회복은 기존 별도 6초다.
- 사용자가 직접 확인할 장시간 플레이와 모든 외형별 방향 검사는 완료로 간주하지 않는다.

## 최종 검증

- 최종 런타임으로 `tools/verify_v01.py` 전체 389507개 검사가 통과했다. 검사 중 원본 변경이 없었고, 원본 해시와 런타임 목록이 일치했다.
- 별도 검증용 Windows EXE/PCK 내보내기와 격리된 검사 저장의 수련장 실행이 통과했다. 검사·궁수·마법사의 실제 실행에 오류·경고가 없었으며, 실제 프레임버퍼를 저장했다. 연속 투사체 영상 전체 인수를 뜻하지는 않는다.
- QA 및 DB 관리의 코드·대표 화면·원본 정합성 인수를 받았다. 검증 기록은 `VERIFICATION_FEEDBACK_V054.json`에 남긴다. Git 소스만 반영하며, 기존 V0.5.3 릴리스·설치본 갱신은 수행하지 않았다.
