# 스텔알피지 V0.5 · 별자리의 길과 모험의 시작

- **시작 화면**: 밝은 숲의 동화책과 나무 팻말. 소개 문구·영문 부제·저장 안내·오른쪽 장소 패널을 제거했습니다.
- **캐릭터 생성**: 외형·기본 5직업·닉네임을 고르고 힘·내구·기술·민첩·마력에 초기 10점을 배분합니다. 기존 모험 기록은 바로 이어집니다.
- **스킬 지도**: 원기술 610개를 보존하고 20직업에 특화 900개를 추가했습니다. 검색·확대·경로·현재와 다음 랭크 비교·환급 미리보기를 제공합니다.
- **선택과 시너지**: 같은 SP로 원기술과 특화를 선택합니다. 핵심은 최대 2개이며, 연쇄·지연 타격·지속 피해·지원기 연계·이동 중 다단 공격 등에 이득과 대가가 있습니다. 특화 900개는 추가 액티브 900개를 뜻하지 않습니다.
- **NPC 대화**: 초상·이름·인사를 먼저 보고 대장간·상점·연금술·길드·여관 서비스를 이용합니다. 상시 조작 안내를 줄이고 긴 장비 이름의 표시를 정리했습니다.
- **Full HD UI**: 기본 1920×1080, 큰 스킬 아이콘과 3×2 HUD, 64px 가방 칸. 금속·금색 장식 안쪽으로 제목과 수치를 배치하고 긴 이름과 목록은 스크롤합니다.
- **아트 통합**: 배경 장식 108개, 일반 몬스터 18종·보스 6종의 새 외형, 나무 토큰 아이콘 168개를 수록했으며 152개를 현재 기능에 연결했습니다. 새 캐릭터 원화 33종 중 직업·무기가 맞는 30종은 코스튬으로, 총을 쓰는 3종은 마을 NPC로 사용합니다. 528프레임을 수록하고 각 역할에 필요한 모션을 사용합니다.
- **던전 시야**: 입구·출구와 보행로 주변의 장식을 비우고 보스의 큰 동작이 HUD에 가려지지 않도록 전투 카메라를 조정합니다.
- **장비 그림**: 완료 장비 팩의 무기 60개·방어구 50개·장신구 5개를 가방·도감·전리품에 연결했습니다. 수치와 착용 제한은 유지합니다.
- **바닥 타일**: 새 숲·석조 던전·사막·얼음·용암·천공 6재료를 마을·튜토리얼·10개 던전 생태계에 대응했습니다. 기존 통로와 보행 판정은 유지하며 월드 좌표에 고정해 경계를 연결합니다.
- **자산 관리 DB**: 적용한 그림의 파일·영역·프레임·출처·사용처를 SQLite/JSON에 등록했습니다. SHA256과 관계 조회로 교체할 그림의 사용 위치를 추적합니다.
- **저장 및 DB**: 저장 형식 v7, 별자리 투자와 경로를 포함한 SQLite/JSON. 기존 모험가의 재산과 배운 기술을 보존합니다.

Windows ZIP을 모두 풀고 StelRPG.exe를 실행하세요. PCK는 같은 폴더에 둡니다. 기존 saves 폴더의 슬롯 JSON을 새 빌드의 saves에 복사하면 이어할 수 있습니다. 개인 저장은 ZIP에 포함하지 않았습니다. DB ZIP은 개발·조회용 별도 자료입니다.

검증: 전체 202,684개 통과. 실제 Windows 실행 파일에서 타이틀·생성 화면·NPC 대화·도감 4탭·전직 15종·저장 재시작을 확인했습니다. 생성과 스킬 투자 입력은 소스의 실제 UI 이벤트 검사로 확인했습니다. 100층 전체 전투는 소스 모델 검사이며, 실행 파일에서는 최종 보스 렌더링과 완료 저장 복원을 확인했습니다. 모든 실전 빌드의 균형을 보장하는 결과는 아닙니다.

이번 버전은 싱글 플레이입니다. 온라인 멀티플레이는 후속 작업입니다. 새 몬스터는 대기·공격 키 포즈를 사용하며, 일부 기존 캐릭터 모션과 장착 무기 그림은 기존 표현을 유지합니다.
