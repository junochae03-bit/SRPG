# 연구 재료를 찾아 떠나는 탐사

2026-09-13. G01과 G03의 연구 해금 연결을 구현한다. 원정의 문에서 필요한 재료·미완료 연구를 탐사 목표로 선택하고, 재료를 가져와 정제·연구·첫 제작을 마친 뒤 다음 탐사를 선택한다. 기존 지도 단서·정예 은닉품·강화 재료 목표를 유지한다. 목표는 캐릭터 개인 소유다.

## 재료와 목적지

`research_journey.gd`는 `town_research.gd`의 실제 연구 비용과 완료 후 제작 비용을 사용한다. 미완료 연구는 선행 완료 또는 선행 예약 상태를 확인해 추천한다. 시설의 연구 화면에서는 원하는 연구·제작물을 직접 목표로 등록할 수 있다. 진행 중인 개인 목표가 있으면 그 연구를 우선 제시한다.

씨앗은 이미 해금한 숲, 광석은 해금한 비숲 일반층, 정수는 제단·정예 은닉품이 있는 일반층으로 안내한다. 비밀방 좌표는 공개하지 않고 재료와 단서를 제시한다. 씨앗을 모은 뒤 광석이 부족해지거나 연구 완료 후 제작 재료가 필요해지면, 연구 ID를 유지하면서 현재 부족 재료에 맞춰 HUD의 권장 층을 갱신한다. 가능한 목적지 중 기존 목표와 가까운 층을 선택한다.

초반에 광산을 열지 못한 캐릭터는 실제 연금술 정제법을 이용한다. 씨앗 5개와 20 G로 광석 3개를 얻는 비율에 맞춰 필요한 정제 횟수를 계산하고, 연구에 직접 사용하는 씨앗도 남길 수 있도록 총량을 안내한다. 예를 들어 광석·씨앗이 없는 탐사 도구 연구는 씨앗 12개 → 광석 정제 2회 → 연구용 광석 4개·씨앗 2개 투자로 이어진다. 정제로 연구 목표를 완료하거나 다른 목표로 바꾸지 않는다. 금화·보관 공간은 실제 작업 견적에서 다시 검사한다.

## 귀환부터 다음 도전까지

모은 재료가 정제에 충분하면 귀환 안내가 연금술로 연결되고 해당 시설은 광석 정제 화면을 연다. 정제를 마치면 연구 시설로 안내한다. 해당 시설을 열면 등록한 연구를 바로 선택하지만 기존 거래 화면으로 돌아갈 수 있다.

연구 예약 중에는 현재 단계를 표시한다. 완료된 연구는 실제 제작법 비용으로 전환한다. 연구 예약·연구 완료·다른 제작물 제작만으로 목표를 완료하지 않는다. 등록한 연구의 `research_craft`가 실제 성공해야 목표가 완료된다. 비용 부족·해금 전 요청·잘못된 시설·다른 연구 요청은 완료를 만들지 않는다.

제작 후에는 `다음 탐사 선택`을 표시한다. 누르면 개인 목표를 다음 해금 층 돌파로 바꾸고 원정의 문 위치를 안내한다. 강제 입장이나 순간이동은 하지 않는다. 귀환 결과의 다음 행동도 제작 완료 뒤에는 다음 탐사를 우선 제시한다.

포털은 개인 목표의 현재 권장 층을 초기 선택으로 사용한다. 협동에서는 기존 권한을 유지한다. 게스트 화면은 방장의 공용 출발 계획을 따르며 개인 목표 등록으로 공용 층·위험도를 바꾸지 않는다. 방장이 출발층을 선택·변경하고 파티가 준비를 확인하는 절차를 유지한다.

## UI·저장·검증

추가 추천으로 목록이 다섯 줄이 되면 스크롤하며, 마지막 항목도 전체 표시·선택할 수 있다. 이미 선택한 연구는 `등록된 탐사 목표`로 표시한다. 긴 설명을 HUD에 추가하지 않고 제작물 이름·현재 재료 수량·현재 작업 단계로 진행을 나타낸다.

저장 형식 7의 기존 `expedition_goal` 9개 필드를 사용한다. `research` 종류의 연구 ID·시설·작업·비용·단계는 정본 정의에 맞는 값만 허용한다. JSON이 정수 값을 실수형으로 복원하더라도 유한한 정수인지 검사한 후 단계 비교를 수행한다. 기존 재료 목표의 같은 저장 복원 문제도 수정했다. 협동 프로토콜은 11이며 이전 10 클라이언트를 거절한다.

검사는 100개 해금 범위에서 연구 6종의 접근 가능한 목적지, 재료·단계 전환, 실제 정제·연구·제작, 개인 소유, 실제 저장 파일 복원, 위조 목표 거절을 확인한다. UI는 등록·기존 거래 복귀·정제·제작·다음 목표·추천층·다섯째 행 스크롤 선택을 실제 버튼으로 검사한다. 6인 ENet은 각자 목표 등록·개인 파일 저장·제작 완료·다음 목표 전환 후 기존 탐사·귀환 흐름을 확인한다. 연구 시간 완료는 저장 확인 장벽 뒤 호스트 함수를 통제된 30초만큼 전진시킨 검사다.

QA가 지적한 재료 변경 후 목적지 고정과 포털 최심층 초기화 문제를 수정했다. 검증 기록은 `docs/qa/research-journey-verification.json`에 보관한다. 길드 등급·생산 대기열·원정 재접속·부분 귀환·외부 회선 장시간 균형 검증 및 전체 벤치마킹의 다른 항목은 이 작업의 완료로 계산하지 않는다.
