# 스텔알피지 V0.5.2 · 전투와 탐사

ESC에서 소리·화면·전투 표시를 설정하고, 키 변경은 설정 안에서 엽니다. 키 변경에서 돌아와도 설정 화면과 일시정지는 유지합니다. 소리 크기, 창/전체 화면, 창 해상도, 프레임 제한, 수직 동기화, 피해량 숫자와 몬스터 이름 표시를 저장합니다.

스킬 지도는 각 가지의 전투 효과를 탭으로 표시합니다. 액티브는 사각 프레임과 ‘액티브’ 표식, 강화는 원형 메달, 핵심 선택은 문장으로 구분합니다. 시적인 이름 대신 노드 아래에 실제 변화가 먼저 보이며, 오른쪽에서 피해·범위·재사용의 현재와 다음 값을 비교합니다. 첫 선택은 배울 수 있는 기술을 보여주고, 잠긴 기술의 ‘선행으로’는 필요한 노드로 이동합니다. 자동으로 포인트를 쓰지는 않습니다.

광역기의 반경은 기술별로 약 35~50% 확대하고, 좁게 지정됐던 일부 전직 광역기는 최소 범위를 확보했습니다. 회전·돌진 광역기는 주변 적에게 맞으며 전방 찌르기·투사체의 성격은 유지합니다. 이펙트의 지면 윤곽도 실제 판정 반경을 사용합니다.

몬스터 몸통을 클릭했을 때 바닥의 먼 지점을 조준하던 문제를 고쳤습니다. 실제로 그려진 몸체를 선택하면 해당 몬스터를 향하며, 발밑의 금색 고리로 조준 대상을 보여줍니다. 피격 반경도 몸집에 맞춰 넓혔습니다. 벽 너머 피해와 적의 공격 사거리·이동 충돌 확대는 허용하지 않습니다.

던전은 가지 길·순환 회랑·대공동·곁굴·갈라진 다리·교차 성채의 여섯 구조를 회전·변형해 생성합니다. 통로는 5칸으로 넓히고 입구는 비워 둡니다. 넓은 방의 군집, 갈림길 경계, 나뉜 무리처럼 적 배치를 바꿨습니다. 같은 생태계에서도 일부 바닥 재질을 달리 쓰며, 기존 100층 진행과 10층마다의 레이드 규칙은 유지합니다.

배경은 실제 그림을 보고 생태계에 어울리는 소품만 선별했습니다. 등록된 108종은 보존하고 사용 후보는 68종으로 줄였습니다. 숲의 병풍·북·향로와 빙하의 가구·악기 등을 제외하며, 제거한 위치를 다른 소품으로 다시 채우지 않습니다.

마을은 현재 작업·선택 품목·비용·완성 결과를 나란히 보여줍니다. 수량을 골라 물약을 구매·조제하고, 대장간에서 미착용 장비를 분해할 수 있습니다. 연금술에 광석 정제, 길드에 재료 납품과 의뢰 포기, 여관에 회복과 물약 보충을 묶은 원정 재정비를 추가했습니다. 거래 공간이나 재료가 부족하면 부분 차감 없이 거절합니다.

마을을 확장해 독립 코스튬 상점과 수련장을 추가했습니다. 수련장의 거대 허수아비는 누적 피해·초당 피해·타격 수·무력화 연습을 지원합니다. 교관에게서 훈련 기록과 기술 대기시간을 초기화할 수 있으며 경험치나 전리품은 생기지 않습니다.

가방은 120칸이며 기존 60칸의 위치를 유지합니다. 같은 부위 장비의 현재 능력치와 교체 후 능력치를 비교하고, 증가·감소와 착용 제한을 표시합니다. 이동기 사용 후 화면 중앙에 실제 재사용 시간을 표시하고, 강공격 충전량은 캐릭터 우측의 주황색 게이지, 치명타 피해는 굵은 빨간색 숫자로 보여줍니다.

기존 캐릭터 기록·코스튬 소유·직업·스킬 포인트와 키 배치를 이어서 사용합니다. 개인 저장 파일과 별도 제작 중인 V0.6 원화는 배포에 포함하지 않습니다. 시설·거래·던전 구조·훈련·가방 규칙 DB와 원본 연결을 추가하고 프로젝트의 ‘DB 관리’ 작업에 인계합니다.

저장에 실패하면 변경 기록과 기존 저장 파일을 보존하고 다시 시도합니다. 재료 상한을 넘는 거래·제작·습득은 부분 차감 없이 처리하며, 저장 검사에도 같은 상한을 적용합니다. 화면 문구와 문서의 한국어 및 원치 않는 문자 혼입을 점검합니다.

전체 소스 검사와 실제 Windows 실행 검증을 통과했습니다. DB 관리는 최종 데이터와 원본의 일치·무결성을 확인해 인수했습니다. [검증 결과](VERIFICATION_V052.json)에 확인 범위를 기록했습니다. 첫 30분 성장 흐름, 대표 층의 전술 차이, 장시간 성능은 남은 플레이 평가 항목입니다. 짧은 측정에서 도감 최초 열기는 약 0.7초가 걸렸으며, 이 지연은 개선 완료로 처리하지 않았습니다.
