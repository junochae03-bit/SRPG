# 스텔알피지 V0.3 · 모험 도감과 보스 무력화

이번 버전은 싱글 플레이입니다. 실제 온라인 멀티플레이는 후속 단계로 진행합니다.

- **B 모험 도감**: 장비 2,500개 등급 변형, 몬스터 원형 24종과 레이드 10종, 몬스터별 드랍·층별 획득처, 기존 스킬 610개의 검색·랭크 비교.
- **SQLite/JSON DB**: 같은 실제 게임 데이터에서 생성. 100층 출현 620조합, 독립 드랍 132행, 스킬 선행 651개와 랭크 2,030행, SQL 조회 예제.
- **보스 무력화**: 일반 축적 게이지와 HP70%·40%의 12초 체크. 성공하면 4초 행동 중단·받는 피해 +20%, 이후 6초 면역. 실패 공격은 예고 후 회피할 수 있습니다.
- **기술 능력치**: 기존 재사용 시간 감소에 스킬 무력화 증가 추가. 기술60은 무력화 +30%. 다단·지속·소환 공격의 시전당 총량을 제한합니다.
- 다른 프로젝트 작업의 **18계열 스킬 VFX 통합**. 새 배경·코스튬은 검토·인계 상태를 문서화했으며 게임에 연결하지 않은 원본 팩은 첨부하지 않았습니다.

Windows ZIP을 모두 풀고 StelRPG.exe를 실행하세요. PCK는 같은 폴더에 둡니다. 데이터베이스 ZIP은 개발·조회용 별도 자료입니다. 기존 saves의 슬롯 JSON을 새 빌드의 saves에 복사하여 이어할 수 있습니다. 개인 저장은 ZIP에 없습니다.

검증: 전체 52,156개 통과. 이후 무력화 HUD 테두리 조정은 25개 렌더 검사로 재확인했습니다. 실제 Windows EXE의 저장 재시작, 도감4탭, 전직15종,100층 보스 상태 및 완료 저장 복원을 검사했습니다. 전체100층 전투는 소스 모델 검사입니다.
