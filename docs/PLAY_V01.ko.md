스텔알피지 V0.1 · 개인용 싱글 액션 RPG

ZIP을 폴더에 모두 풀고 StelRPG.exe를 실행하세요. 별도 Godot 설치는 필요 없습니다.
StelRPG.pck는 실행 파일과 같은 폴더에 두세요. Windows 64비트용입니다.

처음에는 햇살 마을에서 시작합니다.
I → 연습 무기 4종 받기 → 무기 장착 → 원정의 문 근처에서 E → 던전 선택 → 원정 시작.
레벨을 올린 뒤 K에서 능력치와 스킬 포인트를 직접 투자하세요.

WASD / 방향키: 이동, 마우스: 조준
좌클릭: 기본 공격, 우클릭 누르기/떼기: 충전 강공격
Shift: 달리기, Space: 회피
Q: 기본 직업 기술, F/V/C: 배운 액티브 기술
1: 물약, E: 줍기/마을 NPC 대화, R: 마을 귀환
I: 장비/가방/외형, K: 성장, Esc: 닫기/메뉴/음량

가방, 성장, 거래 화면에서는 전투 시간이 멈춥니다.
장비는 모두 한 칸이며 7개 장착 부위와 소지품 60칸을 별도로 사용합니다.
거래에서는 상품이나 작업을 고른 뒤 오른쪽의 비용과 결과를 확인하고 실행하세요.

저장은 실행 파일 옆 saves 폴더에 생성됩니다. 슬롯은 3개입니다.
기존 소스 버전의 runtime/saves 안 slot-1.json, slot-2.json, slot-3.json을
이 버전의 saves 폴더에 복사하면 이어할 수 있습니다. 게임을 종료한 뒤 복사하세요.
같은 슬롯을 두 게임 창에서 동시에 실행하는 방식은 지원하지 않습니다.
세이브와 음량 설정은 ZIP에 포함하지 않았습니다.

추가 전투 프레임은 기본 직업 외형 3종에 적용되어 있습니다.
