## 현재 단계: HUD와 소모품

- 왼쪽 아래: 능력치 탭은 실제 세부 능력치, 스킬 탭은 룬/기세/패 등 직업 상태, 가방 탭은 동일한 소모품 퀵슬롯 1~4를 표시한다. 전체 메뉴는 기존 단축키로 진입한다.
- 왼쪽 위: 초상화, 레벨, 닉네임, 직업과 생명력/기력 표시.
- 최신 추가: 개인 패널의 중앙 정렬 여백을 없애 화면 왼쪽 12px에 고정한다. 아래에는 본인을 제외한 최대 5명 체력/자원 막대와 작은 버프 아이콘만 표시한다. 자원은 실제 스냅샷의 마나가 있으면 마나, 현행 기력만 있으면 기력을 사용한다. 디버프는 제외하고 상세 이름/시간은 호버에 둔다. `party_hud.gd`, `expedition_hud_chrome.gd`, `combat_hud.gd` 및 `expedition_hud.gd`로 검증한다.
- 하단 가운데: 가로 스킬 6칸. 공격/강공격/회피 상시 버튼 없음.
- 하단 스킬바 바로 위: 작은 소모품 등록 1~4칸. 최신 위치 변경 지시를 반영하며 기존 상호작용/귀환 화면 버튼은 숨기고 단축키 유지.
- 등록은 로컬 UI 설정으로 원자적으로 저장. 사용은 기존 방장 권위 세션 경로를 사용하며 재고/쿨다운을 복제하지 않는다.
- QA 원본21 반영으로 회복·마나·공격 강화 물약을 등록한다. 마나는 현행 기력60 회복, 공격 강화는20%/30초. 전체 규칙과 검사 범위는 `QA_FEEDBACK_21.ko.md`에 기록한다.
- 키 설정 추가 시 기존 사용자 키를 보존하는 마이그레이션. 장식/텍스트 가림 및 입력 차단 검증.
- 증거 명령: Godot `--path game --script res://tests/expedition_hud.gd`, `hud_layout_v04.gd`, `keyboard_ui_v051.gd`, `hud_world_labels_v052.gd`, `performance_ui_v05.gd`.
- 검토: QA팀에 코드와 실제 화면 인계. 사용자 추가 승인 대기 단계는 없다. 진행 중.

## 다음 실행: 비밀방과 도구 선택 보상

- `hidden_rooms.gd`, `dungeon.gd`: 일반층의 자연스러운 빈 공간에 1~2개 단서·숨은 공동·선택 도구 문을 시드로 생성한다. 빈 공간이 좁으면 주 경로를 바꾸어 방을 억지로 끼우지 않는다. 기존 주 경로는 항상 열려 있고 방 개방에 따라 지도 형상을 갱신한다. 레이드 준비/전장에는 추가하지 않는다.
- `exploration_rooms.gd`, `simulation.gd`, `local_session.gd`, `coop_session.gd`: 가까이에서 발견한 단서를 파티에 공유한다. 개방은 파티 공동, 보상은 개인별 한 번. 세대·거리·전투 안전·도구 비용과 가방 한도 검증 후 확정하며 지연된 요청을 거절한다.
- `exploration_panel.gd`, `forest_environment.gd`, `minimap.gd`: 단서와 열리는 길을 실제 렌더에 반영하며 상호작용 카드에는 명확한 개방/회수 버튼만 둔다. 마스크는 개방 시에만 다시 만든다.
- 증거: `hidden_rooms.gd` 신규 테스트(여러 시드, 도구 없이 출구 도달, 공동 개방/개인 보상, 비용 부족/중복/이전 층 요청 무변경), 기존 탐사·협동 회귀, 실제 전후 캡처. 검증 후 다음 항목 진행. 사용자 승인 대기 없음.

## 이후 단계: 전체 선택 벤치마킹

사용자가 HUD 이후 남은 선택 요소 전부 구현을 요청했다. 기존 46개와 Stoneshard 선택 14개의 중복을 묶어 `PLAN_SELECTED_BENCHMARKS.ko.md`에서 항목별 증거와 상태를 추적한다. 체크표시나 기반 구현을 전체 완료로 바꾸지 않는다.

1. 탐험: 비밀방/도구 보상/소문 지도/지역 규칙/위험 선택/출발 정보/귀환 결과.
   - 최신 우선 수정: `dungeon.gd`의 교차 회랑 생성 후보 제거, 일반 탐사 공간 확대. 막힌 진입·연결·레이드 분리·반복 시드 및 실제 맵 렌더를 `exploration_rooms.gd`, `dungeon_variety_v052.gd`, `exploration_visual.gd` 검사로 확인한 뒤 나머지 탐사 기능을 진행한다.
2. 전투: 적 역할 구성/방어 대응/소음 경계/위험 회피/함정·투척/적 정보/화면 밖 예고.
3. 성장: 시설 해금/연구/길드 계약/목표 추천/의뢰 선택과 지역 결과.
4. 운영: 제작량·대기열/창고 정책/장비 옵션 보존/수리·보급·거점.
5. 편의: 연결 툴팁/실제 능력치 출처/알림 연결/수량 분할/스케일·오디오 설정.
6. 협동: 재접속/방장 이탈/원정 귀환 정책과 실제 환경 검증.
7. DB 생성·출처·정합성 및 QA/DB 관리 인계.

각 단계의 변경 파일과 구체 검증 명령은 해당 실행 계획에 기록한다. QA 누적 계획에서 이미 검증된 항목은 재작업하지 않고 신규 HUD 요구가 과거 배치 요구보다 우선한다. 전체 벤치마킹은 진행 중이며 완료되지 않았다.
