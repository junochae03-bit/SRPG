# 공격 예고 우선순위와 화면 밖 위험

2026-09-13. C06의 개인 위험 강조, 여러 공격 예고의 겹침 처리와 화면 밖 방향 안내를 구현한다. 전투 판정·피해 수치·스킬 범위·네트워크 권한은 변경하지 않는다.

- 실제 `MonsterAttacks.contains`와 공격원에서 플레이어까지의 시선 검사를 사용한다. 내 캐릭터에게 닿는 공격, 다른 생존 파티원에게 닿는 공격, 나머지 순으로 강조한다. 고리의 안전 중심과 벽에 막힌 공격은 내 위험으로 판정하지 않는다.
- 낮은 우선순위와 늦게 도달하는 예고를 먼저 그린다. 내게 곧 닿는 경계가 마지막에 보이며, 0.45초 이하에서는 밝은 경계색으로 바뀐다. 모든 도형의 경계를 유지하고 채색은 현재 화면·현재 시야와 실제로 교차하는 도형 중 최대 4개에 배정한다.
- 채색 대상은 실제 렌더 외곽 다각형과 화면/시야 타일의 교차로 확인한다. 원점·중심만 검사하지 않으므로 긴 선이나 일부만 보이는 원의 테두리가 누락되지 않는다. 고리의 안전 중심만 보이는 경우에는 채색 한도를 소모하지 않는다. 멀리 떨어진 파티원의 보이지 않는 공격도 내 채색 한도를 소모하지 않는다.
- 동일한 렌더 도형은 채색을 합친다. 원형/고리는 시전자 위치가 달라도 같은 도형이면 합치되 각 시전자의 방향·위험도·남은 시간은 별도 유지한다. 병합된 도형은 가장 높은 위험도와 그 위험도에서 가장 빠른 도달 시점을 표시한다. 벽에 막힌 빠른 공격이 실제로 나에게 닿는 늦은 공격의 시점을 덮지 않는다.
- 현재 파티 시야에 있는 공격원이 화면 밖에서 나에게 닿는 공격을 예고하면 화면 가장자리에 방향과 남은 시간을 표시한다. 발견하지 못한 공격원 위치는 노출하지 않는다. 8방향으로 묶고 가장 빠른 최대 4방향만 표시한다. 기존 HUD·조사 창·탐사 창 영역을 피해 배치하며 공간이 없으면 겹쳐 그리지 않는다. 메뉴·사망·이탈 때는 숨긴다.
- 남은 시간은 시전 준비와 후속 타격 지연을 합하며, 이미 예약된 후속 공격은 실제 남은 타이머를 사용한다. 소유자가 사라지거나 사망·기절·무력화로 취소된 공격은 실제 전투 처리와 같은 조건으로 제외한다.
- 표시 요소는 마우스 입력을 받지 않는다. 공격·이동·회피·키 설정에 동작을 추가하지 않는다. 개인별 위험 강조는 같은 6인 스냅샷에서도 각자의 위치로 계산한다.
