# 과거 추출 에셋 제거

범위: 현재 작업 프로젝트의 스텔랜덤디펜스 캐릭터 프레임 및 쿵야 배경, 관련 런타임 참조와 DB. 원본 게임, 별도 보관본, 다른 작업자의 신규 원화, Git 과거 기록은 변경하지 않는다.

1. 런타임 로딩·선택·렌더링에서 제거하고, 기존 저장의 미지원 코스튬은 기본 외형으로 정규화한다. 확인: 외형·상점·실제 화면 테스트. 별도 승인 단계 없음.
2. 카탈로그가 참조한 추출 파일만 절대 경로를 검증한 뒤 제거한다. 확인: 제거 대상 경로와 런타임 참조 검색. 별도 승인 단계 없음.
3. DB와 이름 목록을 재생성한다. 확인: DB 생성 및 무결성 검사, 실제 미리보기 렌더링. QA와 DB 관리에 결과를 전달한다.

진행: 구현 및 검증 완료.

- 추출 PNG 42개, import 설정 42개, 카탈로그 2개를 제거했다. 기존 네 코스튬 선택·렌더링·아트 DB 등록도 제거했다.
- 삭제된 보유 코스튬 ID 네 가지만 저장 파서에서 정리한다. 미지원 ID, 정상 ID 중복, 비문자열 거부는 유지한다.
- `python tools/verify_v01.py`: 374,216개 검사 통과. 검증 시작·종료 런타임 파일 해시 일치.
- 전체 게이트에 등록한 `removed_assets`는 358개 검사 통과. schema 3/7의 실제 저장 왕복, 독립 대조군, 정상 보유 외형·장비·성장·재료 보존을 검사한다.
- `python tools/build_database.py`: JSON/SQLite/manifest 재생성. 아트 1,656개, 파일 182개, 사용 관계 10,091개. DB 관리의 초기 수신 검증 통과, QA의 코드 및 집중 검사 검토 통과.
- 이름 지정용 미리보기는 91개로 갱신했다. 남은 외형 번호는 보존했다.
- 기존 V0.5.2 배포 실행 파일과 릴리스는 교체하지 않았다.
