# V0.5.2 짧은 처리 시간 측정

2026-09-10에 기존 100레벨 기록의 복사본으로 마을, 가방, 스킬, 도감, 1층 전투를 각각 12초 실행했다. 원래 저장 파일은 사용하거나 변경하지 않았다. 실제 화면을 숨긴 측정이며 수직 동기화를 해제했으므로 사용자가 보는 초당 프레임 수나 장기 안정성의 증거로 사용하지 않는다.

측정 장치는 NVIDIA GeForce RTX 4070 SUPER다. 창 크기와 렌더링 조건을 포함한 원본 결과는 개발 폴더의 `runtime/performance-v052.json`에 보관한다. 개인 기록과 복사본은 배포하지 않는다.

| 측정 항목 | 관측값 |
|---|---:|
| 마을 반복 그리기 처리의 95백분위 | 0.85ms |
| 1층 전투 반복 그리기 처리의 95백분위 | 1.05ms |
| 가방 최초 열기 | 98ms |
| 스킬 지도 최초 열기 | 47ms |
| 도감 최초 열기 | 710ms |

반복 그리기는 이번 표본에서 짧았지만, 도감 최초 열기는 멈칫함을 느낄 수 있는 구간이다. 이 항목은 개선 완료로 처리하지 않는다. 최초 자산 준비의 순간 지연도 있으며, 위 백분위 수치만으로 없다고 판단하지 않는다.

최종 가방 수정은 레이아웃 확정 뒤 선택 항목을 노출시키는 변경이다. 위 측정은 그 수정 직전 원본을 대상으로 했으며, 해당 수정의 성능 향상을 주장하는 자료가 아니다. 실제 창을 띄운 60분 이동·전투, 여러 층의 최대 적 배치, 메모리와 소리의 장기 검증은 별도 평가가 필요하다.
