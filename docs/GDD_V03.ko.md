# V0.3 · 모험 도감과 보스 무력화

이 버전은 싱글 플레이로 개발한다. 최종 방향은 온라인 던전 탐사 MMORPG지만 계정·서버·동기화·파티 전투는 후속 작업이다. [V0.2의 직업·장비·100층 설계](GDD_V02.ko.md)를 이어받으며, 이번 변경은 조회 데이터와 보스 공략 요소에 집중한다.

## 모험 도감

HUD의 도감 아이콘 또는 B로 연다. 장비·몬스터·드랍·스킬을 검색하고 조건으로 좁힌다. 게임에서 쓰는 카탈로그를 직접 읽으므로 도감과 전투가 다른 수작업 숫자표를 사용하지 않는다. 도감에서는 포인트·아이템을 소비하지 않으며 전투와 무력화 제한시간이 멈춘다. B/Esc로 닫거나 I/K로 다른 화면으로 바꾼다.

장비는 등급·직업·계열·부위·착용 레벨·강화 옵션과 획득처를 표시한다. 몬스터는 기본 원형과 층별 성장 수치를 구분하고, 10개 레이드의 실제 능력치·패턴·드랍으로 연결한다. 독립 드랍 확률, 확정 추가 장비의 등급 확률, 특정 부위까지의 확률을 별도로 설명한다.

스킬 DB는 이름·직업·선행 조건·랭크 수치·무력화 정보를 조회한다. 기준 공격력 100/HP 1000/기술 0과 현재 캐릭터 능력치 적용 모드를 구분한다. 적 방어·직업 자원·다른 패시브에 따라 실전 결과가 달라질 수 있으며 조회값의 기준을 표시한다. 성장창 K의 현재→다음 비교에도 스킬 무력화량을 표시한다.

[SQLite·JSON 데이터와 조회 예제](GAME_DATABASE.ko.md)는 동일한 게임 데이터에서 재생성한다. 610개 스킬 노드는 기존 구현의 조회 자료이며 새 스킬 610개를 추가한 것은 아니다.

## 보스 공략

체력 아래에 별도 무력화 게이지를 표시한다. 실제 적중이 게이지를 채우며 일반 몬스터에는 이 시스템을 적용하지 않는다.

| 상태 | 규칙 |
|---|---|
| 축적 | 최대 `180 + 층 × 0.8`. 4초 동안 적중하지 않으면 초당 8 감소 |
| 무력화 집중 | 레이드 체력 70%·40%에서 각 1회. 12초 동안 `65 + 층 × 0.2` 축적 필요 |
| 무력화 성공 | 진행 중 공격 중단, 4초간 행동 불가, 받는 HP 피해 +20% |
| 무력화 면역 | 성공 종료 또는 체크 실패 후 6초간 다시 축적 불가 |
| 체크 실패 | 반경 3.6의 범위 공격을 1.8초 예고. 밖으로 이동하거나 회피 가능. 1회 피해는 최대 HP 70% 이하 |

100층은 일반 게이지 260, 체크 게이지 85다. 20개 기본·전직 모두 실제 기본 공격 간격으로 제한시간 안에 체크를 수행할 수 있게 맞췄으며, 스킬을 모아 사용하면 더 빨리 끊을 수 있다. 이 검사는 정지 표적을 사용하며 실전 회피·위치 선정을 대신하지 않는다. 일반 기절로 레이드 보스를 계속 묶을 수 없다.

5초 동안 살아 있는 플레이어가 전장에서 이탈하거나 사망으로 초기화되면 보스 HP·위치·무력화 상태·체크 기록을 복구한다. 초기화 전에 발사된 지연 공격은 새 전투에 피해나 무력화를 넣지 못한다. 전투 중 상태는 저장하지 않고 기존 안전한 재시작 규칙을 유지한다.

## 기술 능력치와 시전당 무력화

힘·내구·민첩·마력의 역할은 유지한다. 기술 T는 투자값과 개방된 장비 옵션의 합이다.

- 기존 쿨타임 감소: `0.40 × T / (T + 60)`.
- 추가 스킬 무력화 보너스: `0.60 × T / (T + 60)`.
- 기술 60이면 쿨타임 20% 감소, 스킬 무력화 30% 증가. 두 효과는 점감한다.
- 스킬 기본 무력화는 공격 성격에 따라 16/24/32/40. 랭크당 기본값의 20% 증가 후 기술 보너스를 적용한다. 직접 공격이 없는 지원·패시브는 0이다.
- 일반 공격 7, 강공격 14~20의 무력화 기여는 기술 능력치로 증가하지 않는다.

다단·장판·출혈·투사체·소환·반격은 시전당 예산을 실제 명중에 나눠 사용한다. 빗나감·취소·이펙트 재생은 무력화 피해를 만들지 않는다. 시전 뒤 기술이나 장비를 바꾸어도 이미 발사한 공격의 예산은 달라지지 않는다.

## 시각 작업 연동

다른 작업에서 만든 18계열 스킬 VFX를 시전 메타데이터로 연결했다. 효과의 생성·재생과 HP/무력화 판정은 독립이다. 차지, 이동 끝점, 실제 장판 펄스, 사슬·원소·소환 등을 구분한다. [이펙트 사용법](SKILL_EFFECTS.ko.md)과 [작업 간 인계 현황](TEAM_INTEGRATION_V03.ko.md)을 참조한다.

새 배경·장비·코스튬 원화는 담당 작업의 완성 상태와 프레임·발 기준점·ID 매핑을 확인한 뒤 연결한다. 사용하지 않은 원본 팩은 게임 릴리스나 저장소에 포함하지 않는다.
