스텔알피지 V0.1.1 · 직업 밸런스 / 성장 UI 테스트

ZIP을 모두 풀고 StelRPG.exe를 실행하세요. StelRPG.pck를 같은 폴더에 둡니다.
Godot 설치가 필요 없는 Windows 64비트 빌드입니다.

I: 장비·가방·외형 / K: 스킬 트리·능력치 / Esc: 닫기·설정
WASD·방향키: 이동 / 마우스: 조준 / Shift: 달리기 / Space: 회피
좌클릭: 기본 공격 / 우클릭 누르기 → 떼기: 충전 강공격
Q·F·V·C·Z·X: 장착한 액티브 6칸 / 1: 물약 / E: 줍기·시설 대화 / R: 마을 귀환
도박사 TAB: 카드·컷 후보 선택 / 평타: 교체·후보 확정

햇살 마을에서 I로 연습 무기를 받고 장착한 뒤 원정의 문에서 E를 누르세요.
레벨마다 스킬 포인트 1, 능력치 포인트 3을 직접 투자합니다.
30레벨에는 같은 기본 계열의 3개 전직 중 하나를 선택할 수 있습니다.
60레벨부터 기존 기술의 강화 노드가 단계적으로 열립니다. 최대 레벨은 100입니다.
전직·장착 변경·초기화는 마을에서 가능합니다. 전직하면 SP를 다시 배분합니다.

K에서 기술 이름을 검색하거나 연결선을 따라 경로를 찾으세요.
노드를 선택하면 실제 현재 → 다음 랭크 수치가 나옵니다.
오른쪽 Q/F/V/C/Z/X 버튼으로 기술을 배치합니다. 아래 슬롯을 누르면 해당 경로로 이동합니다.
표시 피해는 치명타·카드 배당·기세·상대 약화 이전의 기본값입니다.
왼쪽 아래 직업 패널에서 룬·카드·기세·연무·동료를 확인합니다. 마우스를 올리면 세부 설명이 나옵니다.

가방·성장·거래 화면에서는 전투가 멈춥니다.
아이템은 한 칸이며 장비 7부위와 소지품 60칸을 별도로 사용합니다.
상점·대장간에서는 상품/작업을 고른 뒤 비용과 결과를 확인하고 실행합니다.

실행 파일 옆 saves 폴더에 슬롯 3개가 저장됩니다.
기존 게임을 종료한 뒤 예전 saves 또는 소스의 runtime/saves에 있는 slot-1.json 등을
이 빌드의 saves 폴더에 복사하면 이어할 수 있습니다. 같은 슬롯을 두 창에서 동시에 실행하지 마세요.
패키지에는 개인 세이브와 검사 세이브를 넣지 않습니다.
