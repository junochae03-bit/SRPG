WASD·방향키: 이동 / 마우스: 조준 / Shift: 달리기 / Space: 회피
좌클릭: 기본 공격 / 우클릭 누르기 → 떼기: 충전 강공격
위 Q·F·V, 아래 C·Z·X: 장착 액티브 6개 / 1: 물약
E: 줍기·시설 대화·던전 출구 / R: 마을 귀환
I: 장비·가방·외형 / K: 스킬·능력치 / B: 도감 / Esc: 닫기·설정
도박사 TAB: 카드·컷 후보 선택 / 평타: 교체·후보 확정

새 게임은 꽃바람 숲에서 시작합니다. I로 연습 장비를 받고 장착하세요.
적 5마리를 처치한 뒤 R로 햇살 마을에 도착하면 튜토리얼이 끝납니다.
이후 원정의 문에서 E를 눌러 1~100층 중 해금된 층에 입장합니다.
최심부 수문장 처치 → 출구에서 E로 다음 층. R로 마을에 돌아올 수 있습니다.
주변 전리품이 있으면 E는 줍기를 먼저 합니다. 해금한 층은 마을에서 재입장할 수 있습니다.
10층마다 강력한 레이드 보스가 있으며 최종 목표는 100층 아스트라 격파입니다.

레벨당 SP 1점, 능력치 3점을 직접 투자합니다. 최대 레벨 100입니다.
힘: 물리 공격 / 내구: 물리·마법 방어 / 기술: 스킬 재사용 감소·스킬 무력화 증가
민첩: 공격·이동 속도 / 마력: 마법 공격. K에서 실제 변화량을 확인하세요.
30레벨에 계열별 3개 전직 중 하나를 선택하며 60레벨부터 전직 강화가 열립니다.
기술 선택 시 현재 → 다음 수치가 나옵니다. 오른쪽 Q/F/V/C/Z/X로 배치합니다.
전직·기술 배치·초기화는 마을에서 가능하며 전직하면 SP를 다시 배분합니다.

모든 아이템 한 칸, 가방 60칸, 장비 7부위입니다.
무기는 현재 직업 전용, 방어구·장신구는 1차 계열 공용입니다.
등급 테두리: 일반 회백색 / 레어 파랑 / 유니크 보라 / 에픽 금 / 레전드리 주황
레어 +2, 유니크 +3에서 능력치 옵션이 열립니다.
에픽 +4, 레전드리 +5에서 스킬 강화 옵션이 열리며 레이드 보스에게서만 나옵니다.
가방 상세에서 착용 조건·잠금 상태를 확인하고 대장간에서 강화·재련하세요.
도감·가방·성장·시설·메뉴 화면에서는 전투가 멈춥니다.

실행 파일 옆 saves 폴더에 슬롯 3개가 저장됩니다.
기존 게임을 종료한 뒤 예전 saves 또는 소스 runtime/saves의 slot-1.json 등을
이 빌드의 saves에 복사하면 이어할 수 있습니다. 같은 슬롯을 두 창에서 동시에 열지 마세요.
이전 능력치 포인트는 전액 반환되므로 K에서 5종 스탯에 다시 투자하세요.
이전 장비는 현재 직업·계열 기준으로 이행하고, 던전은 1층부터 시작합니다.
재시작은 안전한 마을에서 이어집니다. 해금 층과 레이드 기록은 보존됩니다.
배포 ZIP에는 개인·검사용 세이브를 넣지 않습니다.
