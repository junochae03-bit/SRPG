# 선택 벤치마크 구현 계획

기준: SELECTED_BENCHMARKS의 선택 46개. 체크는 완료가 아니다. 기존 스킬트리 UI와 V06 작업을 보존한다. 미선택 C07/O05/O06/O10, 아군 AI·고용·자동 파티원, 턴제·명령 예약, 자동 매칭은 범위 밖이다. 배포·설치본 변경은 하지 않는다.

확정: 사용자가 방장 호스팅 방식을 선택했다. 최대 6명은 방장 포함. 방장만 월드 판정·거래·층 이동을 적용하며 참가자 ID는 통신 발신자로 결정한다. 개인 메뉴는 본인 입력만 막고 방장 틱은 계속된다. 싱글 메뉴 정지는 현행 유지. 솔로는 기존 진행을 유지한다.

1. N1 실시간 협동 세션: coop_session.gd와 방 UI. ENet 주소 접속, 방장 포함 6명 제한, 버전/저장 데이터 검증, 참가자는 입력만 전송, 개인 메뉴와 월드 틱 분리, 실패/이탈 복귀. 증거: tools/run_coop_check.py의 독립 프로세스 호스트·참가자 검사 및 기존 save/model 검사. 사람 승인 추가 없음. 진행 중.
2. N3 저장/소유권: 개인 저장 슬롯에 방장이 확정한 체크포인트만 저장, 타인 전리품 제한, 중복 요청 적용 방지. 첫 단계는 마을 참가와 방장 종료 시 최근 체크포인트 보존. 재접속/분리 귀환/파티 준비 이동은 후속 단계에서 명시적 원정 정책 구현. 증거: coop 검사 및 저장 실패/중복 요청 검사. 사람 승인 추가 없음. 대기.
3. N2/C01~C06/C08~C10: 인원별 적/무력화/다운과 구조, 고정 방향 돌진 벽 충돌, 역할 편성, 대체 방어 해법, 적 도감 연결·화면 밖 위협. 기존 소환 AI는 직접 조작 효과로 재설계하며 기존 스킬 보존 원칙의 예외를 정확히 기록. 증거: combat/monster/coop 회귀와 대표 실제 화면. 대기.
4. E01~E10: 방 목적·사건·채집·휴식·환경·준비/귀환 보고. 시드/지역/가중치를 데이터화하고 기존 던전 생성기 확장. 증거: 여러 시드 연결/진입/중복 보상/저장 회귀. 대기.
5. G01~G09/U01~U11: 개인 시설/연구/길드 성장, 목표/조건/도감 연결, 정보 출처, 분할·실패 보호·배율·음량·저장 안내. 기존 구현 중복은 차이만 구현. 증거: 각 UI 실제 화면 및 거래/저장 회귀. 대기.
6. O01~O04/O07~O09: 목표 수량 제작·큐·개인 소모 정책·창고, 전투/파밍 설정, 보급·마모·수리. 비용과 저장을 후보 사본에 적용 후 확정. 증거: 경제 보존·재시작·반복 요청·가방 한계 검사. 대기.
7. DB 재생성/원본 정합성 및 QA/DB 인계. 전체 선택46개별 증거를 기록하고 미완료를 분리한다. 독립 QA가 사용량 한도로 못 돌면 인수 미완료로 기록. 대기.

정책 대기/후속: 인터넷 NAT 자동 중계·호스트 이전, 장시간 연결 품질. 초기 LAN/주소접속을 인터넷 자동 매칭 완성으로 표현하지 않는다.

## 2026-09-12 작업 상태

- 사용자 확정: 친구끼리만 접속하며 자동 매칭과 공개 배포를 구현하지 않는다.
- N1의 첫 단계 구현·로컬 6인 검증 완료: 방장 생성/주소 참가, 6명 제한 및 일곱 번째 거절, 개인 메뉴 중 월드 진행, 공동 층 이동, 연결 실패·동시 퇴장 처리. 외부 네트워크·장시간 실전 검증은 남아 있다.
- N3의 첫 단계 구현·검증 완료: 개인 전리품, 수문장 공동 해금, 중복 요청 방지, 저장 체크포인트·쓰기 실패 복구, 방장 확정 거래 영수증. QA 지적에 따라 정상 퇴장 최종 디스크 저장 ACK와 종료 중 신규 참가 차단도 구현·통신 검증했다. 재접속·분리 귀환은 남아 있다.
- N2/C01/C10 1차 구현: 인원별 체력·무력화, 벽 충돌 빈틈, 플레이어 구조. 소환 효과는 플레이어 입력에 반응하며 자동 공격하지 않는다. 직업 조합별 장기 밸런스는 남아 있다.
- E07/E09: 파티 전원의 해금·준비와 다운 여부 검사, 장비·보급 준비 요약, 출발 전 몬스터 도감 연결을 구현했다. 귀환 보고는 아직 없다.
- C/E/G/U/O의 나머지 세부 확장은 아래 후속 상태를 따른다. 46개 전체 완료로 집계하지 않는다.
- DB의 `metadata.coop_rules`와 원본 코드·해시를 추가했다. 기존 스킬 사이드바 변경 및 별도 V06 에셋 작업은 보존했다.
- 세부 증거·미완료 경계는 [협동 기반 인계](COOP_FOUNDATION.ko.md)에 기록한다. 전체 회귀·QA·DB 인수 최종 결과는 해당 문서에서 관리한다.
- 이번 기반 단계의 최종 전체 회귀는 103개 그룹/391043개 검사 PASS, 런타임 345개 파일 SHA 일치. DB 최종 읽기 인수 및 QA 종료 중 참가 P1 해소 확인을 받았다. 아직 남은 선택 항목과 외부 네트워크 실전 검증은 위 대기 상태를 유지한다.

## 자유 탐사 단계와 추가 인계

- 2026-09-12 사용자는 갈림길·순환로가 많은 자유 탐사를 선택하고 전용 레이드 맵을 요청했다. 일반층 6종 재설계, 전용 레이드 3종, 채집·휴식·택1 제단의 첫 구현을 [탐사 인계](EXPLORATION_DUNGEONS.ko.md)에서 관리한다. E01/E02/E03/E06/E08의 일부이며 해당 범주 전체 완료는 아니다.
- 벤치마킹 담당이 사용자 선택에 따라 전달한 Stoneshard 14개를 개발 범위에 통합한다. 원본: `D:/SSRPG/Stoneshard_benchmark/SELECTED_BENCHMARKS.ko.md`. 기존 46개와 합쳐 60개의 별도 시스템으로 계산하지 않는다. 기존 실시간·솔로/인간 최대6인·아군 AI 없음 조건을 유지한다.

다음 구현 순서는 아래와 같다. 각 단계 시작 시 파일·실패 조건·검사 명령을 구체화하고 현재 검증된 상태 위에서 진행한다. 이번 인계만으로 새 릴리스나 별도 V06 변경을 하지 않는다.

1. SE01/SE02/SE03 → E01/E08: 이번 순환 구역·넓은 통로·레이드 분리 기반 위에서 지역별 공간 규칙과 선택 탐사 경로를 보강한다. 자유 탐사 선택을 유지하며 단일 주 경로를 강제하지 않는다.
2. SE04/SE05 → E01/E02/E08/E09: 단서로 여는 비밀방과 도구 선택 보상. 발견은 파티에 공유하되 주요 진행은 도구·특정 직업 없이 가능해야 한다. 공동 개방과 개인 보상·재전송·저장 경계를 먼저 검증한다.
3. SE07/SE08/SE09 → E09/C05/E08/O07/G01/E03: 출발 정보, 지역 위험과 별개인 인원 보정, 소문·지도 목표. 비밀 정보와 공개 정보의 경계를 정의한다.
4. SC05/SC06/SC08 → C02/C04/C06: 소음·경계, 적의 장판 회피·분산, 직접 설치 함정/투척. 자동 아군을 만들지 않고 6인의 소음·설치 수 상한 및 솔로 도주 경로를 검증한다.
5. SS01 → E06/E07: 거점 위치 선택. 파티 동의·잔류·저장 귀속부터 확정하며 현재 고정 휴식 지점을 이동식 거점 완성으로 세지 않는다.
6. SQ01/SQ03 → E10/G06/E02/E05/G09: 돈/평판 개인 정산 선택과 의뢰 결과의 지역 상태 반영. 중복 지급과 다른 동료의 선제 제출을 처리한다. 동적 교역 전체나 오프라인 강제 손실은 추가하지 않는다.

미선택 Stoneshard 부상·출혈·중독·피로 등 18개는 이번에 추가하지 않는다. 기존 Dungeon Settlers의 O08 등 선택은 유지한다. 위 후속 항목은 아직 대기 상태다.

## 추가 구현 증거

- SE01/SE02: 일반층 80×80, 5종의 넓은 갈림길·순환 구조. 사용자가 거부한 교차 회랑 제거. 레이드 50×50 전용 전장 유지. 지역별 가중치·공간 규칙 SE03은 후속이다.
- SE04/SE05: 비밀방 단서 발견 공유, 도구를 통한 공동 개방, 개인 보상 및 중복 수령 방지. 도구가 없어도 주요 경로는 진행 가능하다. 모델 604개·실제 화면 9개 검사 통과. 실제 6인 통신에서 개방 지형과 개인 수령을 검증했다.
- SE07/E09/C05 일부: 공개 생태권 몬스터·수문장, 층 목표·보상 종류, 개인 보급·장비, 파티 준비 상태 표시와 몬스터 도감 연결. 실제 화면 검사 628개 통과. 실제 생성된 비밀방 좌표·보상 추첨은 공개하지 않는다.
- U02 일부: HUD 세부 능력치는 실제 전투 계산 및 직업 버프를 참조한다. 탭·상단 여백·실제 창 맞춤 32개 검사 통과. 모든 기여분의 출처 분해는 후속이다.
- QA 직업 빌드: 20직업×5방향 미리보기, 기존 투자 규칙과 SP 예산 내 적용. 1385개 모델 검사, 적용 및 연결 종료 UI 8개 검사 통과.
- QA 무력화: 성공 6초 기절/종료 후 60초 잠금, 교전 범위 일치, 낮은 공격력 직업 무력화 보정. 1231개 무력화 검사와 18개 실제 레이드 교전 검사 통과. 2.5배 요구량과 보정 상한 1.65는 개발 조정값이다.
- 이번 추가분의 전체 회귀 및 DB 관리 최종 인수는 진행 중이다. 이전 단계의 전체 검사 수치를 새 변경의 증거로 사용하지 않는다.
