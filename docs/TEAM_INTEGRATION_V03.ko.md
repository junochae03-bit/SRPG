# V0.3 작업 간 인계

사용자가 배경·장비·이펙트 원화를 다른 프로젝트 작업에서 제작하므로, 메인 기능은 `publish/SRPG-v03`에 격리했다. 기준은 V0.2/main `6e6e6bb`이며, 원래 `publish/SRPG`의 진행 중 수정과 원본 팩은 보존한다.

## 스킬 이펙트: 통합

**“다양한 스킬 이펙트 만들어줘”** 작업에서 18계열 VFX와 갤러리·검사를 인계받았다. 갤러리와 사신 실제 전투 캡처를 확인했다. 검격·화염·얼음·번개·카드·사슬·독·치유·소환 등이 서로 구분된다.

새 렌더러·카탈로그·갤러리를 가져오고, `active_skills.gd`와 `job_combat.gd`는 V0.2와 비교하여 시각 메타데이터 변경만 선택 병합했다. 그 위에 무력화의 시전 예산과 실제 명중 처리를 유지했다. VFX 이벤트 수를 피해 횟수로 계산하지 않는다. 담당에게 통합 위치·기준 커밋·무력화 계약·DB의 skill ID/랭크 구조를 공유했다.

- [갤러리·실행·검사 방법](SKILL_EFFECTS.ko.md)

## 배경: 원화와 독립 미리보기 확인

**“너는 다양한 배경 스프라이트 만들어”** 작업의 6테마·36종 팩을 확인했다. 숲과 수정 동굴 원본을 열어 실루엣·색·스타일을 확인하고, 독립 Godot 미리보기의 36개 로드와 색상 키 제거를 검증했다. 상세한 렌더 결과와 잔여 가장자리 보정 사항은 인계 문서에 기록했다.

이 팩의 열 경계는 일정하지 않으므로 512×512 고정 자르기를 사용하지 않는다. `atlas_rect`와 잘린 그림 내부 `foot`을 사용해야 한다. `art_theme`는 현재 `terrain`과 구분하며, 원본 팩의 `project.godot`로 게임을 덮어쓰지 않는다. 용암·기계·성운·마력핵은 전용 원화가 아직 없는 연결 제안 단계다.

새 배경의 게임 배치·가림·발 기준점 검증은 후속 연결 작업이다. 사용하지 않은 원본 PNG·ZIP·독립 프로젝트는 이번 게임 릴리스와 Git 업로드에서 제외한다.

- [좌표 JSON](TEAM_HANDOFF_ENVIRONMENT.json)

## 장비·코스튬: 인계 확인

**“Rpg의 필수요소가 뭐라고 생각해”** 작업에서 완성 원화 6묶음·22시트·352포즈와 19개 아틀라스의 인계를 받았다. 실버캣 여름 의상 원본을 열어 16포즈 구성을 확인했다. 민트 3시트의 좌표, 프레임별 발 피벗, 색상 키별 머티리얼, 기존 코스튬 ID와의 연결 및 게임 재생 검증이 남아 있다. 파란 배경 시트는 현재 마젠타 전용 셰이더로 처리할 수 없으므로 원화 파일만 바꾸지 않는다. 이후 제작 중인 raven 묶음은 이번 확인 수량에서 제외했다. [파일별 크기·좌표·키·검증 상태](TEAM_HANDOFF_COSTUMES.md)

확인한 배경·코스튬 담당 범위에는 독립 장비 원화가 포함되지 않는다. 새 장비 원화의 완료 파일·직업·부위·등급 매핑은 확인되지 않았으며, 이번 버전은 검증된 기존 장비 그림을 사용한다.

도감·DB는 에셋 경로/아틀라스 영역/프레임/발 기준점을 별도 데이터로 노출한다. 새 그림을 연결할 때 직업 전용 무기·계열 공용 방어구·등급 테두리 규칙과 기존 아이템 ID를 보존한다. 미완료 원화를 완료·통합한 것으로 표시하지 않는다.
