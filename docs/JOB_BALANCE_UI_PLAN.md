# 직업 특색을 유지하는 밸런스·UI 개선

기준: GitHub 2732f1e. 5개 기본 계열, 15개 전직, 6개 장착 슬롯, 기존 저장 스키마를 유지한다. 직업을 같은 공격으로 통일하지 않는다. 새 던전·장비 체계·전직 증설·원안의 공중 전투 재현은 이번 범위 밖이다. 기존 원화와 장식 UI 아틀라스를 재사용하며 색만 칠한 박스로 화면을 대체하지 않는다. 별도 사용자 승인 체크포인트 없이 구현·검증한다.

| 단계 | 변경 | 증거 | 상태 |
|---|---|---|---|
| 1 | 최신 전직 소스에서 실제 단일/다수 대상 전투, 자원 소모, 생존/회복, 소환 지속 측정. 직업별 역할과 문제 기록 | Godot tests/job_benchmark.gd 기준 측정 JSON, 기존 tests/jobs.gd | 완료 |
| 2 | job_balance.gd의 공통 시전/표시 수식. 직업별 계수·다단 피해·소환·방어·회복 랭크 성장과 과도한 중첩/자원 공백 수정 | 전후 측정, 직업 자원/5랭크/강화/지원 실제 효과 검사 | 완료 |
| 3 | 성장 UI를 이름·해금·랭크·연결선·검색·경로가 있는 직업별 트리로 복원. 실제 현재/다음 효과와 6슬롯 관리, 장식 그림 프레임 | tests/job_ui.gd 합성 입력, tests/visual_jobs.gd 실제 화면 | 완료 |
| 4 | 직업 역할·자원·대시/시전 정보를 알아보기 쉬운 HUD에 배치, 6슬롯 간섭 제거. 기본 도적/격투가 초반 기술 보완 | 15직업 시각/입력, 초반 1~30 성장 검사 | 완료 |
| 5 | 전체 회귀·저장 복원·Windows 실제 실행, 변경/밸런스 근거 문서, 사용 파일/해시 갱신. 최신 코드 및 로컬 플레이 파일 동기화 | 전체 게이트, 전후 비교표, 독립 프로세스·그래픽/저장 검사 | 완료 |

피해 측정은 같은 레벨·능력치 예산·스킬 투자 예산·장비, 동일한 지형과 방어를 사용한다. 근접/원거리/다수 대상/지원 역할을 따로 해석한다. 고정 시나리오 수치로 재미나 모든 빌드의 동등함을 보장하지 않으며, 계수 조정 근거와 시나리오 한계를 기록한다.

완료 증거: [최종 검증](VERIFICATION_V011.json), [전후 수치](JOB_BENCHMARK_V011.json), [사용 안내](PLAY_CURRENT.ko.md). 전체 7,860개 검사, Windows 15전직 렌더/복원, 실제 이동·6마리 처치·재시작, 패키지 해시를 확인했다. 로컬 소스와 실행 파일을 동기화했고 기존 저장 파일 3개는 해시가 같다.
