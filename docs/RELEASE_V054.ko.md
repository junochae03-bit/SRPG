# 스텔알피지 V0.5.4

스킬트리 탐색과 전투·인벤토리 편의성을 개선한 싱글 플레이 버전입니다.

- 스킬 계열 전체 보기, 액티브·랭크 표시, 선행 스킬 이동과 추천 성장 경로
- 퀵슬롯 실제 효과·재사용 시간·룬 소모 툴팁
- 가방 정렬, 장비 포함 17개 능력치 상세 창, 대장간 착용 장비 우선 표시
- 회피 거리 확대와 긴 프레임의 벽 관통 방지, 도적·시프 단검 근접 판정
- 사냥꾼 늑대 4프레임 및 소환수 크기·발 위치·프레임 경계 정리
- 유지 효과 시간, 캐릭터 주변 룬, 굵은 치명타·피해 숫자 표시
- 화살·마법탄 발사 높이, 화살촉·깃·잔상과 발사 섬광 개선
- 허수아비 기록 10초 자동 초기화, 초상화 캐시 및 DB 원본 추적 수정

## 다운로드

게임 실행은 Windows ZIP을 풀고 `StelRPG.exe`를 실행하세요. Database ZIP은 DB 관리용이며 플레이에 필수는 아닙니다. 검사 저장이나 미사용 V06 원화는 패키지에 포함하지 않습니다.

기존 캐릭터를 이어가려면 게임을 종료하고 기존 `saves` 폴더를 백업한 다음 새 실행 파일 옆으로 복사하세요. 이전 V0.5.3 릴리스도 유지합니다. 문제가 생기면 이전 버전과 백업한 저장으로 돌아갈 수 있습니다.

## 검증 범위와 남은 작업

이번 버전 변경의 병합·푸시는 추가 검증 없이 진행했습니다. V0.5.4 Windows 빌드와 실행 파일 검사는 아직 완료하지 않았습니다. 장시간 사용자 플레이·청음, 모든 외형의 정밀 발사점, 완전한 직업별 빌드 프리셋과 미확정 밸런스는 후속 작업입니다. 온라인 멀티플레이는 포함하지 않습니다.
