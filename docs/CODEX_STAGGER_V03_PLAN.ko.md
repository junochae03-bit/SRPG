# V0.3 · 모험 도감/DB와 보스 무력화

기준 main 6e6e6bb / V0.2. 이번 버전은 개인용 싱글 플레이이며 실제 온라인 멀티플레이는 후속 단계다. 새 배경·장비 원화·스킬 이펙트 제작은 사용자 지정 다른 작업에서 진행한다. 여기서는 기존 사용 에셋으로 도감을 구성하고 다른 작업의 파일·매핑·검증 상태를 공유한다.

## 구현 계약

- 게임 실제 Content/Equipment/World/Abyss/DropTables를 읽는 `game_database.gd`. 장비 2,500 등급 조합, 몬스터 기본형과 10층 보스, 100층 출현, 독립 드랍 확률과 보스 확정 추가 드랍, 직업별 스킬/선행/랭크 값을 조회한다. 숫자를 별도의 수작업 표에 중복 기입하지 않는다.
- 게임 내 B 도감: 장비·몬스터·드랍·스킬 탭, 검색/필터/페이지 이동, 원화 미리보기와 읽기 쉬운 상세. 성장 포인트를 쓰지 않는 열람 화면이다. 열면 다른 메뉴처럼 전투가 멈추고 닫으면 복구된다.
- 개발용 JSON 및 SQLite DB를 같은 런타임 데이터에서 생성한다. FK/고유 ID/확률 범위/스킬 부모/계열 착용 관계를 검사한다. DB 설명과 재생성 명령을 제공한다.
- `boss_stagger.gd`는 HP 피해와 별도의 무력화량을 계산한다. 스킬별 낮음/중간/높음 등급과 랭크 성장, 기술 보너스 `1 + 0.60*T/(T+60)`(T에는 장비 옵션 포함). 기술의 기존 쿨타임 효과도 유지한다.
- 보스 일반 무력화 게이지, 누적 성공 시 공격 중단·넘어짐·피해 기회, 회복/재무력화 유예. 레이드 HP 구간에 제한시간 무력화 패턴, 성공과 실패 결과를 분리한다. 실패는 회피 가능한 강공격으로 만들고 개인 플레이에서 즉사 판정을 강요하지 않는다.
- 다단·지속·투사체·소환수는 실제 적중에만 기여하며 시전 예산을 나눠 중복 산정과 무한 무력화를 막는다. 무력화 피해의 출처는 이펙트 재생과 분리한다. 기본/강공격에도 작은 기여를 주되 기술 능력치 증가는 스킬 무력화에 적용한다.
- UI/DB 공용 API: `BossStagger.skill_profile(node, rank, player={})` → `base`, `value`, `grade`, `multiplier`를 포함한 Dictionary. 보스 상태는 `e.stagger` Dictionary로 노출하고 HUD는 해당 상태를 읽는다. 담당 간 구체 필드는 구현 전에 공유한다.
