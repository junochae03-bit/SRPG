# 6스탯 런타임 이관

기본 능력치를 위력·활력·견고·신속·정밀·특화로 전환한다. 구조는 사용자 확정이며 아래 수치는 기존 설계 DB의 초기 계수를 채택한 것이다. 3차 전직과 강화 미정 정책은 포함하지 않는다. 소스 연결과 실행 검증은 구분하며 최종 검증 기록은 메인 통합 결과를 따른다.

## 계산

투자와 착용 조건을 충족한 장비 옵션을 합산한다. 점감 비율은 `x / (x + 60)`이다.

| 능력치 | 효과 |
|---|---|
| 위력 | 물리·마법 공격력 각각 점당2 |
| 활력 | 최대 HP 점당8, 받는 기술 회복 최대15% 점감 |
| 견고 | 물리·마법 방어력 각각 점당2, 일반 피격 경직 최대20% 감소 |
| 신속 | 공격/이동/시전 속도 최대40%/20%/25% 점감 |
| 정밀 | 치명 확률 최대15%p, 치명 배율 최대0.30 점감 |
| 특화 | 현재20직업의 실제 기술/자원에 제한적으로 적용 |

시전 속도는 준비 시간만 나누며 최소0.1초다. 원래 즉발은 즉발로 유지하고 강공격·차지·궁극기 시간은 바꾸지 않는다. 채널 지속과 타격 간격도 변경하지 않는다. 견고는 일반 피격 경직용이며 다운·잡기·넉백 거리를 줄이지 않는다. 활력의 회복 배율은 기술 HP 회복만 대상으로 하며 물약·부활·마을 전회복·흡혈과 분리한다.

치명타는 기존 두 확률을 합성한 뒤 정밀을 더하고 최종85%로 제한한다. 기존 두 배율 중 큰 값에 정밀을 더해 최종3배로 제한하고 한 번만 판정한다. 실제 타격과 UI는 combat_stats.gd의 동일 값을 사용해야 한다. 구 기술 스탯의 모든 기술 쿨타임 감소와 모든 직업 무력화 증가는 제거한다.

## 저장과 장비

개인 저장 외피 schema_version7을 유지하고 별도 stat_schema_version2를 사용한다. 구 투자 기록은 stat_migration.old_stats에 보존하고 한 번만 비운다. 레벨당3점과 기존 생성 포인트 예산은 그대로이며 별도의 환급 화폐를 추가하지 않는다. 새 버전으로 저장한 투자는 재로드 시 유지한다. 저장 검증은 구 버전과 신 버전의 허용 키를 구분하고 버전·정수·유한값·총 예산을 확인한다.

기존 옵션 ID와 장비 ID, 수량, 강화 수치를 보존한다. focus/fortune은 위력, vigor는 견고, breath는 신속, guard는 특화로 계산한다. 범용 호환 함수는 같은 장비의 구 힘/마력을 높은 값 하나로 합친다. 기존에 없던 원시 장비 스탯 필드나 임의 옵션 생성 시스템을 추가하지 않는다.

장비 전용 특수 스탯18종은 이번 차수에 생성하지 않는다. 제작/연금/확률형 강화/재료 획득 등 미구현 연결을 먼저 준비해야 하며 롤풀은 활성화하지 않는다. 기본 능력치의 정밀 등과 장비 전용 손재주/탐색/지능은 서로 별개다.

## 직업 특화

stat_specialization.gd가 공통 계산을 제공하고 job_balance.gd/skill_scaling.gd가 실제 시전과 미리보기 프로필을 함께 계산한다. 동일 기술이 여러 조건을 만족해도 피해 특화를 중복 곱하지 않는다. 궁극기는 제외한다.

| 직업 | 실제 연결 대상 |
|---|---|
| 기본5직업 | 기본 액티브 피해·회복·방어/보호막 |
| 탱커 | 스킬 무력화25%, 보호막15% 점감 |
| 마검사 | 룬 비용이 있는 피해 기술25% 점감 |
| 검사 | 자기 공격 강화 기술 효과15% 점감 |
| 소환술사 | 소환수 타격20%, HP15% 점감 |
| 원소술사 | 준비 시간이 있는 원소 기술 피해25% 점감 |
| 치유사 | 기술 회복/보호막20%, 공격 지원 버프10% 점감 |
| 저격수 | 실제 관통 투사체 사격·차지 피해25% 점감 |
| 헌터 | 출혈20%, 출혈 대상 처형15% 점감 |
| 탐험가 | 일반 적 제어 시간10% 점감; 속도 지원 연결은 별도 확인 |
| 시프 | 현재 방어 감소/취약 보정10% 점감; 독 피해는 독 시스템 도입 후 |
| 사신 | 일반 강공격 및 heavy 기술 피해25% 점감, 중복 적용 금지 |
| 도박사 | 현행 패 정산 피해20% 점감; 7장 포커 설계를 구현한 것은 아님 |
| 인파이터 | 현재 몰아침0~10스택 비례 피해, 특화 최대20% 점감 |
| 브레이커 | 일반 강공격·차지 기술·패링 반격25% 점감 |
| 무도가 | 연무 finisher 피해25% 점감 |

## 파일 소유와 검증

DB 담당은 성장/생성/스탯 UI·장비 호환·저장 검증과 순수 프로필을 담당한다. simulation.gd는 stat schema 복원·persistent·recalculate만 변경한다. 메인은 player_combat.gd/job_combat.gd/active_skills.gd/skill_effects.gd의 실제 치명·피격·회복·조건부 특화 호출과 운영 DB를 연결한다. 아트와 패배 초기화, 공통 스냅샷은 DB 담당이 수정하지 않는다.

character_stats_v2.gd는 실제 피해/HP/방어, 곡선과 시간 예외, 구 저장 환급/재저장, 아이템 보존, 허위 스키마 거절,20직업 매핑을 검사한다. progression_v02와 character_creation_v04 등 기존 회귀 검사도6스탯 계약으로 갱신한다. 메인의 엔진 실행 슬롯과 조율해 실행하며 검사 전 적용 완료를 주장하지 않는다.
