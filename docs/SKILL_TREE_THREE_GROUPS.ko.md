# 스킬트리 세 계열 표시

2026-09-13. 기존 스킬 구성을 유지한 채 화면을 세 계열로 통합하고, 선택한 기술의 행동·효과를 이름 아래에 표시한다.

- `skill_presentation.gd`의 `TREE_GROUPS`와 `tree_group()`은 표시 전용이다. 검사 계열은 검술·돌파·수호이며 20직업마다 이름을 구분한다. 기존 회피 계열의 자원 회복·방어·제어 특성은 세 번째 표시 계열에 배치한다.
- 원본 다섯 cluster, 스킬 ID, concept_id, 효과, 투자 비용, 랭크, 선행·배타 조건 및 저장 형식은 그대로다. 다섯 빌드 미리보기와 추천 경로도 유지한다.
- 처음 열면 세 계열이 가로 스크롤 없이 함께 보인다. 세로 탐색과 계열 선택·확대·검색은 유지한다. 아이콘 아래 투자 랭크, 액티브 위 표식을 표시한다. 기술 이름은 선택 상세와 마우스 툴팁에서 읽는다.
- 서로 다른 계열의 연결선은 선택·마우스 강조·경로 보기에서 표시한다. 여러 단계를 건너는 선은 아이콘 사이 여백으로 우회한다. 실제 선행 기술로 이동하고 투자하는 동작은 기존 규칙을 사용한다.
- 선택 상세는 기술 이름 → 유형·투자 단계 → 짧은 설명 → 선행 조건 → 배우기/강화 → 수치 비교 순서다. 설명은 원본 effects_text/description에서 가져오며 전체 효과·대가·시너지는 상세 스크롤에 유지한다. 설명 높이에 따라 아래 영역을 배치하며 능력치·직업 탭에서는 숨긴다.

## 확인 범위

Godot 실제 렌더링의 `skill_tree_ui_v04`, `skill_clarity_v052`, `ui_v01`과 순수 규칙의 `skill_build_v04`, 세션 투자의 `skill_build_session_v04`를 검사했다. 20직업·1,510노드의 탐색 전후 규칙 정의 동일성, 모든 스킬 설명·아이콘·랭크의 가림, 선행 이동, 배타 조건, 투자·회수, 6개 슬롯 배치를 포함한다. 로그는 `runtime/three-groups-*.log`에 있다. 이는 변경 범위 검사이며 V0.6 전체 배포 검사를 다시 수행했다는 의미가 아니다.

실제 1920×1080 화면: `artifacts/skill-clarity-v052-warrior-entry.png`, `artifacts/skill-clarity-v052-gambler-entry.png`.

DB 재생성 시 이전 커밋의 JSON과 33개 본문 영역 전체가 동일하고, metadata는 원본 SHA256 외 동일함을 확인한다. DB 표의 cluster를 표시 인덱스 0~2로 바꾸지 않는다. QA 및 DB 관리의 읽기 리뷰를 받았고 최종 검증 결과를 인계한다. 이번 변경으로 설치 EXE나 게시된 V0.6 릴리스를 교체하지 않는다.
