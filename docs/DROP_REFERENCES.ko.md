# 메이플DB 드롭 참고 · 2026-09-09

사용자가 지정한 사이트의 몬스터/아이템 상세 페이지를 직접 확인했다. 아래는 사이트에 표시된 값이며 스텔알피지의 실제 적용 확률과 구별한다.

| 상세 페이지 | 확인한 드롭 확률 예 |
|---|---|
| [마스터 크로노스](https://mapledb.kr/search.php?q=4230115&t=mob) | 톱니바퀴 50%, 하얀 포션 1%, 가넷 원석 0.2%, 미스릴 스케일러 0.01%, 골든 모울 0.006% |
| [바이킹](https://mapledb.kr/search.php?q=8141000&t=mob) | 돛 60%, 깃발 20%, 하얀 포션 3%, 흑수정 원석 0.5%, 호프만 0.01%, 일비 표창 0.006% |
| [이블윙즈](https://mapledb.kr/search.php?q=1382007&t=item) | 주니어 발록 0.1%, 비틀/다크 스톤골렘/예티 각각 0.006% |

반영한 구조: 몬스터마다 다른 아이템 표, 흔한 재료·보급품·희귀 장비의 빈도 차이, 아이템별 독립 확률 판정. 독립 판정이므로 여러 물건이 동시에 나올 수 있고 확률 합계가 100%일 필요는 없다.

개인용 짧은 원정에 맞춘 스텔알피지 확률은 별도로 설계했다. 위 0.006% 등의 희귀 확률을 그대로 적용한 게임이라고 표시하지 않는다. 무기는 기본 공격/연습용 장비로 시작할 수 있으므로 획득 전에도 전투가 가능하다. 실제 테이블은 game/data/drop_tables.json과 GDD에 기록한다.

게임 코드가 웹사이트를 호출하지 않으며 원본 사이트의 아이템 이미지나 데이터베이스 전체를 복제하지 않는다.

실제 적용값은 [몬스터별 드롭표](DROP_TABLES_V05.ko.md) 및 game/data/drop_tables.json에 기록했다. v0.5 검증은 24종 각각 50,000회, 합계 1,200,000회 판정이며 0%/100% 경계와 독립 동시 드롭, 시드 재현을 포함한다.
