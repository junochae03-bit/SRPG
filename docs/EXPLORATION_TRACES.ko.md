# 설명문 대신 경험으로 익히는 갈림길

2026-09-13. 사용자가 요청한 탐사의 긴장감과 경험에 의한 길 선택 중 **시각 단서 부분**의 변경이다. 전체 벤치마킹이나 탐사의 재미가 완성됐다는 의미가 아니다.

## 실제 변경

- 분기점의 광석·씨앗·발자국 설명 문구를 제거했다.
- 완성된 광맥·수풀·상자를 축소 반복하던 표시를 지면 파편으로 교체했다. 파편에는 충돌·상호작용·보상 아이콘이 없다.
- 실제 통행 가능한 경로의 초입에만 최대 5개를 배치한다. 간격·크기·회전·횡위치를 시드로 달리하며, 가려진 모퉁이를 가로질러 이어 붙이지 않는다.
- 각각 현재 시야 안에 들어왔을 때만 그린다. 다른 파편이 보인다고 벽 뒤나 안개 속 파편까지 표시하지 않는다. 목적지 전체 경로나 숨겨진 적·보상 수치는 공개하지 않는다.
- 같은 종류의 흔적이 같은 종류의 장소로 연결되므로 도착 경험을 다음 선택에 사용할 수 있다. 광석은 채집, 나무 조각은 보급 장소, 낙엽은 식물 재료, 보라색 룬은 마력 장소, 마른 얼룩은 피의 제단, 큰 발자국은 정예 도전으로 연결된다. 이는 개발용 정의이며 길목에 설명문으로 띄우지 않는다.

## 사용 리소스와 DB

`game/assets/exploration_traces_v06/ground-traces.png`의 5개 셀과 `purple-rune-fragments.png`를 사용한다. 원래 시트의 푸른 마력 셀은 광석과 비슷해서 소비하지 않는다. 최종 마력 파편은 보라색 반원 형태다. 두 PNG는 built-in image_gen 생성 원본이며 실제 RGBA와 알파를 보존했다. 영역 좌표로만 잘라 읽는다. 투명 배경이 아닌 RGB 편집 시안은 배포에 넣지 않는다.

정확한 생성 프롬프트·도구·원본 해시는 `game/assets/exploration_traces_v06/PROVENANCE.json`, 영역은 `catalog.json`에 있다. 관리 DB의 `art:exploration_trace:*` 6개, 파일 2개, 적용 경로, `metadata.exploration_cues` 및 `exploration_cue_source_rules`로 추적한다. 기존 환경 108종 목록과 혼합하지 않는다.

## 관찰과 검증 범위

- 일반층 90개와 보스층 10개의 결정성, 실제 바닥, 연결 경로, 목적지 대응, 개별 시야 및 원본 알파 검사.
- 실제 1920×1080 화면에서 파편 확인. 동일 B12 분기점에서 광석/나무 조각을 동시에 본 뒤 각 길을 **입력 이동**하여 광맥/잠긴 보급 상자에 도착하는 두 동선을 기록했다. AI는 동작하지만 플레이어는 무적 fixture이므로 생존 난도나 사람의 판단 성공률을 입증하지 않는다.
- QA팀은 소스와 화면을 읽어 완성 오브젝트 축소 반복(P2), 광석과 마력의 시각 의미 혼동(P3)이 해소됐음을 확인했다. QA팀의 읽기 검토와 메인 작업의 엔진 실행 결과는 별도 근거다.

## 발견 간격 측정과 남은 작업

3개 시드 계열 × 일반층 90개, 각 주 경로와 두 곁길 경로를 합친 810개 동선을 측정했다. 실제 바닥의 AStar 경로와 벽에 막히는 시야를 사용하고, 적·장소·흔적을 **처음** 보는 시점 사이의 이동 거리를 측정했다. 기본 속도 3.8칸/초로 환산하며 전투·회피·길 찾기·조작 망설임 시간은 제외한다.

| 동선 | 경로 수 | 경로별 가장 긴 발견 공백의 중앙값 | 가장 긴 공백 |
|---|---:|---:|---:|
| 주 경로 | 270 | 3.38초 | 7.12초 |
| 곁길 포함 | 540 | 6.33초 | 10.76초 |
| 전체 | 810 | 5.50초 | 10.76초 |

긴 공백의 우선 조사 대상은 B77/seed611789, B28/seed223758, B82/seed651384다. 이 결과는 적을 더 뿌리거나 모든 길을 짧게 만들 근거가 아니다. 해당 동선의 불필요한 우회, 이미 본 공간을 다시 지나는 비용, 적 역할과 경계 행동, 발견 뒤 보상/전투의 차별성을 다음 작업에서 확인해야 한다. 최초 방문자의 단서 추론 성공률과 파티 탐사 중 전투 압박은 아직 별도 플레이 QA가 필요하다.

스탯 6종 개편 설계 DB는 이 변경과 별개로 인계됐으며 아직 런타임에 적용하지 않았다. 강화 성공률·실패 시 하락과 파괴 규칙도 별도 설계로 인계됐으며, 중간 등급 상한·실패 비용·기존 상한 초과 장비 이관은 사용자 결정 대기 항목이다.
