# V0.2 · 100층 던전 탐사와 장비 성장

직업의 자원과 공격 방식은 유지하면서 성장 규칙을 힘·내구·기술·민첩·마력으로 바꿨습니다. 기본 공격·강공격·회피의 HUD 버튼을 숨기고 스킬 6개를 3×2로 정렬했습니다. 일반 몬스터 크기를 키우고 퀘스트·능력치·장비 화면의 글자 여백과 줄바꿈을 다듬었습니다.

- 꽃바람 숲 튜토리얼 → 햇살 마을 → 100층 탐사. 10개 생태권과 10층마다 레이드 보스, 최종 목표는 100층 아스트라 공략입니다.
- 일반·레어·유니크·에픽·레전드리의 5등급 테두리. 무기는 현재 직업 전용, 방어구·장신구는 1차 계열 공용입니다.
- 레어 +2·유니크 +3에서 능력치 옵션, 에픽 +4·레전드리 +5에서 스킬 옵션 개방. 에픽 이상은 레이드 보스에서만 나옵니다.
- 15개 전직 무기와 상호작용 손 아이콘을 같은 화풍으로 제작했습니다. 직업 미리보기와 강화 조건·결과 표시를 수정했습니다.
- 이전 저장의 능력치 포인트는 전액 반환합니다. 기존 장비는 현재 직업·계열 기준으로 이행하며 K에서 새 능력치를 배분하세요. 기존 모험의 심층 진행은 1층부터 시작합니다.

Windows ZIP을 모두 풀고 StelRPG.exe를 실행하세요. Godot 설치는 필요 없습니다. 이전 저장은 게임 종료 후 saves 폴더로 복사하면 이어할 수 있습니다. 자세한 조작과 입장 조건은 패키지의 시작 안내에 있습니다.

기존에 정한 개인용 오프라인 싱글 플레이 버전입니다. MMORPG식 성장과 레이드 구조를 사용하며 온라인 동시 접속 기능은 포함하지 않습니다. 자동 측정 결과와 실제 조작에 따른 난이도는 다를 수 있습니다.

소스 회귀·실제 화면·기존 저장 이행·Windows EXE 실행과 재시작·15개 전직 복원·100층 진입과 완료 기록 복원을 검사했습니다. 전체 100층의 처치·해금·저장은 소스 전투 모델 검사로 확인했습니다. 상세 수치와 검사 기록은 저장소의 docs/VERIFICATION_V02.json, docs/BALANCE_V02.ko.md를 참고하세요.

배포에는 실행 파일·PCK·안내·에셋 출처·Godot 라이선스만 포함합니다. 원본 추출물·사용하지 않는 파일·개인 및 검사용 저장은 제외했습니다. V0.1과 V0.1.1은 그대로 보관합니다.
