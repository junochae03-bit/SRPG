# 전리품으로 여는 시설 연구와 제작

2026-09-13. G02·G04·G05를 기존 마을 서비스에 연결한다. 대장간·연금술·여관에 기초와 후속 연구를 두고, 연구가 완료되면 해당 시설에서 새 제작법을 사용할 수 있다. 기존 강화·판매·조제·숙박 기능은 유지한다. 연구는 개인 캐릭터 소유이며 파티의 공동 자원을 차감하지 않는다.

| 시설 | 기초 연구 / 해금 | 후속 연구 / 해금 |
| --- | --- | --- |
| 대장간 | 탐사 도구 제작 / 광석으로 탐사 도구 제작 | 올가미 구조 / 광석·별씨앗으로 올가미 덫 제작 |
| 연금술 | 유인제 배합 / 유인 돌 제작 | 화염 증류 / 화염병 제작 |
| 여관 | 긴급 보급 꾸리기 / 회복 물약 2개와 탐사 도구 1개 | 전투 보급 꾸리기 / 마나 물약 2개와 공격 강화 물약 1개 |

연구에는 별씨앗·광석·정수와 금화를 사용한다. 세부 비용과 해금 후 제작 비용·출력은 `town_research.gd`의 `DEFINITIONS` 및 정본 DB `metadata.town_research`에 기록한다. 해금은 표시만 바꾸는 상태가 아니며, 호스트가 실제 제작 요청에서 연구 완료를 검사한다.

## 예약과 시간

캐릭터당 세 시설을 합쳐 현재 연구 1개와 다음 연구를 포함한 최대 3개를 예약한다. 선행 연구가 완료됐거나 앞에 예약되어 있어야 후속 연구를 예약할 수 있다. 같은 연구를 중복 예약하거나 완료한 연구를 다시 예약할 수 없다.

기초 연구는 30초, 후속 연구는 60초다. 접속한 세션의 시간으로 진행하며 원정과 개인 메뉴 중에도 진행한다. 오프라인 시간은 진행하지 않는다. 솔로 메뉴에서는 전투 시뮬레이션을 정지한 채 연구 시간만 진행한다. 협동에서는 호스트만 시간을 계산하며, 클라이언트는 받은 진행 상태를 표시한다. 이탈 처리를 시작한 캐릭터의 연구는 더 진행하지 않는다.

예약 시 비용을 맡긴다. 취소하면 선택한 연구와 그에 의존하는 뒤의 예약을 취소하고 맡긴 재료와 금화를 모두 환급한다. 관계없는 예약은 유지한다. 환급 물품의 수량 한도나 가방 공간 때문에 전부 받을 수 없으면 연구와 자원 모두 변경하지 않는다. 취소는 해당 시설에서 수행하며, 다른 시설의 대기열도 볼 수 있지만 그 자리에서 취소할 수는 없다.

## UI와 검색

시설의 `시설 연구` 버튼으로 진입한다. 연구 이름과 해금 제작물, 비용, 시간, 선행 연구를 표시한다. 현재와 다음 연구는 공통 대기열에 나타나며 남은 시간이 갱신된다. `개인 연구 · 접속 중 진행 · 시설 공통 3칸`으로 시간과 소유 규칙을 안내한다.

현재 시설의 연구 이름 또는 정식 제작물 이름으로 검색하면 해당 연구를 선택해 볼 수 있다. 선택한 후속 연구의 선행 연구 버튼은 기초 연구로 이동한다. 완료된 연구에서는 실제 제작 비용과 모든 결과물을 확인하고 제작한다. 취소·시작·제작은 비용과 상태를 현재 권위 데이터로 다시 검사한다. 원격 요청 처리 중에는 다음 요청을 막는다.

QA에서 발견한 제목 높이 부족, 잘못된 아이콘 키, 상단 자원 표시 지연을 수정했다. 정식 `공격 강화 물약` 이름으로도 복수 출력 제작법이 검색되도록 했으며 해금명과 결과명을 통일했다. 이미지 대신 색만으로 연구 상태를 구분하지 않고 아이콘·연구 이름·현재 행동을 함께 표시한다.

## 저장·거래 경계

저장 형식 7의 선택 필드 `town_research`에 완료 연구 ID와 순서 있는 예약 ID·진행 시간을 보관한다. 필드가 없는 기존 저장은 연구가 없는 상태로 시작한다. 알 수 없는 ID, 중복, 선행 누락, 대기열 초과, 잘못된 구조, 음수·무한·NaN·이미 완료 시간을 가진 예약, 대기 중인데 진행 시간이 있는 항목을 거절한다.

현재 개인 상태를 깊은 복사한 뒤 연구 비용·제작 비용·다중 결과·환급을 모두 적용하고, 성공할 때만 실제 자원·가방·연구 상태를 변경한다. 두 번째 출력이 가방 한도를 넘으면 첫 번째 출력도 지급하지 않는다. 연구 시작·취소 재전송은 중복 비용이나 환급을 만들지 않으며, 제작 요청의 같은 네트워크 번호도 한 번만 처리한다.

새 층에 이동하거나 개인 저장을 복원해도 완료 연구와 예약 진행을 유지한다. 진행은 기존 정기 저장과 체크포인트에 포함하며, 완료 시 바로 저장 대상에 표시한다. 다른 플레이어의 스냅샷에서는 연구 정보를 제거한다. 협동 프로토콜은 10으로 구분한다. 원정 재접속·부분 귀환 전체 구현과는 별개다.

## 검증과 남은 연결

모델은 6개 연구의 선행·예약·시간·취소·환급 한도·해금 전 요청 거절·실제 제작·개인 소유·층 이동·실제 저장 파일·메뉴 중 전투 정지를 검사한다. UI는 세 시설의 초기·예약·완료 화면 9장과 실제 버튼·정식 이름 검색·자원 갱신을 검사한다. 정본에는 정의와 `valid`, `restore`, `matches`, `stage`, `use`, `tick`의 실제 원본 및 해시를 보관한다.

6인 ENet 검사는 개인 비용 예약, 중복 요청, 각자 체크포인트 저장, 완료 전파, 해금된 제작의 중복 보호를 확인한다. 게스트의 저장 확인 전에 테스트가 연구 시간을 앞당기지 않도록 확인 장벽을 사용한다. 완료 단계는 호스트의 실제 연구 함수를 30초 전진시키는 통제된 검사이며, 여섯 명이 실제 벽시계 30초를 기다렸다는 의미가 아니다. 정본 및 전체 검사 기록은 `docs/qa/town-research-verification.json`에 보관한다.

이 변경은 연구 기반 기능을 구현한 범위다. 부족한 연구 재료에 따른 탐사 목표 추천(G01), 첫 제작과 다음 도전 연결(G03), 길드 등급 확장(G06), 시설 성장 외형·대사(G09), 생산 대기열(O02)은 계속 후속 작업이다. 연구 대기열을 생산 대기열 완료로 계산하지 않는다. 외부 회선 장시간 플레이와 장기 경제 균형도 별도 검증이 필요하다.
