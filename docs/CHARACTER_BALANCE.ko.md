# 캐릭터 밸런스 · 스킬트리 기준 1차 적용

2026-09-10. 설계 담당: DB 관리. 사용자 지정 구조인 액티브·액티브 강화 모듈·캐릭터 행동 패시브·스탯 패시브를 실제 전투와 도감에 연결했다. 관리 DB 스키마는 5이며 게임 저장 형식 v7·빌드 형식 v2와는 별개다.

## 설계 기준과 적용 상태

**설계 목표**는 특정 액티브 숙련, 여러 기술을 잇는 행동 변화, 안정적인 캐릭터 스탯 성장 사이에 선택 가치를 만드는 것이다. 방어·회복·소환·기동·차지 직업을 같은 DPS에 맞추는 목표는 두지 않았다. 수치 조정은 현재 소스와 생성 DB에 적용됐다. 배포 클라이언트의 반영 여부는 이번 기록의 검증 범위가 아니다.

**실제 반영값**은 `job_balance.gd`, `constellation_catalog.gd`, `constellation_effects.gd`, `skill_node_roles.gd`가 제공한다. `metadata.character_balance`에도 적용 리비전과 계수를 저장한다. 이 문서의 전후 측정표는 실행 결과이며 승률이나 모든 빌드의 우열을 의미하지 않는다.

| 노드 역할 | 개수 | 적용 규칙 |
|---|---:|---|
| 액티브 | 224 | 직접 사용. 사용 슬롯·기력·쿨타임을 가진다. |
| 액티브 모듈 | 220 | 기존 강화 180개 + 대상 지정 연결 모듈 40개. `target_active_id`에만 적용한다. |
| 캐릭터 패시브 | 289 | 발동 조건·공격 전달 방식·자원 및 회복 규칙을 바꾼다. |
| 스탯 패시브 | 777 | 피해·치명타·공격 속도·거리·지속·기력 등의 수치를 높인다. |

`type`의 original/minor/notable/keystone은 투자 등급과 형태이며 위 역할과 별개다. `node_kind`, `effect_scope`, `target_active_id`, `concept_id`를 UI와 DB에서 공유한다. 20직업 모두 네 역할을 보유한다. 복합 패시브는 숫자 증가와 함께 새 행동을 열면 캐릭터 패시브로 분류한다. 예: 소환술사의 최대 소환수 증가, 평타 표적 지휘.

기존 노드 ID·선행 조건·1/3/6SP 비용·핵심 최대 2개·저장 배분을 유지했다. 변경된 40개 연결 노드는 전역 효과에서 지정 액티브 모듈로 전환했으므로 기존 투자자의 효과 범위도 바뀐다. 재분배는 기존 마을 회수 기능을 사용한다. 모듈을 먼저 투자할 수 있는 기존 경로도 유지하며, 실제 사용하려면 대상 액티브를 습득·장착해야 한다.

나머지 직업의 기본 공격·스킬 역할 계수는 유지했다. 탱커·치유사 본래 회복·보호막 계수도 유지하고 지원 스탯 투자로 성장하도록 했다. 브레이커 조정은 추적 연타로 변환한 충전기에 한정하며 일반 차지 빌드의 원래 피해는 유지한다.

## 전후 측정 조건

기본 5직업 LV30/29SP, 전직 15직업 LV60/59SP. 레벨당 능력치 3점 중 주 능력 55%, 내구 25%, 기술 12%, 나머지 민첩에 배분한다. 기본 장비를 사용하고, 같은 직업 안에서는 전후 레벨·능력치·장비·SP 배분·장착 슬롯·시드가 같다. 준비 장비나 무료 추가 SP는 지급하지 않는다.

4개 투자 전략 × 20직업 × 단일/5대상 × 시드 123/456 = 적용 전 320회, 적용 후 320회. 각각 30초 동안 실제 기력·쿨타임·소환수·상태 효과·별자리 지연 타격·보스 무력화 시간을 진행했다. 모든 배분이 저장 검증을 통과하고 SP를 전부 사용했으며 실제 피해가 발생했다. 전후 배분·슬롯 일치도 별도로 검사했다.

전략은 액티브 랭크 우선, 기존 액티브 강화 모듈 우선, 계열 행동 패시브 우선, 스탯 패시브 우선이다. 기본직은 기존 `_upgrade` 노드가 없으므로 앞의 두 전략 배분이 동일하다. 새 대상 지정 연결 모듈은 별도 `tree_balance` 검사에서 20직업 전체의 대상 격리와 발동 조건을 확인했다. 이 네 전략은 모든 직업 컨셉의 최적 빌드를 뜻하지 않는다.

표의 값은 두 시드 평균이며 `단일 DPS / 5대상 합산 DPS`다. 적 AI·입는 피해·회피·실제 거리 유지 비용은 제외하고 공격 위치를 고정했다. 특히 연타의 이동 이점, 지원의 파티 가치, 원거리의 생존 가치는 이 표로 평가할 수 없다. 단일 대상은 보스이고 5대상은 일반 적이므로 단일 값을 단순히 5배한 결과와 다를 수 있다.

브레이커 행동 패시브형의 5대상 DPS는 약 27% 감소했다. 액티브 집중·기존 모듈 집중형은 동일하다. 저격수·사신은 기존 모듈 집중 단일 DPS가 각각 약 8% 증가했다. 기본직 스탯 우선형은 피해 상승이 있지만 여전히 액티브 집중형보다 공격력이 낮다. 원소술사 스탯 우선형은 더 빠른 순환이 기력 소모와 시전 순서를 바꾸어 피해가 소폭 감소했다. 따라서 스탯 강화가 모든 전투 순환에서 DPS 상승을 보장한다고 보지 않는다.

기력 고갈 수치와 빌드별 배분은 아래 원시 결과에 기록한다. 지원 직업의 실제 회복·보호막·피해 감소는 `job_balance`의 실전 실행 검사로 검증한다. 적 공격을 포함한 장기 생존률, 자동 최적 순환, 파티·PvP, 모든 레벨/장비의 최적 조합은 이번에 측정하지 않았다.
