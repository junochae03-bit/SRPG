# 탐사 개선 및 남은 벤치마킹 작업

2026-09-13 탐사 개선 1차, 선택형 정예 도전과 개인 탐사 목표 후속 변경. 전체 벤치마킹 완료를 뜻하지 않는다. 선택 목록은 완료 목록이 아니다. 기존 QA 21건과 별개다.

## 이번에 구현한 범위

- 기존 80칸 던전 크기 안에서 출구로 향하는 주 경로와 앞쪽에 합류하는 보상 곁방을 생성한다. 모든 방을 청소할 필요는 없다.
- 중간 휴식은 주 경로에 둔다. 네 곁방에는 채집, 제단, 물약/재료 선택 보급 상자, 정예를 하나씩 배정하여 빈 곁방이 없도록 한다.
- 갈림길에는 광석/씨앗, 보급품, 마력, 큰 발자국의 짧은 환경 단서를 두며 목적지 전체 좌표는 노출하지 않는다.
- 달리기와 성공한 공격은 오디오 재생과 독립적인 소음을 발생시킨다. 소음 발생 1회당 최대 4마리가 통로를 따라 조사하고, 교전 후 시야를 잃어도 길을 찾아 귀환한다. 큰 소음은 직전 작은 소음의 제한에 막히지 않는다.
- 일부 지능형 적은 0.35초 반응 후 지속 피해 장판을 회피하고, 일반 적은 전투 중 간격을 벌린다. 숨은 함정·도발·레이드 패턴을 회피로 무효화하지 않는다.
- 장갑형 일반 적은 기존 무력화 예산을 이용한 연속 공격/강공격으로 방어를 무너뜨릴 수 있다. 같은 시전 중복 기여는 제한하며 레이드 무력화와 분리한다.
- 벽과 모서리에 막히는 파티 공유 시야. 현재 시야는 밝고 떠난 곳은 0.65초 후 어두운 지형 기억으로 남는다.
- 미니맵은 플레이어 주변을 확대하고 미탐사 지형을 숨긴다. 적과 전리품, 피해 숫자, 투사체는 현재 시야에서만 보인다.
- 시야는 셀 이동과 지형 변경 때만 다시 계산하고, 정지 후에는 렌더 캐시를 유지한다.
- 시야 기억은 현재 맵 인스턴스 기준이다. 저장·재접속 시 탐사 기억 보존은 아직 구현하지 않았다.
- 귀환 후 길드의 원정 기록을 열어 층별 누적 시간, 레벨업을 반영한 경험치, 처치, 금화·재료·물약의 순증감, 보유 중인 새 장비를 보여준다. 재접속 후 보존되는 영구 기록은 아니다.
- 보급 상태와 광석·의뢰 진행에 따라 다음 준비를 추천한다. 시설 버튼은 실제 위치의 바닥 경로와 미니맵 표시로 연결하며 원격 거래를 허용하지 않는다.
- 귀환 집계는 저장 성공 시 후보 시뮬레이션에만 반영한다. 개인별 원정 결과만 전송하고 내부 집계 기준과 다른 사람 결과는 스냅샷에서 제외한다.
- 가까운 시야 안의 적이 있으면 목표 패널을 미니맵 아래 한 줄로 축약하여 적을 가리지 않는다. 안전해지면 사용자의 수동 접기 설정을 복원한다.

## 후속: 선택형 정예 도전

- 기존 정예 곁방에 은닉품을 배치한다. 초기 적 23마리와 주 경로는 유지한다. 건너뛰어도 층 돌파에 영향이 없다.
- 정예를 처치한 뒤 재료 `2 + tier`를 회수하거나 추가 적을 부르는 도전을 선택한다. 곁방은 앞쪽 길에 합류하여 보상 때문에 입구로 되돌아갈 필요가 없다.
- 원정 시드에 따라 일반 적 4마리 또는 정예 1마리·일반 적 1마리로 갈린다. 완료 보상은 각각 정수 `3 + tier`, `4 + tier`다. 기존 생태계의 몬스터를 사용한다.
- 한 사람이 도전을 시작하면 파티 공통 전투가 한 번 열린다. 아직 선택하지 않은 동료의 확정 재료 회수도 닫히고, 모두 처치한 뒤 개인 정수 보상을 받는다. 이미 재료를 회수한 사람은 정수를 중복 수령할 수 없다. 협동 버튼과 선택 전 툴팁에 공통 선택임을 표시한다.

## 후속: 개인 탐사 목표와 제작 준비

- 원정의 문에서 층 선택과 탐사 단서를 나누어 표시한다. 지도 조각, 정예 은닉품 소문, 부족한 제작 재료, 다음 층 돌파 중 목적을 선택하면 실제 입장 층이 연결된다. 목표 해제도 가능하다.
- 단서는 바람이 새는 벽, 큰 발자국, 떨어진 씨앗과 광석을 가리킨다. 숨은 방 좌표나 보상 난수를 사전에 노출하지 않는다. 기존 전진 경로와 앞쪽 합류 곁방을 이용한다.
- 개인 목표는 마을의 권위 서버에서 검증한다. 공동으로 단서를 발견해도 보상 수령과 목표 완료는 개인별이다. 다른 사람의 개인 목표는 스냅샷에서 제외한다.
- 숨은 공간은 발견 → 개방 → 보상 회수, 정예 은닉품은 발견 → 선택 전투 → 회수 순서로 HUD에 표시한다. 기존 전투 중 한 줄 축약 동작을 유지한다.
- 강화·물약 조제·광석 정제·정수 합성의 실제 거래 견적에서 부족한 재료를 추천한다. 초반 숲에서 광석을 직접 얻을 수 없으면 씨앗으로 정제하는 경로를 제시한다.
- 모든 재료의 충족 여부를 확인하며, 금화·가방 등 실제 작업 조건은 별도로 계산한다. 귀환 추천은 해당 시설과 실제 실패 사유로 연결하고 성공한 거래 뒤에 작업 완료로 기록한다.
- 저장 버전 7의 선택 필드로 개인 목표를 보존한다. 기존 저장에 필드가 없어도 읽는다. 새 맵에서 유효하지 않은 중간 발견 단계는 초기화하고 현재 권위 맵에서 다시 관찰한다. 완료한 목표와 재료 목표는 유지한다.

## 후속: 지역 위험 선택과 탐사 밀도 기준

[지역별 위험 원정](EXPEDITION_RISK.ko.md)에서 SE08의 지역 상한·공유 출발 조건·역할 조합 증원·위험 보상을 연결했다. 지형 면적은 늘리지 않았다. 위험 효과와 보상은 원정의 문과 협동 방의 준비 버튼 앞에서 확인한다. 변경된 조건은 전원의 준비를 해제하고 새 변경 번호로 다시 확인한다.

사용자 기준은 넓이 자체가 아니라 발견·탐색·선택할 이유와 불필요한 왕복 감소다. 현재 실제 통행 셀을 10개 생태권×3개 시드로 표본 분석했다. 30개 맵의 120개 곁길은 원래 갈림길을 경유해 되돌아가는 경로보다 앞쪽 합류 경로가 11.31~68.43타일 짧았다. 8방향 최단 경로를 사용하고 모서리 통과는 금지했다. 표본의 출입구 최단 거리는 57.24~73.14타일, 통행 셀은 2,240~2,919개였다. 이는 이동 구조의 측정이며 탐사 재미나 모든 시드의 보장이 아니다.

남은 체감 문제는 기본 앵커·주 경로의 반복, 층마다 같은 네 보상 종류의 반복, 위험 병력이 있는 곁방을 고르기 전의 단서 부족이다. 다음 개선은 이 발견 순서와 구역의 목적을 바꾸고 실제 동선을 검사한다. 빈 면적 확대·모든 곁방 정리 강제·설명 패널 추가로 해결하지 않는다.
