# 설치 함정과 투척 도구

SC08과 SC05의 투척 소음 연결을 구현했다. 맵을 단순히 넓히는 대신, 발견한 적을 끌어내거나 길목을 묶고 적이 모인 위치를 공략하는 선택을 제공한다. 기존 소모품 1~4번 슬롯을 사용하며 별도의 전투 단축키는 추가하지 않는다.

| 도구 | 구입 가격 | 사용과 효과 |
|---|---:|---|
| 유인 돌 | 12 G | 바라보는 방향 5칸 앞에 던진다. 0.45초 뒤 착지 위치에서 반경 12칸의 소음을 낸다. 환경의 소음 보너스가 적용되며 파티 전체 청취 예약 4마리 상한을 유지한다. |
| 올가미 덫 | 35 G | 1.6칸 앞에 설치하고 1초 뒤 준비된다. 최대 30초 동안 반경 1.3칸에서 적의 피격 몸체와 접촉하면 한 번 작동한다. 피해 40 + 기본 공격력 50%, 일반 적의 속박 1.5초·둔화 4초. 보스는 속박·둔화 없이 무력화 피해 24를 받는다. |
| 화염병 | 45 G | 바라보는 방향 4칸 앞에 던지고 0.65초 뒤 반경 2.5칸에 한 번 폭발한다. 피해 60 + 기본 공격력 120%, 무력화 피해 16, 소음 반경 10칸. 아군은 맞지 않는다. |

피해는 기존 `PlayerCombat.hit`을 거치므로 직업·장비·적 방어와 치명타 등 기존 전투 규칙이 적용된다. 기본 공격력은 해당 직업의 기본 공격이 사용하는 공격력이다. 반경 판정은 기존 `EnemyHitGeometry.circle`을 사용해 몬스터 몸체 크기를 반영한다. 벽 너머의 적은 폭발 범위와 몸체가 겹쳐도 맞지 않는다. 레이드 보스와 수문장의 소음 유인 제한은 기존 규칙을 유지한다.

## 사용과 표시

- 상점 구매 목록, 구매 전 효과 설명, 수량 선택, 확정 거래와 영수증을 연결했다. 가방의 도구 버튼은 4개 슬롯 중 등록 위치를 선택한다. 가방을 열고 있는 동안 도구를 투척하지 않는다.
- 슬롯을 우클릭하면 보유한 6종 소모품에서 선택한다. 도구는 한 묶음 20개까지 한 칸에 보관한다.
- 도구 공통 대기 3초와 물약 공통 대기 2초는 별개다. 도구를 쓴 직후에도 회복 물약을 사용할 수 있다.
- 본인 도구는 청록색, 동료 도구는 파란색으로 범위·준비 진행과 덫 소유자를 표시한다. 적 공격 예고보다 먼저 그려 피격 경고를 가리지 않는다. 현재 시야의 바닥 마스크를 적용한다.
- 효과음은 기존 소리 중 착지·장비·폭발 소리를 재사용하며, 유인 판정은 오디오 볼륨과 무관하다. 전용 도구 그림은 새로 제작하지 않고 기존 의미 아이콘을 사용했다.

## 권한·수명·저장

호스트가 플레이어의 실제 방향과 위치로 사용 지점을 계산한다. 던전 층, 생존 상태, 소유 수량, 대기시간, 바닥과 직선 경로, 설치 수를 모두 확인한 뒤 도구를 만들고 1개만 차감한다. 잘못된 요청은 수량과 대기시간을 바꾸지 않는다. 플레이어당 동시 2개, 파티 전체 8개가 상한이며 투척 중인 도구도 포함한다. 작동 후 짧은 효과만 0.6초 남는다.

사망 시 즉시 도구를 지우며 이탈·연결 해제 시 다음 시뮬레이션 틱에서 정리한다. 새 지도는 별도 시뮬레이션이므로 설치 기록이 넘어가지 않는다. 도구를 설치한 뒤 주인이 사라지거나 지도에서 나가도 이미 사용한 수량을 환불하지 않는다. 스냅샷에는 현재 살아 있는 파티의 시야 안에 있는 도구만 포함한다. 적 위치나 탐사 안개를 도구 때문에 공개하지 않는다.

저장 스키마 7의 기존 `consumables` 사전에 새 3종의 허용 ID를 추가했다. 배치·비행·대기시간은 저장하지 않는다. 기존 저장은 그대로 읽으며 잘못된 ID와 음수·소수·20개 초과 수량은 거절한다. 새 도구를 담은 저장은 이전 클라이언트의 허용 ID 검사에서 거절될 수 있으므로 이전 버전으로 되돌려 쓰는 호환성은 제공하지 않는다. 협동 프로토콜은 6이며 프로토콜 5의 참가를 거절한다.

## QA와 검증

QA팀이 읽기 리뷰로 찾은 착지 소음 억제를 수정했다. 같은 소유자가 착지 직전에 강공격을 해도 소음 발생 셀이 다르면 착지 이벤트를 허용한다. 여러 참가자가 번갈아 던져도 파티 청취 예약 상한은 그대로 유지한다. 상점 카드의 기존 설명 툴팁과 함께 우측 구매 확인창에도 효과와 피해를 표시했다. QA팀이 변경 코드와 갱신한 상점 캡처를 다시 확인했으며 추가 확정 결함은 없었다. 엔진 검사 실행 주체는 본 작업이다.

- `tactical_tools`: 71개. 구매·수량·벽·지연·한 번 작동·아군 비피해·보스 면역/무력화·6인 설치 상한·이탈/사망·시야·저장·일시정지·강공격 직후 착지 소음을 검사했다.
- `tactical_tools_visual`: 21개. 실제 게임 화면에서 슬롯 등록·투척·가방 등록·상점 구매/영수증과 배치를 검사하고 `tactical-quickslots.png`, `tactical-tools-ground.png`, `tactical-tools-shop.png`를 캡처했다.
- 표적 실행: `runtime/combat-information-checks/20260913-065916`. 기존 `enemy_awareness` 22개와 `combat_information` 70개도 통과했다.
- 6인 ENet: `runtime/coop-check-1789250188259245600`. 각 참가자의 실제 신뢰성 요청을 중복 전송해 수량이 한 번만 줄고 6개 도구의 소유자가 보존되는지 검사했다. 7번째 참가 거절과 빈자리가 있는 방의 프로토콜 5 거절도 통과했다. 이후 착지 소음 셀 수정은 3종 환경의 표적 검사로 확인했다.

전체 회귀는 **135개 그룹 / 529,969개 검사 PASS**다. 실행 경로는 `runtime/v01-checks/20260913-070045`이며 검사 완료 시점의 런타임 383개 해시가 관리 목록과 모두 일치한다. [최종 검증 기록](qa/tactical-tools-verification.json)에 결과·DB·캡처 해시를 보관한다. 외부 회선에서의 장시간 6인 전투와 직업별 체감 밸런스는 아직 검증하지 않았다. 이 단계는 전체 벤치마킹 목표의 완료를 뜻하지 않는다.

## DB 관리 인수
