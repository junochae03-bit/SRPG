# V0.2: 심층 던전 · 5종 능력치 · 장비 성장

기준: V0.1.1 d627a6e. 기존 직업별 자원·공격 방식·6개 스킬 장착은 유지한다. 온라인 서버 구축은 별도 범위이며, 기존 개인용 플레이에서 MMO식 던전 탐사와 레이드 성장 구조를 구현한다.

## 결정
- 힘/내구/기술/민첩/마력, 레벨당 3점. 이전 4종 스탯은 전액 반환한다. HP는 레벨로 성장, 물리/마법 방어는 내구가 함께 강화한다. 기술 쿨타임 감소와 민첩 공속/이속은 점감식으로 상한을 둔다.
- 방어구·장신구는 1차 계열 공용, 무기는 현재 직업 전용. 기존 장비는 첫 이행 시 보유 직업 기준 귀속 정보를 채운다. 전직은 맞지 않는 장비를 가방으로 옮길 공간이 있어야 원자적으로 성공한다.
- 일반/레어/유니크/에픽/레전드리 5등급, 흰/파랑/보라/금/주황 테두리. 레어 +2, 유니크 +3, 에픽 +4, 레전드리 +5에 옵션 개방. 레어/유니크는 능력치, 에픽/레전드리는 해당 직업 스킬 효과 강화. 일반 재련 불가. 에픽 이상은 10층 단위 보스 전리품 전용.
- 새 모험은 꽃바람 숲 튜토리얼에서 시작한다. 숲 과제를 마치면 마을 도착, 이후 1~100층 던전 탐사. 기존 저장은 튜토리얼 완료로 이행한다. 각 층 수문장 또는 보스 격파로 다음 층 해금, 10층마다 레이드 보스, 100층 최종 보스. 마을에서 해금한 층 재입장 가능.
- 10개 생태권(지하 숲/수정/침수 유적/균사/용암/빙하/기계/황혼/별빛/마력 핵). 개체별 공격과 드랍 테이블을 유지하며 층·역할에 따른 HP/공격/보상 곡선, 후반 보스 다중 예고 공격을 적용한다.
- HUD 기본/강공격/회피 버튼 제거, 스킬 3열 2행. 조작은 유지. 퀘스트·성장·장비·거래 텍스트를 실제 이미지로 확인하고 NPC·스킬 아이콘의 기존 삽화 소재를 통일한다.
