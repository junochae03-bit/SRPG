# 현재 C 구현 → H2 적용 차이

정본: `SELECTED-H2.ko.md` / `H2-field-journal.png`. 현재 `game/project.godot` 버전 0.7.1의 소스를 읽어 대조했다. **엔진 실행·공용 런타임 변경 없이 작성한 소스 검토**다. 메인 진행 중 변경이 있을 수 있으므로 적용 직전 재확인한다.

## 이미 C에 들어간 부분 — 유지

- `combat_hud.gd`는 `job_identity_strip.gd`를 생성한다. 과거 `job_resource_hud.gd`는 상속 기반이며, 수정의 실제 진입점은 새 strip이다.
- `expedition_hud_chrome.gd`: 스킬 6칸은 `(500+i*90,803)` / 74×74, 직업 자원 하단은 y=786에 고정하고 높이에 따라 위로 확장한다. **후속 사용자 지시로 소모품은 화면 오른쪽 아래 논리24px 여백 고정**으로 변경됐다. `align_consumables()`가 담당하며 등록 창은 위쪽/오른쪽 정렬이다. H2 적용 때 중앙으로 되돌리지 않는다. 좌하단 메뉴는 `toggle_bag()` / `toggle_skills()` + stats/skills 모드로 이미 연결됐다.
- 독립 도감 버튼은 생성 후 숨김·입력 IGNORE로 처리돼 있다. 도감 데이터·B 단축키를 제거하지 않는다.
- `party_hud.gd`는 본인 제외 5명과 동적 버프 줄 높이를 처리한다. H2 이미지가 솔로 예시라는 이유로 되돌리지 않는다.
- `combat_hud.world_label_regions()`가 실제 직업 자원 영역을 포함하고, chrome/party가 각 입력 영역을 제공한다. 기존 자원 확장·파티 계산을 보존한다.

## 실제 차이와 파일별 범위

| 파일 | 현재 C 소스 | H2 변경 |
|---|---|---|
| `expedition_hud_chrome.gd` | `PERSONAL` 385×141, `panel()`이 개인·스킬·하단 메뉴에 같은 회색 종이 틴트와 직사각 테두리를 그림 | 개인은 작은 밝은 종이 카드, 스킬은 어두운 녹색 슬롯, 메뉴는 간단한 글자/구분선으로 역할별 표면을 나눔. 개인 축소 시 `align_personal`, 파티 앵커, personal_surface, world_regions를 함께 맞춤. `PROFILE` 상수는 남아 있지만 큰 옛 패널을 다시 그릴 필요 없음. |
| `combat_hud.gd` | `_draw()`가 사각 초상 프레임과 별도 LV를 직접 그림. 이름/직업은 밝은 외곽선 글자. 체력/기력 막대는 실제 상태 연동 | 작은 원형 초상 프레임, 이름+레벨/직업의 정돈된 줄, 종이 위 짙은 녹색 글자로 변경. 기존 초상 크롭은 넓은 모자/귀 보존 목적이 있으므로 원형 마스크에 맞춰 안전 여백 확보. 실제 HP/기력·후유증 툴팁 유지. |
| `combat_hud.gd` 목표 | `refresh_quest_presentation()`은 근거리 적이 보일 때만 자동 36높이 축약, 평상시는 112높이 종이창으로 복귀. 자동 축약 중 지역명도 숨김 | 던전 평상시에도 H2처럼 지역명+짧은 실제 목표를 읽게 함. 상세 진행·위험/환경·현재 접기 동작은 펼침/툴팁으로 유지. 단순히 높이만 줄이거나 목표 대신 ‘던전 탐사’ 제목만 남기지 않음. 위치·점유영역을 같이 갱신. |
| `action_circle.gd` + `combat_hud.refresh_slot_metadata()` | 그림을 그대로 그린 뒤 원형 hover/쿨다운, `rank_text`가 있으면 하단 표시. 빈/잠김 그림은 metadata에서 선택 | H2의 얇은 사각 틀·약한 빈 슬롯·명확한 잠김/사용불가·아이콘 위 실제키/쿨다운으로 맞춤. 랭크는 HUD 상시보다 기존 상세 툴팁에 유지. 그림 자체에 갈색 원형 배경이 들어 있다면 바깥 패널 색만 바꿔서는 H2가 안 됨: 실제 아이콘 경로를 확인하고 HUD 전용 표현으로 처리. 전역 아이콘 레지스트리 일괄 교체 금지. |
| `consumable_bar.gd` | 내장 `Slot._draw()`가 회색 사각 표면·아이콘·키·수량을 그림 | 4칸 기능·우클릭 picker·실제키·수량·불가 사유와 최신 우하단24px 배치·등록창 위/오른쪽 정렬을 유지하고 슬롯 표면/테두리만 H2 계열로 맞춤. |

| `job_identity_strip.gd` | 일반112, 도박사138/후보216 높이. 기본 직업도 역할 한 줄과 112높이 영역을 항상 사용 | 20직업 계산/카드 후보를 유지하고 H2 슬롯에 어울리는 표현만 조정. 기본 직업에 활성 시전·보호막·강화가 없으면 정보없는 여백을 접는 조건부 높이 처리가 필요. 자원 있는 직업을 통째로 숨기지 않음. 현재 `786-size.y` 앵커로 위 확장을 유지하고 소모품/클릭영역을 실측. |

`ui_art.gd` 공통 paper/decorate 기본값을 전역 변경하지 말고, 위 HUD 사용처 또는 전용 helper에서 H2 표면을 선택하는 편이 기존 제작·M1/M2·보스 화면에 미치는 영향이 작다. `main.gd`, 제작/세션/전투/DB 변경은 H2에 필요하지 않다.

## 검증 인계

기존 `tests/expedition_hud.gd`, `expedition_hud_preview.gd`, `combat_information_visual.gd`, `ui_legibility_v04.gd` 등을 필요한 변경에 맞게 사용한다. 현재 테스트 이름에 C/H2가 없더라도 실제 검사 범위를 확인하고 재사용한다.

필수 실제 화면: 기본 격투가 무상태/버프 활성, 마검사 룬, 도박사 현재패+후보, 5파티원+다중버프, 평상/전투/긴 목표, 생존→사체→생존 검사카드, 카드 내부 버튼 hover, 슬롯의 빈/잠김/쿨다운/자원부족과 긴 리바인딩 키. `settings_panel.gd`의 창 해상도 선택은 1920×1080 / 1600×900 / 1280×720이므로 Full HD와 최소 선택지 1280×720에서 텍스트/히트영역/보스바 충돌을 확인한다. 임의 창 크기를 더 작게 허용하는 별도 정책은 메인 기준을 따른다.

H2 선택은 전체가 유효하다. V071에 어느 부분을 포함하고 다음 패치로 어느 부분을 넘길지는 메인이 추적하며, 일부 스킨만 변경하고 H2 전체 완료라고 표시하지 않는다. E1/E2, 대상 근처 팝업, 신규 데미지 폰트는 제외한다.
