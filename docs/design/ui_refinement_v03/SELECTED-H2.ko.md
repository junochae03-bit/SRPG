# H2 선택·적용 정본

사용자 원문: “H2 개선안은 마음에 드네 근데 그건 적용해줘.”

사용자는 앞선 개선 요청이 배치 위치·구조 형식에 관한 것임을 정정했으며, 그와 별도로 H2의 적용을 명시했다. 따라서 H2를 취소하거나 H1로 대체하지 않는다. 기존 C HUD 배치·전 직업 아이덴티티와 합쳐 적용한다.

## 적용할 화면

기준 그림: [H2-field-journal.png](H2-field-journal.png).

최신 위치 예외: 메인 작업의 후속 사용자 스크린샷 지시로 **소모품 1~4는 화면 오른쪽 아래, 논리 24px 여백에 고정**한다. 등록 창은 슬롯 위로 열리고 오른쪽 끝을 맞춘다. 이 지시가 H2/C 이미지 속 중앙 소모품 배치보다 우선한다. `expedition_hud_chrome.gd::align_consumables()`가 현재 담당한다.

- 좌상단: 작은 종이 카드에 원형 초상화·이름·레벨/직업·생명력·기력. 얇은 테두리·짙은 녹색 글자와 절제한 종이 질감.
- 우상단: 기존 미니맵, 아래 지역명/목표를 짧게. 미니맵 옆 독립 도감 버튼 제거는 기존 확정대로 유지.
- 우측 임시 적 정보: H2 그림의 작은 종이 카드 형태. 처치된 대상은 이름·레벨·처치됨·도감/드롭을 간결하게 표시. 살아 있는 적의 HP·상태·공격 정보는 보존. 마우스가 카드 버튼으로 이동해도 조작할 수 있게 기존 대상 유지/해제 동작을 확인.
- 하단 중앙: 어두운 녹색 스킬 슬롯 6개, 얇은 밝은 테두리. 소모품 4개는 별도로 화면 오른쪽 아래에 고정한다. 활성/빈/잠김/쿨다운/자원 부족을 구분하고 반복된 큰 갈색 원형 틀을 정리.
- 좌하단: 큰 푸른 능력치 장식 패널을 덜어내고 능력치·스킬·가방 메뉴만 간결하게 표시. 상세 정보 기능은 기존 화면으로 연결.

## 기승인 사항과 연결

H2 그림은 기본 격투가 예시로 별도 고유 자원이 보이지 않는다. 마검사 룬·도박사 패/후보·인파이터 몰아침/회피·브레이커 기세 등 **20직업 표시를 삭제하지 않는다.** `../hud_selected_c_v02/class_identity.json`과 README의 공통 하단 자원 위치를 H2 스킨에 맞춰 유지한다. 6인 파티 표시·키 리바인딩·툴팁·입력 차단 영역·최소 지원 화면 가독성도 보존한다.

기존 초상화·캐릭터·미니맵 데이터·아이콘·데미지 폰트를 재사용한다. 이미지 생성으로 달라진 캐릭터 모습·지도 모양·게이지 비율·쿨다운 값은 실제 게임 데이터가 아니므로 복제하지 않는다. 미니맵 인접 버튼 제거와 달리 적 정보 안의 도감/드롭 및 도감 단축키는 유지한다.

M1/M2와 G1 혼합·G2 혼합·G3 B, 기존 보스 연출 규칙은 변경하지 않는다.

## 이번 선택에 포함되지 않은 것

H1, 은닉품 E1/E2, 직전 답변에서 제안한 ‘마우스 대상 근처에 적 정보창 배치’는 자동 승인으로 보지 않는다. H2 그림은 우측 임시 정보 카드 배치다. 은닉품의 배치·구조 개선은 별도 논의로 남긴다.

## 전달과 완료 구분

이 폴더는 확정 디자인·연결 범위다. 메인 개발에 H2 실제 적용을 요청하며, 런타임 구현·엔진 검증 완료 여부는 메인 결과로 확인해야 한다. 문서 확정만으로 게임 적용 완료를 표시하지 않는다.

소모품 위치 변경은 메인에서 실제 클릭·단축키·경계·등록 창 140건 PASS로 보고했다. 이 스레드는 `align_consumables()`의 오른쪽 아래 24px 및 등록 창 위/오른쪽 정렬 소스를 확인했으며 엔진 재실행은 하지 않았다. 해당 결과는 H2 전체 적용 완료와 구분한다.
