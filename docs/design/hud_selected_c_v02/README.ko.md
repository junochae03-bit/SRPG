# C 전장 몰입 · 전 직업 대응 · M1 + M2

사용자 선택 확정: **C 전장 몰입**, **미니맵 옆 도감 버튼/라벨 제거**, **마검사에 한정하지 않고 도박사 등 전 직업 아이덴티티 대응**, **M1 스킬 지도와 M2 장비 비교 모두 적용**.

이 폴더는 선택 내용을 반영한 제작 예시와 구현 전달 자료다. 게임 코드·세이브·DB는 변경하지 않았다. 하단 세부 배치와 직업별 상태 표현은 선택된 방향의 구체화이며, 새 전투 규칙이나 밸런스를 승인받은 자료가 아니다.

- [C 수정 시안](C-approved-no-codex.png): 기존 C 미술 시안에서 미니맵 옆 책 버튼과 도감 글자 제거. 기본 제공 image_gen으로 편집했다.
- [직업 전환·20종 갤러리](preview.html): 기본 5종 + 2차 15종, 평상/활성/특수 상태 총 60개 전환 예시. 수치는 표시 검토용이며 실제 저장 데이터가 아니다. 카드·룬·막대는 HTML/CSS로 제작했다.
- [데이터 연결표](class_identity.json): 현재 `Content.CLASSES` 20종과 일치하는 ID·이름·렌더러·소스 필드·예외.
- [M1/M2 미술 예시](../hud_options_v01/M-menu-layout.png): 두 메뉴 모두 선택 확정. 예시 아이템·스킬 값은 실데이터에 대입하지 않는다.

## 공통 배치

1600×900 논리 좌표 기준 시작안: 본인 좌상단, 본인 제외 파티 최대 5명은 그 아래. 미니맵과 목표는 우상단. 액티브 6칸은 하단 중앙, 아이덴티티는 그 바로 위. **소모품 1~4는 후속 사용자 스크린샷 지시에 따라 화면 오른쪽 아래 논리24px 여백에 고정**한다. 등록 창은 위로 열고 오른쪽 끝을 맞춘다. `expedition_hud_chrome.gd::align_consumables()`의 최신 위치를 유지하며 이 폴더의 과거 그림/HTML에 남은 중앙 소모품 배치보다 이 문서가 우선한다. 도박사의 후보 2장은 패 밑 별도 줄로 확장하며 패·합계·정산 정보를 유지한다. 슬롯 바닥 위치는 고정하고 추가 줄은 위로 확장한다. 캐릭터와 위험 예고가 있는 중앙 영역을 가리는 큰 장식 패널은 제거한다.

기본 아이덴티티 폭 약 600, 일반 높이 50~110, 카드 상태 최대 약 220을 시작점으로 실제 엔진에서 실측한다. HTML은 상태와 가독성 예시이며 그 픽셀을 Godot에 그대로 복사하지 않는다. 1600×900에서 후보 확장·4소모품·6스킬·보스바·파티 툴팁이 겹치지 않아야 한다. 작은 창은 지원 최소 해상도 정책에 맞춰 검증하고 텍스트를 무조건 축소하지 않는다.

키는 실제 리바인딩 결과를 표시한다. 예시의 Q/F/V/C/Z/X, 1~4, TAB, 평타 표기를 하드코딩하지 않는다. 쿨다운·사용 불가·선택·홀드·자원 부족은 숫자와 문양을 함께 사용한다. 공통 시전/강화/보호막은 직업 자원과 충돌하지 않는 보조 줄에 우선순위를 두고 상세 툴팁으로 이어진다. 시전 완료·취소·직업 변경·사망·재접속 때 이전 직업 표시를 제거한다.

좌하단 능력치/스킬/가방은 해당 상세 화면으로 연결하는 메뉴 의도다. 현재 `job_resource_hud.display_mode` 전환과 다른 행동이므로 기존 상세 화면/단축키를 재사용해 연결하고, 필요 상태 정보를 탭 전환으로 숨기지 않는다.

## 도박사 상세

현재 패 0~5장, 선택 테두리, 홀드 배지, 합계, 정산 배율, 덱·버림 수를 보존한다. 후보 2장은 현재 패와 별도이며, 합계·배율은 `JobCombat.hand_total(s.hand)` / `payout(s.hand)`로 계산한다. 예시 K♠+7♥=17, ×1.15. 후보 A♦/4♣는 확정 전 합계에 포함하지 않는다.

후보 선택 중 실제 액티브 사용 차단을 슬롯에 표시한다. TAB 후보 변경·평타 확정은 런타임 입력 규칙을 재사용한다. 후보가 없으면 TAB은 현재 패 선택에 쓰인다. 주사위는 `dice_time>0`일 때 값·잔여 시간을 표시하고 만료 시 숨긴다. 버림 구성은 패시브 조건, 다음 패는 `peek>=0` 등 기존 공개 조건을 따른다. 미공개 덱 내용을 UI가 계산해서 보여주면 안 된다. 0장/5장, 버스트, 블랙잭, 홀드 상태와 후보 취소/확정을 실제 엔진에서 추가 검증한다.

## 직업 데이터 기준

`game/scripts/content.gd`, `game/data/jobs/catalog.json`, `game/scripts/job_resource_hud.gd`, `game/scripts/job_combat.gd`, `game/scripts/job_balance.gd`의 현재 구현을 확인했다. 모든 직업의 필드와 표현은 JSON에 있다. 주요 예외:

- 마검사 최대 룬은 `6 + passive(p,0)`. 무조건 6칸이 아니다.
- 브레이커 피격 자원은 배열 합계가 아니라 시간에 따라 감소하는 `grit(p)` 결과다.
- 인파이터 몰아침과 대시 2회를 함께 표시. 무도가는 연무 3단계와 만료, 사신은 즉결 잔여 시간.
- 소환술사/헌터는 생존 동료별 체력. 헌터는 사망 시 사냥개 복귀 시간. 현재 소환체는 조준·이동에 따르는 구현으로 자동 공격 모드 버튼을 추가하지 않는다.
- 시프는 본인이 부여한 유효 표식만. 남의 표식·죽은 대상·만료 상태와 숨은 적 위치를 노출하지 않는다.
- 탱커·검사·원소술사·치유사·저격수·탐험가·기본 직업도 고유 문맥과 실제 보호막/강화/시전을 표시한다. 실제 없는 게이지를 꾸미기 위해 생성하지 않는다.
- 카탈로그의 탱커 ‘결의’, 소환술사 ‘계약 용량·자동 전투’ 설명은 현재 런타임과 차이가 있다. 이번 HUD 선택이 해당 시스템 신설을 의미하지 않는다. 메인은 실제 구현이 달라졌으면 연결표를 갱신한다.

## M1과 M2

M1: 선택 노드·관련 선행 경로를 강조하고 우측에 현재→다음 단계 값, 소모 SP, 투자 행동을 둔다. 최대 랭크는 다음 단계 대신 최대 상태를 표시한다. 잠김 이유와 선행 조건을 설명한다. 모든 직업의 실제 노드·선행 연결·검색·랭크·SP·장착·회수/초기화·확대/전체 탐색과 마을/전투 제한을 유지한다.

M2: 캐릭터/장비, 가방, 현재↔선택 장비 비교의 3영역. 120칸·7부위·분류·정렬·전체 목록 접근·기존 장착/해제 행동을 유지한다. 빈 부위·선택 없음·동일 아이템·장착 불가 상태를 구분한다. 해당 직업의 장착 제한, 고정/비율 옵션, 특수 효과를 실제 계산에서 가져온다. 증감 색만 쓰지 않고 +/−·수치를 함께 표시한다. 값이 모두 클수록 좋다는 가정(쿨다운 등)은 금지한다.

## 메인 적용 위치와 완료 확인

`combat_hud.gd`의 `codex_button` 구성·refresh·표시 복구 루프·레이아웃·입력 차단 영역에서 미니맵 옆 버튼을 제거한다. 사용자 요청은 버튼 제거이므로 `toggle_codex`, 기존 도감 화면/데이터와 B 단축키는 유지한다. 빈 버튼 영역이 클릭을 가로채지 않아야 한다.

`expedition_hud_chrome.gd`의 하단 배치·탭 동작, `job_resource_hud.gd`의 직업 표현을 공통 틀에 연결한다. `world_regions`는 확장/축소된 실제 패널·클릭 영역을 반영한다. 전장 클릭과 HUD 조작이 동시에 발생하지 않게 확인한다. 직업별 아이콘은 실제 스킬 ID/기존 아이콘 라이브러리를 사용하고 예시의 기호는 출하하지 않는다.

디자인 검증은 `verify_preview.cjs` 및 `verification.json` 참조. 게임 적용 뒤 메인이 20직업 전환, 특수 상태, M1 전 직업 지도와 M2 장착 비교를 실제 런타임으로 검증해야 한다. 이 전달에서 엔진 통합이나 게임 실행 검증을 완료했다고 주장하지 않는다.
