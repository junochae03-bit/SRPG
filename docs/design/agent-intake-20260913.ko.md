# 에이전트 설계 자료 인수 — 2026-09-13

이 기록은 네 설계 자료를 DB 관리 체계에 편입하기 위한 목록이다. **6스탯·새 제작법·신규 일반 몬스터40종의 런타임 적용 완료를 뜻하지 않는다.** 3차 전직은 제외하고 강화의 미정 항목은 보류한다. 이번 작업은 이 문서와 동명의 JSON만 작성했다.

## 정본 후보와 출처

각 폴더의 catalog.json이 설계 내용을 담고, 존재하는 catalog.sqlite는 같은 설계의 조회용 자료다. 파일별 크기·현재 SHA256·기록된 과거 출처해시는 동명의 JSON에 보존했다. 과거 출처를 현재 운영 정본의 출처로 바꾸지 않는다.

## 실제 격차와 필수 연결

현재 progression.gd의 NAMES는 힘·내구·기술·민첩·마력의 5스탯이다. equipment_catalog.gd의 옵션도 기존 스탯 키를 사용한다. 6스탯은 계산·전투/회복·장비·시트/툴팁·투자 UI·저장 이관을 연결해야 한다. 구 투자 포인트는 한 번만 환급하고 생성/레벨 예산을 보존한다. 같은 장비의 힘과 마력은 높은 값 하나를 위력으로 옮긴다. 특수스탯은 착용 장비만 활성화하며 생성 시 호스트가 확정하고 저장한다. 미구현 효과는 생성 풀에서 제외한다.

제작 대상500종은 기존 기본 장비 정의를 참조한다. crafted: ID는 설계행이며 existing_equipment_id가 실제 기본 정의다. 새 기본 장비500종을 중복 추가하지 않는다. 재료 등록·저장 허용목록·가방·획득 사건·대장간 UI·원자적 비용/산출물 처리가 필요하다. 대성공 추가 산출물의 용량도 미리 검증하고 재전송 중복 지급을 막는다. 구 affix_stat_value와 effect_policy는 새 스탯 계약으로 재대조한다.

추가40종은 개체 등록·지역 조우 후보·공격 예고/발동/후딜·4포즈·드롭 연결이 필요하다. 기존 밀도 안에서 후보를 대체하며 보스층에 추가 스폰하지 않는다. 전용 드롭120행과 범용 지역 재료표를 중복 판정하지 않는다. 속성 피해와 저항 파이프라인 확인 전 속성 효과를 반영 완료로 표시하지 않는다.

monster_ecology의 applied_snapshot은 오래된 출처의 기록이다. 현재 운영 수치로 덮어쓰는 입력이 아니다. C03 이전 방어 자세·치유 쿨타임12초 제안은 최신 방어/지원 정책과 개별 대조한다. 기존종의 저항20%·약점15%와 신규종의10% 값은 서로 다른 초기 제안이므로 자동 통합하지 않는다. 패턴 이름만으로 독·출혈 등의 효과가 구현되었다고 표시하지 않는다.

## 크기와 아트

normal_monster_expansion/size_assignments.json이 크기 최신 기준이다. 소형0.5배는 비교용 잠정값이고, 중소형1.2·중형2·중대형3·대형6·초대형10배는 사용자 지정이다. 동일 기준 캐릭터의 외곽 표시 높이를 사용하며 레이드 ID가 종별 지정보다 우선한다. 기존 display_height_px는 참고값이다. 표시 크기로 충돌·히트박스·사거리를 자동 확대하지 않는다.

92종 배정은 기존24종+추가40종+아트 후보28종이다. 아트 후보까지 스폰 허가로 해석하지 않는다. 레이드 지정은10개다. art_intake_priority.json 및 art_intake_regional.json은 신규20종80포즈의 당시 인수 기록이다. 당시 상태는 크로마키 아트 준비/원본 RGBA 대기였으므로 현재 제작팀의 새 납품을 대조해야 한다. 재사용 검토9종 가능/11종16포즈 보완 기록은 두 팩에서 중복 집계하지 않는다.

## 상호 참조와 보류

- 제작 설계의 stat_policy_reference는 character_stats_v2를 참조한다.
- 신규종 drops.item_id는 탐사전리품60종 또는 기존 재료 ID를 참조한다.
- 신규 출현행의 baseline_appearance_id는 기존 층별 실제 출현행이다. ID 유효성과 수치의 최신성은 별개다.
- monster_ecology의 고유전리품24종은 탐사 제작재료60종과 별도이며 연구/외형 용도 제안이다. 판매나 장비 제작재료로 자동 연결하지 않는다.

강화는 일반+3·전설+12와 목표 단계별 성공률90/80/70/70/70/70/30/30/30/10/10/5%가 확정이다. 성공률 구간 변경 시 상위 재료를 쓴다. 실패 시 조건부3% 파괴 판정 후 생존하면1단계 하락하며, 현재+7만 하락을 막는다. +7도 파괴를 막지는 않는다.

중간 등급 상한은 미정이며 +6/+8/+10은 제안이다. 실패 재료/금화 소모, 단계별 비용/성능, 기존 상한 초과 일반 장비 이관도 사용자 판단 보류다. 손재주 보정과 기타 구체 계수·수량·가격은 초기 제안값으로 표기한다. 이 보류 때문에 나머지 자료 이관을 멈출 필요는 없다.

## 이관 순서와 완료 기준

1. 현재 ID 대조와 저장 복사본, 일회 이관 표식을 준비한다.
2. 6스탯·UI·장비·저장 및 특수 옵션을 연결한다. 예산 보존, 반복 환급/재추첨 방지, 비착용 옵션 비활성을 확인한다.
3. 전리품 등록·획득·제작을 연결한다. 용량 실패 무차감과 중복 요청 무중복 지급을 확인한다.
4. 준비된 아트로40종의 조우·공격·드롭을 연결한다. 밀도와 중복 드롭, 예고/피해 시점을 확인한다.
5. 크기를 실제 장면에서 확인하고 C03·C04·C09 정책 회귀를 검사한다.
6. 메인이 운영 DB·SQLite·캐시·런타임 목록을 동기화하고 필수 검사를 마친 뒤 항목별 상태를 반영으로 변경한다.
