## 설계 기준

| 단계 | 레벨 | 내용 |
|---|---:|---|
| 기본 직업 | 1~29 | 전사·마법사·궁수의 기초 전투 |
| 2차 전직 | 30 | 기본 직업마다 3개 중 하나 선택, 총 9직업 |
| 3차 강화 | 60~99 | 선택 직업의 기존 스킬을 심화, 추가 직업 분기 없음 |
| 마스터 | 100 | 같은 직업의 완성 단계. 이번 상세 설계 범위에서 제외 |

**스킬트리에 액티브가 6개만 있는 것이 아닙니다. 다양한 액티브를 배우고, 그중 전투에 사용할 6개를 장착합니다.**

| 기본 직업 | 2차 전직 | 무기·도구 | 핵심 역할 |
|---|---|---|---|
| 전사 | 탱커 | 대형 방패·한손 무기 | 아군에게 대시해 공격을 대신 막는 보호형 전열 |
| 전사 | 마검사 | 검·룬 | 일반 공격으로 룬을 축적하고 유용한 룬 마법에 소비 |
| 전사 | 검사 | 검 | 자기 공격 버프를 조합하는 단일 보스 딜러 |
| 마법사 | 소환술사 | 마도구 | 소환수에게 버프와 명령을 제공하는 지휘형 마법사 |
| 마법사 | 원소술사 | 지팡이 | 캐스팅으로 강력한 원소 광역 공격을 수행 |
| 마법사 | 치유사 | 성물·마도구 | 힐과 버프로 아군을 강화하는 서포터 |
| 궁수 | 저격수 | 활 | 긴 사거리에서 캐스팅·충전으로 집중 사격하는 보스 딜러 |

| 궁수 | 탐험가 | 채찍·로프 | 짧은 사거리 광역 공격과 강한 CC·기동성을 갖춘 이질적인 전직 |

## 학습·장착·강화 규칙

### 1. 이번 문서의 규모

- 직업당 액티브 **12개**, 패시브 **6개**, 액티브별 3차 강화 **12개**를 설계했습니다. 직업당 총 30노드입니다.
- 9직업 합계: 액티브 **108개** + 패시브 **54개** + 3차 강화 **108개** = **270개**의 개별 효과를 명시했습니다. 기본 직업 기초와 100레벨 마스터는 이 수에 포함하지 않습니다.
- 액티브 12개는 이번 초안의 분량이며 최종 개수 상한이 아닙니다.
- 각 직업의 세 경로는 내부 투자 묶음입니다. 서로 섞어서 배울 수 있으며 추가 전직이나 배타 선택이 아닙니다.

### 2. 배운 스킬과 장착한 스킬

| 구분 | 규칙 |
|---|---|
| 학습 | SP와 선행 조건을 충족하면 여러 액티브 습득 가능 |
| 장착 | 배운 액티브 중 최대 6개 선택 |
| 기본 조작 | 일반 공격·강공격·회피·상호작용은 6슬롯 밖의 공통 행동 |
| 기존 Q/F/V/C | 기존 직업 액티브도 새 6슬롯 체계 안에 편입. Q를 별도 7번째 액티브로 두지 않음 |
| 패시브 | 배운 효과 상시 적용, 액티브 슬롯을 쓰지 않음 |
| 3차 강화 | 연결된 액티브의 효과 변경·확장. 추가 슬롯 없이 적용 |
| 재입력·연계 | 원래 장착 스킬의 같은 슬롯에서 사용. 별도 숨은 액티브 추가 금지 |
| 교체 | 마을·지정 안전 구역에서 교체하는 안. 전투 중 즉시 교체하지 않음 |
| 쿨다운 | 장착 해제·교체로 재사용 시간을 초기화하지 않음 |
| 장착 해제 | 해당 액티브의 유지 소환·지속 버프를 종료. 전투 외 사전 버프 후 교체를 통한 슬롯 우회 방지 |

6슬롯의 실제 키 배치와 모바일 UI는 별도 확정합니다. 이 문서에서는 슬롯 1~6으로 표기합니다.

### 3. 해금과 선행 조건

- 각 경로 액티브 A1~A4는 **30·38·46·54레벨**에 해금됩니다. 30레벨에는 세 경로의 첫 액티브가 열립니다.
- 각 경로 패시브 P1·P2는 **34·42레벨**에 해금됩니다.
- A1: 2차 전직 완료. A2: 같은 경로 A1 1랭크. A3: 같은 경로 A2 1랭크. A4: 같은 경로 A3 1랭크.
- P1: 같은 경로 A1 1랭크. P2: 같은 경로 P1 1랭크. 다른 경로 투자량은 요구하지 않습니다.
- 각 액티브의 3차 강화 E1~E4는 **60·70·80·90레벨**에 열립니다. 연결 액티브 3랭크가 필요하며, 다른 강화 노드 습득은 요구하지 않습니다.
- 액티브는 1랭크에서 기본 동작을 모두 얻고 2~5랭크에서 역할에 맞는 효율을 올립니다. 3차 강화도 1랭크에서 표의 추가 동작을 얻고 2~5랭크에서 효율을 높입니다.
- 랭크마다 피해·범위·재사용을 전부 동시에 높이지 않습니다. 기술별 주요 성장 축을 수치 설계에서 정합니다.
- SP는 2~100레벨에 1씩, 총 99를 지급하는 안을 유지합니다. 30개 전직 노드를 모두 5랭크로 만들려면 150 SP가 필요하므로, 기초 투자까지 포함해 선택과 집중이 필요합니다.
- 이 문서의 추천 조합은 장착 예시입니다. 6개의 해당 스킬을 배운 뒤 사용할 수 있고, 해당 강화의 해금 전에는 기본형으로 운용합니다.

### 4. 표 읽는 법

- 각 표는 한 내부 경로입니다. 왼쪽은 2차 액티브, 오른쪽은 **같은 액티브에 연결되는 3차 강화**입니다.
- ID의 앞부분은 직업, 가운데 T1~T3는 내부 경로, A는 액티브, P는 패시브, E는 강화입니다.
- 상세 선행 조건은 위 공통 규칙을 따릅니다. 예: T2-E3는 같은 T2-A3 3랭크와 80레벨을 요구합니다.

### 동작·밸런스 확인 사항

- 수호 도약은 아군·아군 소환수에게 사용한다. 대상이 없는 솔로 상황에는 자신이 지정한 가까운 지점으로 대시하며 자기 보호막만 얻는다.
- 수호의 맹세는 자신을 대상으로 지정하면 피해 분담 대신 약한 자기 피해 감소로 작동한다.
- 방패는 투사체·방향성 직접 공격을 판정한다. 바닥 장판·전방위 공격까지 모두 무효화하지 않는다.

## 2. 마검사

**계열:** 전사 → 마검사 · **무기:** 검·룬

**전투 정체성:** 일반 공격으로 룬을 축적하고 유용한 룬 마법에 소비

**핵심 자원·행동:** 적에게 적중한 일반 공격이 룬을 생성한다. 룬 마법·추가 피해·지속 피해는 룬을 다시 만들지 않는다. 룬은 전투 자원과 별도로 관리한다.

### 경로 1 · 룬 순환과 공격 강화

- 기본 사냥개와 기본 아이템 회수는 전직 시 무료 제공하며 슬롯을 쓰지 않는다. 영리한 회수 노드는 이 기능을 강화한다.

## 공통 전투 판정

### 피해·제어·보호

- 보스의 필수 패턴은 속박·기절·띄우기·강제 이동·도발로 무한 취소하지 않습니다. 저항한 효과는 명시된 약화 또는 무력화 축적으로 바꾸고 실제 적용 결과를 표시합니다.
- CC 연속 적용에는 적 종류별 저항·회복 시간을 둡니다. 탐험가의 강점은 제어 빈도와 선택지이며 영구 행동 불가가 아닙니다.
- 보호막은 남은 흡수량·갱신·중첩 규칙을 통일합니다. 피해 감소는 상한 또는 곱연산을 사용합니다.
- 피해 분담은 원본 피해마다 한 번만 계산합니다. 탱커끼리 맹세를 연결해 피해가 무한 순환하지 않도록 합니다.
- 같은 기술이 만든 추가 타격은 자기 자신을 다시 발동하지 않습니다. 룬·치명타·소환수 협동·출혈 소비에는 별도 발동 태그가 필요합니다.

### 캐스팅·충전·정신집중

| 방식 | 사용 직업·예시 | 운용 |
|---|---|---|

### 소환·동반자·슬롯

- 소환술사의 전투 소환수는 장착한 소환 기술과 계약 용량을 모두 요구합니다. 소환을 남긴 채 기술만 빼서 6슬롯을 우회하지 않습니다.
- 헌터의 사냥개는 직업 기본 동반자이므로 슬롯 밖에 존재합니다. 강한 공격·몰이·강화·철수 명령은 각각 장착해야 사용합니다.
- 단순 이동·대기·따라오기·아이템 회수는 기본 AI 행동입니다. 공격 버프·협동 타격이 있는 명령을 무료 기본 행동에 숨기지 않습니다.
- 소환수·사냥개가 없는 순간에도 일반 공격은 가능합니다. 사망·전장 이동·저장 복구 시 동반자 재구성 규칙을 갖춥니다.

### 파티 지원과 현재 싱글 플레이

- 이 문서는 아군 보호·지원 역할을 설계하지만, 현재 저장소에 파티·멀티플레이가 구현되어 있다고 가정하지 않습니다. 아군 대상 선택·투사체 차단·피해 분담은 별도 구현 항목입니다.
- 아군 판정은 플레이어·아군 NPC·아군 소환수를 구분해 데이터로 관리합니다. 파티 기능 도입 전에는 자기 자신·지원 가능한 아군 객체로 검증합니다.
- 치유사·탱커는 지원 행동을 유지하면서 혼자 필수 진행을 완료할 기본 공격·자기 보호 수단을 갖춥니다.
