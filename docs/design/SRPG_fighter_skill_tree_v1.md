# SRPG 격투가 스킬트리 v1

**인파이터 · 브레이커 · 무도가 — 2차 전직, 3차 강화, 마스터와 액티브 6칸 조합**

> 검토용 설계 문서입니다. 게임에 구현된 목록이 아닙니다. 직업명·전투 정체성·대시 특성은 대화에서 확정한 내용입니다. 개별 스킬명·자원 규칙·해금·수치는 이번 초안입니다.
> 손에는 글러브 대신 붕대를 사용합니다. 원화의 갈색 머리·남색 의상·붉은 허리띠를 공통으로 유지합니다.

## 1. 성장과 장착

| 성장 단계 | 내용 |
|---|---|
| 1~29레벨 | 기본 직업 격투가. 붕대 주먹과 기초 발차기, 기본 회피 학습 |
| 30레벨 | **인파이터 / 브레이커 / 무도가** 중 하나 선택 |
| 60~99레벨 | 선택 직업의 기존 스킬 강화. 직업은 더 나뉘지 않음 |
| 100레벨 | 같은 직업의 마스터 패시브 완성 |

격투가 추가 후 기본 직업 5개, 2차 직업 15개입니다. 이 문서는 격투가의 세 전직을 상세 설계합니다.

### 배우는 스킬과 사용하는 스킬

- 직업당 **액티브 12개 + 패시브 6개 + 액티브별 3차 강화 12개**. 합계 90노드이며 마스터 3개는 별도입니다.
- 배운 액티브 중 **6개를 장착**합니다. 12개는 이번 설계 분량이며 최종 개수 상한이 아닙니다.
- 기본 공격·직업 기본 강공격·기본 대시는 공통 입력입니다. 추가 돌진기·패링·태세·채널링은 장착 액티브이며 반드시 칸을 사용합니다.
- 기본 대시에 붙는 직업 특성은 무료 입력 기능입니다. 전용 액티브를 기본 입력에 숨겨 7번째 스킬로 제공하지 않습니다.
- 각 직업의 세 경로는 자유롭게 혼합하는 투자 묶음입니다. 추가 전직이나 배타적 선택이 아닙니다.
- 경로별 액티브는 30 → 38 → 46 → 54레벨 해금. 같은 경로의 직전 액티브 1랭크를 선행으로 요구합니다.
- 패시브는 경로마다 34 / 42레벨 해금. 같은 경로 첫 액티브 1랭크 필요.
- 액티브·패시브 최대 5랭크 초안. 3차 강화는 연결 액티브 3랭크와 각각 60 / 70 / 80 / 90레벨을 요구하는 1랭크 노드입니다. 이전 강화 노드는 필수가 아닙니다.
- 기존 99SP 안을 적용하면 전직 시 기본 격투가 투자분을 초기화해 재분배합니다. 마스터는 100레벨 자동 획득. 기본 격투가 상세 노드는 이번 범위 밖입니다.
- 전투 중 장착 교체 불가. 공격 취소로 스킬 비용·재사용 대기시간을 되돌리지 않습니다.

### 대시 규칙

거리 단위 H는 게임에 표시된 캐릭터의 기본 몸 높이입니다. 아래 수치는 테스트 시작값이며, **직업 간 짧고 긴 관계와 인파이터의 2단 구조가 확정 조건**입니다.

| 직업 | 확정 성격 | 테스트 시작값 | 충전·이동 제한 |
|---|---|---|---|
| 인파이터 | 짧은 쿨·짧은 거리·2단 대시 | 1회 1.2H, 2충전, 충전당 2.5초 | 연속 두 번 입력 가능. 소모 충전은 순차 회복. 2회는 점프가 아닌 지상 대시 |
| 브레이커 | 긴 쿨·긴 거리 대시 | 1회 3.6H, 1충전, 8초 | 한 번 길게 이동. 차지 도중 사용하면 차지 취소 |
| 무도가 | 짧은 쿨·짧은 거리 대시 + 다수 돌진기 | 1회 1.2H, 1충전, 2.5초 | 기본 대시는 단일 충전. 별도 장착 돌진기에는 각자 재사용 존재 |

기본 대시의 회피 판정은 시작 부분에만 적용하고 지속시간은 세 직업 동일하게 검토합니다. 브레이커는 거리가 길다고 전체 이동이 무적이 되지 않습니다. 공격 스킬의 전진 이동은 별도 명시가 없으면 무적이 없습니다. 벽을 통과하지 않고 유효 위치까지만 이동합니다.

## 2. 직업별 전투 규칙

### 인파이터 — 타격을 끊지 않고 몰아친다

- 기본 평타는 잽·스트레이트·보디·훅을 빠르게 잇는 연타. 기본 강공격은 짧은 준비의 어퍼컷이며 브레이커처럼 장시간 기를 모으지 않습니다.
- 고유 자원 **몰아침 0~10**. 직접 평타 적중 또는 공격 액티브의 첫 유효 적중에 1 획득. 액티브 다단히트는 사용 1회당 한 번만 획득합니다.
- 연환난타는 최초 적중에만 획득합니다. 기본 평타가 연속 적중해도 자원 획득 간격의 하한을 둡니다. 공속 증가로 프레임마다 자원을 생성하지 않습니다.
- 스택당 공격속도 증가, 최대 수치는 별도 조정. 적중이 끊긴 뒤 2초 유예 후 초당 1씩 감소하는 안으로 시작합니다.
- 기본 대시는 평타 순서를 짧게 보존합니다. 액티브의 후딜은 허용된 연결 구간에서만 대시로 취소할 수 있으며, 피해 판정 이전 취소는 해당 타격을 발생시키지 않습니다.
- 핵심은 낮은 단발 경직과 높은 연속 압박입니다. 모든 주먹으로 적을 멀리 밀어 콤보가 끊기지 않게 합니다.

### 브레이커 — 기를 압축해 한 번에 터뜨린다

- 기본 평타는 짧은 견제용 타격. 기본 강공격과 [축기 강타] 액티브는 버튼을 누르는 동안 기를 모으고 떼면 공격합니다.
- 고유 자원 **기세 0~100**. 직접 평타 적중은 소량, 패링 성공은 많은 기세를 획득합니다. 한 패링 사용으로 얻는 기세는 최대 한 번입니다.
- 차지 진행도는 해당 공격에서만 사용하는 별도 값입니다. 자연 차지만으로도 최대 차지에 도달하며, 기세가 없어도 직업이 작동합니다.
- [축기 강타] 시작 시 기세를 최대 30 소비해 초기 차지 구간을 단축합니다. 최고 차지 단계에는 최소 준비 동작을 남겨 사신의 즉시 강공격과 구분합니다. 수치·최소 준비 시간은 테스트로 확정합니다.
- 패링 성공 시 **반격권 1회** 획득. 다음 [축기 강타] 또는 기본 강공격의 직접 타격을 강화하고 시작 시 소비합니다. 차지를 자동 완료하지 않습니다. 상한 1, 재획득은 유지시간만 갱신합니다.
- 차지는 최대 단계 도달 후 짧은 유지 제한을 두고 자동 발사합니다. 무한 대기 공격은 불가. 차지 중 기본 대시로 취소하면 투입한 기세·반격권은 환불하지 않습니다.
- 자연 차지와 패링 어느 쪽으로도 큰 타격을 만들 수 있습니다. 적이 공격하지 않는 동안에도 기를 모아 적극적으로 공격합니다.
- 연출은 충분한 준비 → 집중된 한 번의 충격 → 분명한 자세 회복. 사신의 빠른 차지 생략, 무도가의 연속 강타와 구분합니다.

### 무도가 — 무거운 발차기를 빠르게 연결한다

- 기본 평타는 앞차기·돌려차기·뒤차기. 기본 강공격은 짧은 준비의 내려찍기이며 장시간 채널링하지 않습니다.
- 고유 자원 **연무 0~3**. 서로 다른 이름의 공격 액티브를 연속 적중시키면 각 사용당 1단계 상승합니다. 다단히트와 기본 평타는 단계를 올리지 않습니다.
- 다음 스킬을 잇는 유예시간은 첫 유효 적중에서 시작하며, 스킬을 정상 수행하는 동안 정지합니다. 종료 뒤 2초 안에 후속 공격 액티브를 적중시키면 연계 유지하는 안으로 시작합니다.
- 같은 이름을 연속 사용하면 단계는 유지하지만 상승하지 않습니다. 평타는 유예시간을 갱신하지 않습니다. 기본 대시를 쓰는 동안에도 유예시간이 줄어듭니다.
- [마무리]는 기존 연무를 시작 시 전부 소비하고 단계별 피해·경직 보너스를 얻습니다. 마무리 자체는 연무를 쌓지 않습니다. 0단계로도 기본 위력 사용 가능.
- [연결]은 타격 판정 이후 지정된 동작 구간에서 다음 스킬로 이어집니다. 적중 전 취소로 공짜 피해를 만들지 않습니다. 연계 속도는 빨라도 각 발차기의 무게와 자세 전환은 보입니다.
- 여러 돌진기는 서로 다른 이동거리·방향을 가집니다. 기본 대시 충전이나 무적을 공짜로 추가하지 않습니다.

## 9. 공통 판정과 검증

### 피해·자원·취소

- 원천 피해·공속·재사용·지속·피해감소의 확정 수치는 아직 없습니다. 이번 해금과 기믹을 먼저 테스트하고 같은 장비·레벨에서 비교합니다.
- 추가타·이펙트·패시브 발동은 기본적으로 자원을 만들지 않습니다. 문서에 명시된 직접 적중만 자원 판정.
- 기세는 평타·패링·기맥 정돈으로 획득. 자연 차지 유지 자체는 저장 기세를 생성하지 않습니다. 몰아침은 전투 중 감소 규칙, 기세는 전투 이탈 후 초기화, 연무는 연결 유예 만료 시 초기화.
- 자원 소비는 공격 시작 시 확정. 일반 빗나감·피격 취소로 환불하지 않습니다. 벽·유효 표적 검사에서 발동 자체가 거절됐으면 비용과 재사용을 시작하지 않습니다.
- 연환난타 최대 시간, 축기 최대 유지시간, 철벽 자세 유지시간을 유한하게 두고 무한 채널링을 막습니다.
- 패링은 유효 방향·판정 시간·공격 태그 모두 충족해야 합니다. 환경 피해·주기 피해·잡기·패링 불가 공격은 제외. 여러 적의 동시 공격은 방어 판정과 자원 발동을 분리합니다.
- 브레이커의 반격권은 사신의 즉결과 다릅니다. 피해 강화가 중심이며 자연 차지의 핵심 준비를 남깁니다.
- 직업 기본 강공격에는 직접 피해는 있지만 별도 액티브 고유 부가 효과를 주지 않습니다. 인파이터·무도가 기본 강공격은 전용 자원을 자동 소비하지 않습니다.

### 보스·이동

- 공중 띄우기·밀치기·다운에 면역인 보스는 피해와 경직 게이지 기여만 적용합니다. 경직 게이지가 없는 보스에는 추가 피해 없이 기본 피해만 적용합니다.
- 이동 스킬은 벽·낭떠러지·도착 공간 검사. 목표 사망 시 마지막 유효 방향으로 제한 거리 이동하되 맵 밖 추적 금지.
- 기본 대시는 이동 중 취소 규칙과 회피 판정을 하나로 정의해 직업별 스킬이 임의로 무적을 늘리지 않도록 합니다.
- 무도가 돌진 다수와 인파이터 2단 대시는 서로 다른 기능입니다. 무도가에 기본 2충전을 추가하지 않습니다.
- 장시간 보스 무적·컷신·맵 이동에서는 자원과 버프 시간을 일관되게 정지하거나 초기화하는 공통 전투 상태 규칙을 적용합니다.
