# SRPG 도적 계열 스킬트리 v1

시프 · 사신 · 도박사 / 2차 전직과 3차 강화 / 액티브 6칸 조합

> 검토용 설계안. 게임 코드에는 아직 적용하지 않았습니다. 직업 정체성은 대화에서 합의한 내용이며, 스킬명·세부 판정·해금·수치는 이번 초안입니다. 피해 계수, 재사용 대기시간, 지속시간, 사거리, 자원 소모는 플레이테스트로 확정합니다.

## 1. 성장과 장착

| 단계 | 규칙 |
|---|---|
| 1~29레벨 | 기본 직업 도적. 투척·회피·근접 공격의 기초 |
| 30레벨 | 시프·사신·도박사 중 하나로 2차 전직 |
| 60~99레벨 | 선택한 직업의 기존 스킬 강화. 추가 직업 분기 없음 |
| 100레벨 | 같은 직업의 마스터 패시브 획득 |

- 기존 전사·마법사·궁수에 도적을 추가: 기본 직업 4개, 2차 직업 12개. 인형사는 시프로 대체합니다.
- 각 직업 액티브 12개, 패시브 6개, 액티브별 3차 강화 12개: 세 직업 합계 90노드. 마스터 패시브 3개는 별도입니다.
- 각 직업의 세 경로는 투자 묶음이며 자유롭게 혼합합니다. 별도 전직이나 배타적 분기가 아닙니다.
- 습득한 액티브 중 **6개만 장착**합니다. 기본 평타·회피·사신의 기본 강공격은 공통 조작이며 장착 스킬의 추가 슬롯이 아닙니다. 히트·홀드·주사위 등 능동 패 조작은 반드시 슬롯을 사용합니다.
- 전투 중 장착 교체는 불가. 자동으로 슬롯 밖 스킬을 발동시키지 않습니다. 강화는 해당 장착 스킬에 부가됩니다.
- 각 경로 액티브 해금: 30 → 38 → 46 → 54. 앞 액티브 1랭크가 다음 액티브의 선행 조건입니다.
- 각 경로 패시브 해금: 34 / 42. 같은 경로의 첫 액티브 1랭크가 필요합니다.
- 액티브·패시브 최대 5랭크 초안. 3차 강화는 60 / 70 / 80 / 90레벨에 연결 액티브 3랭크를 요구하는 1랭크 노드입니다. 직전 강화 노드는 필수 선행이 아닙니다.
- 기존 99SP 초안을 따른다면 30레벨 전직 시 도적 투자분을 초기화해 재분배합니다. 마스터는 100레벨 자동 획득으로 SP를 쓰지 않습니다. 기본 직업 상세 노드는 이번 범위 밖입니다.

## 2. 핵심 전투 규칙

### 시프: 표식 → 순간이동 → 근접 약화 → 아군 강화

- 평타는 원거리 단검 투척. 전직 고유 특성으로 적중 대상에게 이동용 표식을 남깁니다. 기본 최대 표식 2개, 초과 시 가장 오래된 표식 교체. 표식 자체는 약화가 아니며 아군 버프를 만들지 않습니다.
- 순간이동은 장착한 이동 스킬로만 실행합니다. 표식 유지시간 안에 최대 이동거리·벽·도착 공간을 검사합니다. 죽은 대상이나 막힌 위치로는 이동하지 않습니다.
- 지정한 적의 뒤쪽 안전 지점에 도착하되, 공간이 없으면 가까운 유효 지점으로 보정합니다. 이동 가능 지점이 없으면 발동과 자원 소모를 취소합니다.
- 여섯 약화 스킬은 짧은 근접 공격으로 부여합니다. 원거리 평타는 견제와 진입 준비용으로, 디버퍼의 주력 피해는 근접 연계에서 나옵니다.
- 약화가 새로 적용되거나 해당 스킬로 갱신될 때 자신과 범위 내 살아 있는 아군에게 연결된 버프를 부여합니다. 한 번의 스킬 사용으로 여러 적을 맞혀도 같은 버프 발동은 1회입니다.
- 동일 버프는 지속시간 갱신, 수치 중첩 없음. 다단히트·출혈 주기 피해·패시브 전이·버프 자체는 추가 버프 발동을 일으키지 않습니다.
- 면역 대상에게도 해당 약화 공격이 유효 적중하면 버프 발동을 인정합니다. 무적·빗나감에는 발동하지 않습니다. 보스에게 약화가 적용됐다는 표시는 면역일 때 띄우지 않습니다.

| 디버프 | 판정 | 연결 아군 버프 |
|---|---|---|
| 둔화 | 이동속도 감소 | 이동속도 증가 |
| 방어 파괴 | 방어력 감소 | 방어력 증가 |
| 약점 노출 | 받는 피해 증가 | 주는 피해 증가 |
| 무력화 | 주는 피해 감소 | 받는 피해 감소 |
| 출혈 | 지속 피해 | 공격 적중 시 소량 회복: 아군별 발동 간격 적용 |
| 실명 | 일반 공격 명중률 감소. 보스 확정 패턴에는 미적용 | 회피율 증가: 회피 불가 공격에는 미적용 |

### 사신: 사슬 적중 → 위치 선택 → 차지 없는 강공격

- 기본 평타는 가벼운 낫 공격. 기본 강공격은 차지를 거쳐 최대 위력에 도달합니다.
- ‘포획 사슬’·‘추격 사슬’·‘되감는 사슬’·‘철쇄 투망’이 유효 적중하면 **즉결 1회**를 얻습니다. 기본 보유 상한 1, 재획득 시 지속시간만 갱신합니다.
- 즉결은 다음 기본 강공격 또는 [강공격] 태그 액티브 하나의 차지를 최대 위력으로 생략합니다. 시작 시 소비하며, 공격 동작·후딜·액티브 재사용 대기시간·비용은 생략하지 않습니다.
- 사슬 후 강공격 입력을 예약할 수 있습니다. 끌어오기 또는 추격이 완료된 뒤 공격이 시작됩니다. 자동 공격 강제는 없습니다.
- 끌어오기 면역 보스에게는 추격으로 대체합니다. 추격 경로가 막혔다면 이동만 취소하고 적중으로 얻은 즉결은 유지합니다. 빗나간 사슬은 즉결을 주지 않습니다.
- 한 사슬이 여러 적을 맞혀도 즉결 획득은 1회. 패시브 추가타와 사슬 시각 효과는 자원 생성 판정이 아닙니다.

### 도박사: 실물 덱 흐름과 블랙잭 정산

**한 벌 52장 → 현재 패 → 평타/정산으로 버림 → 덱 소진 시 재셔플**

1. 조커 없는 52장 한 벌로 시작하고 현재 패 2장을 받습니다. A는 합계가 21 이하가 되는 범위에서 11, 그 외 1. J/Q/K는 10점입니다. 무늬는 피해 배율에 영향을 주지 않습니다.
2. 평타는 플레이어가 선택한 현재 패 1장을 카드 투사체로 던져 버린 뒤 1장을 보충합니다. 선택하지 않으면 가장 오래된 비보관 카드를 사용합니다. 명중 여부와 관계없이 발사 때 카드가 소비됩니다.
3. ‘히트’는 버리지 않고 1장을 추가합니다. 현재 패 최대 5장. 따라서 평타는 패 장수를 유지하며, 히트만 장수를 늘립니다. 기본 2장 상태에서는 버스트가 발생하지 않습니다.
4. ‘홀드’는 카드 1장을 평타 자동 선택에서 제외합니다. 최소 1장은 버릴 수 있어야 합니다. 홀드는 정산 소비·재셔플을 막지 않습니다.
5. [정산] 스킬은 발동 시작 때 현재 패를 확정하고 전부 버린 뒤 새 2장을 받습니다. 공격 실패·중단에도 확정한 패를 되돌리지 않습니다. 다른 정산 스킬은 새 패를 사용합니다.
6. 덱이 부족해지면 현재 패와 처리 중인 패를 제외한 버림 더미만 섞어 보충합니다. 사용 중인 카드가 동시에 덱과 손에 존재하지 않습니다. 초기 패·보충·셔플 결과는 UI에 반영합니다.
7. 히트 직후 21 초과가 되면 버스트 표시 후 현재 패를 전부 버리고 2장으로 재시작합니다. 강화 보상은 없지만 평타 피해를 낮추거나 장시간 행동을 막지 않습니다. 버스트는 정산 스킬을 자동 발동하지 않습니다.
8. ‘컷 카드’는 기존 패 1장을 버리고 상단 2장을 확인, 1장을 손으로 받고 나머지를 덱 맨 아래로 보냅니다. 카드 복제·값 변경 없음. 보충 절차 중 필요한 셔플도 동일 규칙을 따릅니다.
9. 기본 UI: 현재 카드·합계·남은 덱 장수·버린 카드 목록·셔플 알림. 강화 패시브는 이미 공개된 기록의 집계를 돕고 미공개 미래 패를 공짜로 보여주지 않습니다.

| 정산 패 | 피해 배율 초안 | 부가 효과 |
|---|---:|---|
| 16 이하 | 1.00배 | 기본 스킬 효과 |
| 17 / 18 / 19 / 20 | 1.15 / 1.25 / 1.40 / 1.60배 | 강한 패 공통 이펙트 |
| 3장 이상 합계 21 | 1.85배 | 21 보너스 |
| 정확히 2장 A + 10/J/Q/K | 2.10배 | 블랙잭 전용 보너스 |

배율은 기본 피해에 한 번만 적용합니다. 21과 블랙잭 보너스는 중복되지 않습니다. 치명타·공격속도 버프와의 최종 상한은 별도 검증합니다.

주사위는 보조 버프입니다. 기본적으로 1개 결과만 유지하며 재굴림은 이전 결과를 교체합니다. 눈 1=공격력, 2=공격속도, 3=치명타 확률, 4=이동속도, 5=카드 투사체 속도, 6=받는 피해 감소. 지속시간·수치는 미확정입니다. 추가 시각 카드가 생겨도 실제 덱 소비를 늘리거나 별도 정산을 하지 않습니다.
