## 공통 규칙

- 검사·궁수·마법사 각 50개 노드: 액티브 12개 + 패시브 38개. 총 150개.
- 노드당 최대 3랭크, 학습·강화마다 1 SP. 사용 가능 SP = 캐릭터 레벨 − 1 − 전체 투자 랭크 합계(최소 0).
- 선행 스킬이 여러 개면 그중 하나를 1랭크 이상 배우면 연결 조건을 충족합니다. 선행 없는 노드는 바로 투자 가능합니다.
- 아래 단계는 화면의 왼쪽→오른쪽 위치이며, 별도 캐릭터 레벨 제한을 뜻하지 않습니다. 행은 화면의 위→아래 순서입니다.
- 학습한 액티브는 F/V/C 슬롯에 배치합니다. 기본 직업 기술 Q는 이 150개 노드에 포함하지 않습니다.
- 액티브 수치는 장비·패시브 보정 전 기준이며, 피해 배율은 공격력 대비 1회 기본 피해입니다. 실제 최종 피해는 전투 보정을 받습니다.
- 패시브의 랭크별 값은 해당 효과에 더하는 누적 기여량입니다. 감소·회복 등 적용 방향은 효과 설명을 따릅니다.

## 수치 적용 참고

- 기술 피해 패시브는 공격형 액티브 기본 피해 배율에 `(1 + skill_power 합계)`를 곱합니다.
- 범위·둔화·기절 패시브는 해당 수치에 가산됩니다. 둔화·기절이 원래 없는 기술에는 지속시간 보정만으로 상태 이상이 추가되지 않습니다.
- 기술 기력 절약은 소모 기력에서 차감하며 최소 5, 기술 대기 감소는 랭크 보정 후 대기시간에서 차감하며 최소 1초입니다.
- 데이터의 설명 문구와 코드 효과 키를 그대로 보존했습니다. 이 문서는 밸런스 변경안이 아니라 현재 구현의 목록입니다.
