# 전리품 등급·제작 연계 V0.7.1

현재 상태: DB 작성 및 정적 검증 완료. 게임 소비측 연결·실행 검증은 메인 개발에서 진행한다. 운영 DB·SQLite·캐시는 메인 통합 시 갱신한다.

## 범위와 호환성

- 재료 110종, 획득 규칙 200개. 기존 60종과 획득 규칙 130개의 ID·확률·수량을 보존했다.
- 기존 레어 장비 제작법 500개의 ID·비용·재료·효과를 보존했다. 이름만 새 표시명으로 맞췄다.
- 유니크·에픽·레전드리 제작법을 각 500개 추가했다. 총 2,000개 모두 기존 장비 정의를 사용한다.
- 연금술 80개: 지역마다 기존 소모품 조제 4개와 재료 정제 4개. 기존 연구·기본 제작법에 병합한다.
- 슬롯별 등급은 일반·레어·유니크·에픽·레전드리의 기존 5등급을 사용한다. 재료에는 rarity, grade_name, grade_color, uses를 명시했다.
- 이름 DB는 표시명만 교체한다. 스킬 1,510개 및 장비 기본 조합 500개의 ID를 유지한다. 확정된 전직명·효과·수치는 변경하지 않는다.

## 획득과 소비

| 추가 재료 | 등급 | 직접 획득 | 용도 |
|---|---|---|---|
| 정제 금속 | 레어 | 일반 몬스터 3%, 정예 20% | 2강 재료 |
| 강화핵 | 유니크 | 정예 4%, 수호자 10% | 7~9강 재료, 유니크 제작, 정수 정제 |
| 정수 | 에픽 | 레이드 20% | 10~11강 재료, 에픽 제작, 원핵 정제 |
| 원핵 | 레전드리 | 레이드 2% | 12강 재료, 레전드리 제작 |
| 레이드 증표·인장 | 유니크 | 레이드 100% | 모든 상위 장비 제작 및 상위 정제 |

위 신규 확률·비용은 초기 밸런스 제안값이다. 모든 신규 직접 드롭 수량은 1개이며 개인별 독립 추첨이다. 레이드 증표는 제작으로 얻을 수 없고, 상위 장비에는 해당 지역의 증표가 반드시 필요하다. 원핵을 정제로 얻더라도 실제 레이드를 우회할 수 없다.

기존 수집품 10종도 상위 장비·정수·원핵 제작 재료로 사용한다. 전 재료는 적어도 하나의 소비처가 있고 재료별 보관 상한 99개를 넘는 단일 제작 비용은 없다. 장비는 즉시 제작·성공률 100%, 연금술은 기존 개인 제작 대기열에서 성공률 100%로 처리한다.

## 강화 연계

목표 단계별 재료: 1강 원광 → 2강 정제 금속 → 3~6강 기존 핵 → 7~9강 강화핵 → 10~11강 정수 → 12강 원핵. 기존 핵과 강화핵은 같은 유니크 등급이지만 후자가 정제를 거친 상위 재료다. 장비 지역 티어에 맞는 재료를 사용한다.

이번 연결에서 사용할 현재 강화 어댑터는 기존 1~5강 비용(목표 단계 × 50골드, 목표 단계만큼 재료)을 보존하며 재료 종류만 교체한다. 이 경로의 기존 +5 상한·100% 성공은 새 확률형 강화 설계와 구분한다.

사용자 확정 설계는 별도 보존: 성공률 90/80/70/70/70/70/30/30/30/10/10/5%, 일반 +3·레전드리 +12, 실패 시 1단계 하락, 7→6 하락 방지, 실패한 경우에만 파괴 확률 3%. 중간 등급 상한, 실패 비용, 6~12강 재료 수량·금화, 기존 초과 강화 장비 이관은 미정이다. automatic_activation=false로 둔다.

## 메인 연결 계약

- `Data.recipes`: recipes 500개 + advanced_recipes 1,500개 병합. 행의 rarity/upgrade/amount를 사용한다.
- `Production.recipes`: alchemy_recipes 80개를 기존 기본·연구 제작법에 병합한다. level은 주문 및 예약 시 검사한다.
- `Equipment.make(type,tier,rarity,existing_equipment_id,affix,job)`의 실제 생성값을 사용한다. 에픽·레전드리의 공명은 기존 장비 정의 ID를 기준으로 정해져 미리보기와 지급 결과가 일치한다. 생성 후 `item.id`만 호스트가 발급한 새 고유 ID로 교체한다. 지급 ID를 기준으로 공명을 다시 계산하지 않으며, 정의 ID는 인벤토리 인스턴스 ID로 사용하지 않는다.
- `enhancement_materials.bands`는 목표 단계·장비 티어로 재료를 고른다. 미완성 확률형 강화 정책은 자동 적용하지 않는다.
- `content_names.monsters`는 선택적 표시명 덮어쓰기다. 몬스터 ID·드롭·스프라이트 대응은 보존한다.
- 현행 `mana_potion`의 효과는 MP가 아닌 기력 회복이므로 소비측 이름도 ‘기력 물약’으로 맞춘다. 실제 MP 기능이 적용되면 별도로 바꾼다.
- 재료에 기존 아이콘 키를 지정했다. 저장키 loot:*를 ore/essence 등으로 바꾸지 않는다.

## 명칭 방향

사용자 보완 기준: 명칭은 직업·동작·재질의 맥락에 맞고, 전체를 소리 내 읽었을 때 자연스러워야 한다. 외국어와 한국어를 기계적으로 결합하지 않는다. 예: 블리츠 권투갑 → 블리츠 글러브. 한자식 이름에 맞는 권갑·권투갑 표현은 개별 맥락에 따라 유지한다.

고전어·독일어 이름은 한글 음역으로, 한자식 이름은 한국어 독음으로 표시한다. 실제 한자·원어 표기가 없어서 현재 한국어 UI에서 읽을 수 있다. 한자식 조어는 게임 고유 이름이며 실제 고어 또는 일본어 관용구라고 주장하지 않는다. 일반 재료는 용도가 읽히게 두고 핵심 기술·후반 장비·전설 재료에 강한 이름을 배치했다. 장비 기본 이름은 기존 구조상 등급별로 공유한다.

| 구분 | 예시 |
|---|---|
| 라틴어 계열 | 이그니스, 룩스 아에테르나, 움브라, 포르투나 |
| 고대 그리스어·신화 계열 | 타나토스, 아이테르, 네메시스, 아이기스 |
| 독일어 계열 | 도너카일, 블리츠, 슈투름 |
| 한자식 창작명 | 공명절천검, 명부단죄의 낫, 삼원개벽의 홀, 백련무극 권투갑 |
| 레전드리 재료 | 영겁수림 원핵, 황동천구 원핵, 공허개벽 원핵 |

어휘 확인: [ignis 사전](https://atlas.perseus.tufts.edu/dictionaries/entry/urn%3Acite2%3Ascaife-viewer%3Adictionary-entries.atlas_v1%3Alat.ls.perseus-eng2-n21403/), [θάνατος 사전](https://atlas.perseus.tufts.edu/dictionaries/entry/urn%3Acite2%3Ascaife-viewer%3Adictionary-entries.atlas_v1%3Amiddle-liddell.perseus-eng2-n14966/), [Donnerkeil 사전](https://www.duden.de/rechtschreibung/Donnerkeil). 이들은 각각 불·죽음·벼락의 이미지를 고르는 근거로 사용했다.

## 검증

`python -B tools/build_exploration_crafting_v071.py --check`: 30,304개 검사 통과. 원본 제작 재료 관계 2,410개 일치, 상위 장비 참조 유효, 모든 재료 소비처 존재, 정제 순환 없음, 레이드 전용 인장 우회 불가, 6개 강화 구간의 1~12단계 일대일 대응을 확인했다.

명칭 키 비교: 기존 스킬 1,510개·장비 500개·직업별 테마 20개의 키를 보존했다. 표시명 변경은 스킬/별자리 1,244개·장비 500개, 몬스터 표시명 맵 6개다. 엔진 실행 검증·UI 캡처·운영 DB 통합은 이 정적 검증과 구분한다.
