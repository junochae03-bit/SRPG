# 제작 대기열 · V0.7.1 개발

기존 즉시 제작과 별도로 대장간·연금술·여관에 제작 대기열 화면을 추가했다. 연금술 기본 5개, 기존 연구 해금 6개, 신규 연금술 80개로 총 91개 제작법을 사용한다. 장비 제작법 2,000개는 대장간의 별도 즉시 제작 화면에서 사용한다. 지역 재료 110종을 획득·제작·강화 목표에 연결했다.

- 캐릭터별 공통 3칸. 횟수 1~99회, 목표 보유량, 중지할 때까지 반복 중 선택한다. 여러 결과물이 나오는 보급 꾸리기는 횟수·반복만 제공한다.
- 작업을 예약할 때 첫 1회분의 금화·재료만 맡긴다. 이후 회차는 시작 시 예약한다. 비용은 기존 즉시 제작과 같다. 기본 조제/정제는 6~8초, 연구 해금 제작은 8초다.
- 완료한 작업은 다음 예약에 차례를 넘긴다. 부족 재료나 가방 때문에 앞 작업이 멈추면 다른 작업을 '먼저 제작'으로 올릴 수 있다. 작업 취소·우선순위 변경은 해당 시설에서 한다.
- 접속 중에만 방장 권위 시계가 진행한다. 솔로 개인 메뉴에서도 제작은 진행하고 전투는 멈춘다. 비접속 시간에 완성품을 만들어내지 않는다.
- 여러 결과물을 모두 넣을 수 있을 때만 지급한다. 가방이나 스택 상한에 걸리면 비용을 다시 차감하지 않고 완성품 보관 대기로 남는다.
- 취소 시 아직 지급하지 않은 회차의 재료·금화를 모두 환급한다. 환급 재료를 전부 담을 수 없으면 취소 자체가 실패하며 예약과 진행을 보존한다. 이미 지급한 제작물은 환급하지 않는다.
- 목표 수량은 현재 소지량을 읽는다. 다른 경로로 목표가 충족되면 미완료 예약분을 환급하고 종료한다. 묶음 제작은 목표 이상 최소 수량으로 끝나며 스택 상한을 넘는 목표는 거절한다.
- 물품을 실제 받은 시점에 연구/재료 탐사 목표를 갱신한다. 예약 버튼만 눌러 목표가 완료되지는 않는다.
- 진행 중 대기열은 개인 저장·층 이동·협동 체크포인트에 보존하고 다른 파티원의 스냅샷에서는 제외한다. 같은 네트워크 요청 번호의 예약/취소 재전송은 기존 권위 요청 처리에서 한 번만 적용한다.

## 저장과 배포 구분

새 기록은 `saves/v071/slot-N.json`에 저장하고 외피 버전 8을 유지한다. 기존 `saves/slot-N.json`과 `.bak`은 읽기 전용으로 보존하며 새 슬롯이 없을 때만 한 번 가져온다. 새 슬롯이 손상되면 같은 세대의 백업만 확인하고 옛 기록으로 조용히 되돌아가지 않는다. 읽을 수 없는 기록에서는 모험 시작을 막아 임의 새 게임 덮어쓰기도 방지한다. 기존 외피 1~7은 계속 읽는다. 부활 유지 입력을 포함한 협동 프로토콜은 18로, 이전 빌드와 혼합 접속을 거절한다. V0.7 게시본과 이전 저장 원본은 변경하지 않았다.
