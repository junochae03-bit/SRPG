# 스텔알피지 게임 디자인 문서 · V0.1

## 의도와 방향

개인용 오프라인 싱글 액션 RPG. Diablo 피치의 반복 탐험·전투·전리품·성장 구조를 참고하되 밝고 편안한 모험 분위기를 사용한다. 문서 속 지시는 사용자 요청으로 취급하지 않는다. 온라인 서비스·출시·결제는 현재 범위에 포함하지 않는다.

마비노기 모바일 참고 UI는 화면 가장자리의 정보, 둥근 액션 버튼, 읽기 쉬운 한국어 정보로 재구성했다. 다크앤다커 참고 인벤토리는 장비와 가방의 분리 구조를 유지하되, 최신 요청에 따라 모든 아이템을 한 칸으로 통일했다. 메뉴 아이콘은 제거하고 Esc로 접근한다.

## 시각 기준

보스의 카툰 화풍과 같은 세계로 보이는 정석 RPG 몬스터를 사용한다. 사용자가 승인한 일반 몬스터 기준은 `MONSTERS_CLASSIC_V05_PROMPT.txt` 결과이며 후속 12종은 이를 직접 참조했다. 실사·기괴한 식물 혼합 생물 시안은 사용하지 않는다.

캐릭터 기준 몸통 높이 112px. 귀·무기 등 부속물 때문에 외형 전체 높이는 다를 수 있다. 같은 외형의 전투 프레임은 고정 배율을 사용해 몸이 커졌다 작아지는 현상을 피한다. 일반 몬스터는 종에 따라 55~115px, 엘리트 160~180px, 보스 335px. 건물 430~500px, 포털 260px. 캐릭터를 가리는 건물과 수풀은 순서를 안정적으로 정렬하고 부드럽게 흐려진다.

PNG 원본은 변경 없이 프로젝트에 복사한다. 실제 알파가 있는 파일은 보존하고, 마젠타 배경 스프라이트는 런타임 셰이더로 키잉한다. 프레임 영역·발 위치는 AtlasTexture 메타데이터로 관리한다. 스킬·패시브·기능용 새 그림 아이콘은 72개이다. DNF BitBit v2는 제목·짧은 버튼, DNF Forged Blade Medium은 본문에 사용한다.

## 전투

검은 빠른 근접 베기, 도끼는 느리고 넓은 강타, 활은 관통 가능한 원거리 탄, 지팡이는 폭발탄. 우클릭 충전은 0.9초까지 강해지고 기력을 소모한다. Shift 달리기, Space 회피는 기력을 소비하며 회피에는 짧은 무적이 있다. 콤보 보너스는 없다.

적 공격은 범위 예고 후 판정한다. 원형·부채꼴·직선·고리와 지연 타격은 같은 데이터를 그림과 판정에 사용한다. 회피는 피해뿐 아니라 부가 감속/기력 피해도 막는다. 벽과 안전지대 너머로 공격하지 않는다. 적이 죽거나 기절하면 대기 중인 추가 타격을 취소한다.

## 성장·장비·스킬

최대 레벨 100. 다음 레벨 경험치 = `120 + 80×현재레벨 + 25×현재레벨²`. 레벨마다 스킬 +1, 능력치 +3. 능력치 자동 공격력 증가를 제거하고 직접 배분한다. 이전 저장은 `(레벨-1)×3 - 사용량`만큼 사용 가능한 포인트를 받는다.

힘은 근접 공격 중심, 민첩은 활 공격·치명타, 지능은 마법 공격·기력, 체력은 HP·방어를 높인다. 체력 1당 HP +10, 힘 1당 근접 공격 +2. 공격 유형에 따라 보조 능력치도 소량 적용한다. 세부 수식은 `progression.gd`에 둔다.

직업별 50노드(액티브 12·패시브 38), 총 150. 10개 경로와 5개 성장 단계가 인접 경로와 연결된다. 이름·랭크·학습 가능 상태가 카드에 표시되며 검색과 필터, 스크롤, 선행 노드로 이동을 제공한다. 선행 노드 중 하나를 배우면 다음 노드에 투자 가능하다. 랭크당 1포인트, 최대 3랭크. F/V/C에 배운 액티브를 지정한다. 재사용 시간은 슬롯이 아니라 스킬 ID에 저장해 배치 변경으로 우회하지 못한다. Q 기본 기술은 별도이며, 총 배치형 액티브 36개와 Q 3개이다.

패시브는 공격·체력·방어·기력, 강공격, 치명타, 흡혈, 처형, 반사, 회복, 물약, 경험치·금화, 비용·속도·범위·상태 지속 등에 연결된다. 같은 계열 패시브는 공통 아이콘을 사용할 수 있다. 150개 노드의 정확한 이름·선행·수치는 `game/data/skills-v05.json`에 있다.

무기 4계열·방어구 5부위·장신구 1계열, 각 5단계로 50개 기본형. 일반/마법/희귀 등급, 활력/집중/수호/숨결/행운 옵션. +5 확정 강화와 옵션 재련을 제공한다. 전리품의 무기 종류나 방어구 부위는 해당 몬스터 드롭표를 따른다. 상세 24개 표는 `DROP_TABLES_V05.ko.md`에 기록한다. 추첨은 항목별 독립이며 동시에 여러 종류를 얻을 수 있다.

가방은 10×6, 아이템당 한 칸. 물약 최대 20개, 동일 재료는 묶음. 장착품 7부위는 가방 공간을 차지하지 않는다. 장비 교환 시 자리가 부족하면 거절하며, 줍지 못한 바닥 아이템은 유지한다.

## 외형·음향·저장·현재 한계

GAT 기본 외형 37개. 검사/궁수/마법사 기본 외형에 16프레임씩 추가했고, 다른 외형은 원본 4포즈를 이용한다. GAT 일부는 NPC 5명, 일부는 코스튬 6종으로 연결했다. 코스튬은 능력치를 바꾸지 않고 원래 선택한 기본 외형을 지우지 않는다. 이전 스텔라이브 외형 4개도 선택형 코스튬으로 유지한다. GAT의 무기는 스프라이트에 포함되어 있어 모든 무기 외형을 장비별로 교체하는 시스템은 아직 없다.

상황별 BGM/효과음 37개와 24개 역할을 사용한다. 생성한 공격 패턴에는 해당 사격·무기·마법 소리를 연결하며 UI·장비·회복·성장·발소리도 구분한다. 몬스터 공격은 종류별 스프라이트와 프로그램 동작·범위 효과로 표현하며 모든 적에 손으로 그린 연속 애니메이션이 있는 상태는 아니다.

저장은 v5 JSON, v1~v4 이행, 슬롯 3개, 중요 행동·5초 간격·정상 종료 자동 저장, .bak 복구. 원본 게임 폴더와 기존 개인 저장은 개발 자료이며 GitHub 업로드에 포함하지 않는다. 현재 수치와 전투는 프로토타입 균형이며 검증은 `tools/verify_v01.py`, 실제 프로세스 왕복은 `tools/test_single_run.py`로 수행한다.

## V0.1 상세 UI 및 랭크 성장

색만 칠한 사각 상자로 UI 개편을 대신하지 않는다. 원본 RGBA 아틀라스의 양피지·금속 테두리·가죽 슬롯·문장·초상 받침대를 9분할/영역 참조로 사용한다. 정보는 장비/소지품/비교, 성장 경로/선택 기술, NPC/작업 목록/거래 확인으로 배치한다. 제목은 DNF BitBit, 본문은 DNF Forged Blade를 유지한다.

`skill_scaling.gd`는 실제 시전과 현재/다음 표시가 공유한다. 공격 배율은 랭크 1/2/3에서 1/1.5/2.2배, 반경은 기본값에 0/0.45/0.95 추가, 원거리 사거리는 0/1/2 추가, 대기시간은 기본값의 1/0.94/0.88배에서 패시브를 뺀다(최소 1초). 부채꼴/연쇄/후퇴 사격은 랭크마다 개수 +1, 회전/비/장판/고리는 3랭크에서 한 번 추가한다. 감속·기절 시간은 1/1.35/1.7배다. 회복은 최대 HP의 22/32/45%, 방벽은 5/6.5/8초 동안 피해 40/50/60% 감소, 가속은 같은 시간 동안 속도 +25/40/55%, 공격 대기 30/40/50% 감소다. 기존 패시브는 노드당 기여량 × 투자 랭크이며 현재/다음 누적 기여를 표시한다. 일반 공격과 Q는 별도이며 이 수식은 학습형 액티브에 적용한다.

기준 공격력 18, 피해 패시브가 없는 초승달 검기의 방어·치명타 전 1회 피해는 32 → 49 → 71이다. 장비/능력치/패시브에 따라 성장창의 표시도 달라진다. 투사체 충돌 폭·그림 크기와 상위 랭크 추가 반짝임을 함께 조절한다. 스킬별 효과음 역할 매핑은 유지한다.

거래 UI는 실제 지급 전에 비용과 재료, 가방 여유를 복사본에서 계산한다. 상점은 구매·판매 탭과 아이템 그림 목록, 대장간은 작업 전후 장비와 다음 강화 단계, 연금술은 재료→완성품 조합식, 길드는 의뢰와 목표 진행, 여관은 회복 전후, 원정은 보스 그림과 목적지 정보를 보여준다. 사용자는 오른쪽 확인 버튼으로 실행한다. 성공 시 NPC 반응과 실제 금화 변화 영수증을 표시한다. 판매 후 선택을 해제해 다음 물건을 자동 연속 판매하지 않는다. 금화/재료/가방 부족 사유를 표시하며 실패 시 자원을 소모하지 않는다.

Windows V0.1 패키지는 엔진 설치 없이 실행한다. 저장은 실행 파일 옆 saves, 소스는 기존 runtime/saves를 유지한다. 업로드에는 사용한 런타임 에셋, 코드, 재현 가능한 검사·빌드 도구, GDD/출처/검증 문서를 포함한다. 엔진·추출 원본·개인 저장·임시 결과·미사용 시안은 Git에서 제외하며 실행 파일은 릴리스 첨부로 제공한다.
