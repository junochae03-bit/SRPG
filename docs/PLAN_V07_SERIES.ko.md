# V0.7 계열 통합·배포 순서

2026-09-13. 사용자는 프로젝트 내 누락을 확인하고 개발 판단에 따라 V0.7을 빌드·게시한 뒤 남은 작업을 V0.7.1, V0.7.2로 순차 진행하도록 승인했다. 이 문서는 버전별 작업 대장이다. **3차 전직과 전용 궁극기의 게임 적용은 보류한다.** 별도 작업의 설계·샘플·수학 모델은 실제 구현 완료로 집계하지 않는다.

## V0.7 — 현재 플레이 기반 통합

상태: V0.7 배포 대상 전체 소스 612,770항목 및 실제 Windows EXE 검사 통과. 배포 파일과 검증 기록을 준비했다. 게시 결과는 GitHub V0.7 릴리스와 태그를 기준으로 확인한다.

- 기존 기본·2차 직업 20종에 위력·활력·견고·신속·정밀·특화와 직업별 특화 효과를 연결한다. 이전 투자점은 한 번 반환하고 재산·레벨·스킬·진행을 보존한다.
- 캐릭터 기술 원화 19장 중 실제 기술에 쓰이는 236자세, 플레이어 코스튬 30종의 승인된 87자세, 기존 몬스터 48외형의 192자세, 스킬 효과 108프레임, 탐사 물체 24상태를 적용한다. 준비된 모든 포즈를 적용했다고 쓰지 않는다.
- 원화 경계색·발 위치·이동/공격 방향·지원 몬스터의 회복 자세·글자 및 아이콘 정합성을 수정한다. 준비된 렌더 캐시 110장과 실제 DB 등록을 함께 배포한다.
- 자연동굴의 시야, 물리적 분기 단서, 유용한 전진 지름길, 사건·위험 선택, 연구·길드, 적 역할·방어 공략 등 V0.6 이후 기능을 포함한다. 자세한 완료 범위는 BENCHMARK_COMPLETION.ko.md를 따른다.
- 마지막 생존자가 강제 이탈할 때 첫 참여자 제거 스냅샷부터 보스를 초기화한다. 다른 생존자가 남았으면 유지한다. 실제 6프로세스 두 경우와 이전 프로토콜 거절을 확인했다.

완료 기준: 현재 런타임 해시의 전체 소스 gate, 실제 EXE 이동·전투·메뉴·저장·원화 표시 검사, 깨진 한글 및 미사용 원본 제외 확인, Windows ZIP·DB ZIP·SHA256 게시, 커밋·main 병합·푸시, QA팀과 DB 관리의 동일 커밋/검증 기록 인계.

확인한 명령: `tools/verify_v01.py`, `tools/build_v01.py --version V0.7`, `tools/test_export_v01.py --version V0.7`, `tools/package_v01.py --version V0.7`, `tools/package_database.py --version V0.7`. Python과 GODOT_EXE는 현재 작업 환경의 실제 실행 경로를 사용한다.

## V0.7.1 — 획득·제작·보관의 연결

상태: 전체 소스 679,022항목/187개 그룹과 실제 Windows EXE 검증을 통과하고 배포 패키지를 준비했다. 이번 확정 범위는 `RELEASE_V071.ko.md`와 `INTEGRATION_V071.ko.md`, 검증 근거는 `VERIFICATION_V071.ko.md`를 따른다. 아래 항목은 최초 계획으로, 완료를 뜻하지 않는다. 원화 승인 29종·지역 재료110종·장비제작2,000개·연금술80개·제작대기열·특수옵션8종·부활후유증을 연결했다. 보관/분할·자동 소모품·마모/수리와 확률 강화의 미확정 정책, 나머지 특수옵션10종은 V0.7.2 이후에 이어간다.

1. 신규 일반 몬스터 설계 40종과 준비된 원화 20종을 실제 공격·생태권 편성·개별 드롭에 연결한다. 미완성 외형은 임의로 대체 완료 처리하지 않는다. 기존 무리의 일부를 교체하며 몬스터와 장식의 총밀도를 무작정 늘리지 않는다.
2. 탐사 재료 60종·획득표·제작법을 실제 획득, 부족 재료 목표, 비용/결과 미리보기, 소지 한도, 원자적 소비·생성에 연결한다. 기존 장비 2,500정의와 설계 제작 대상의 관계를 유지하며 중복 장비와 이중 드롭을 만들지 않는다.
3. 제작 큐·반복(O02), 목표 수량(O01) 연결, 거래 보호(G08/U07), 재련 유지 옵션, 장비 마모·수리(O09)를 이어 구현한다. 재료 예약·취소 반환·저장 복원과 중복 요청을 같은 계약으로 검증한다.
4. 개인 창고·필터·정책 복사(O04), 수량/절반 분할(U06), 개인 자동 소모품 정책(O03)을 구현한다. 각자의 소유권·가방 공간·동시 요청·퇴장 저장을 확인한다.
5. 시설 성장 외형/대사(G09), 의뢰 결과의 지역 위험/상점 변화(SQ03), 기존 연구·길드·첫 제작 안내의 새 재료 연결을 보완한다.

입력: `docs/design/normal_monster_expansion/`, `exploration_crafting/`, `monster_ecology/`, `character_stats_v2/`의 정본과 해당 에이전트 원화 인계. 크기 등급 92건은 원화 몸체·바닥 기준·피격 범위를 함께 확인한 뒤 반영한다.

사전 대조 완료: 신규 몬스터 40 ID와 운영 몬스터 ID의 충돌 0, 제작 대상 500개의 기존 장비 참조 누락 0, 재료 2,410행의 참조 누락 0. 종 전용 드롭은 신규 재료 외에 기존 seed/ore도 사용한다. 이 결과는 DB 참조 준비 상태이며 획득·제작 구현 완료가 아니다.

미확정 정책: 일반 +3·레전드리 +12와 강화 성공/실패 규칙 외의 중간 등급 상한, 비용, 성장 곡선, 기존 일반 +4 이상 이관은 사용자 판단이 남아 있다. 이 항목과 장비 특수 스탯 18종의 활성 풀은 확정 전 보류하고 독립 작업을 진행한다.

완료 기준: 실제 탐사→신규 드롭→보관→제작/수리→장착 경로, 같은 요청 재전송 시 중복 지급 없음, 가방 가득 참/연결 종료 시 재산 보존, 이전 저장 이관, UI 비교와 한글 표시, 해당 DB 갱신·QA 인수·패치 빌드 확인.

## V0.7.2 — 탐사 압박·정보·협동 안정성

상태: 계획. 지속 원정의 저장 및 소유권 정책을 먼저 정하고 화면 연출을 연결한다.

1. 원정 재접속, 일부 귀환/잔류(E04), 영속 개인 원정 기록과 다음 행동(E10), 위치 선택·이동 거점(E06/SS01)을 연결한다. 기존 발견·단서·사건·개인 보상·파티 조건의 재접속 보존도 함께 검증한다.
2. 전투 난도와 파밍 부담의 독립 설정(O07), 기력과 별개인 보급·체류 압박(O08)을 추가한다. 넓이만 늘리거나 설명문으로 길 선택을 대신하지 않고, 경험으로 읽는 위험과 보상을 유지한다.
3. 학습/사용 조건과 실패 사유(G07/U03), 고정·연결 툴팁(U01), 장비·스킬·버프 기여분(U02), 해결 화면 연결 알림(U04), 최초 도움말 반복 억제(U05), 저장 호환/실패/손실 안내(U11)를 정리한다.
4. UI·툴팁 독립 배율(U09), 환경음·UI 음량 분리와 비활성 음소거(U10)를 구현한다. 작은 화면·긴 한국어·큰 배율에서 가림과 입력 영역을 확인한다.
5. 실제 보스 사건에 연결할 수 있는 추가 효과 5개를 우선 반영한다. 구조 유지 입력·후유증·마을 치료는 `REVIVAL_AFTEREFFECTS.ko.md`를 따른다. 보스 격노·무력화·승리 원화는 확정 후 연결한다. 첫 조우 A+C/재조우 A를 적용하며, 거대한 생물을 더 큰 보스가 지나가는 연출은 가장 큰 보스 한 번만 사용한다. 보스 ID와 원화 선택 전에는 임의로 확정하지 않는다.
6. 다인 역할·도발·위치/장판 공략(C02/C04/C08/SC06/SE02), 개인 조건부 효과(C09), 예고 가독성(C06), 지연·손실·중도 이탈·외부 회선 장시간 검증을 마무리한다. 로컬 프로세스 통과를 외부 회선 실전 인수로 보고하지 않는다.

완료 기준: 원정 이탈→복귀 시 소유권/진행 보존, 잔류자 전투 지속, 마을 치료 및 저장 복원, 배율별 UI·오디오 검증, 통제된 지연/손실 테스트와 확보 가능한 실제 외부 플레이 기록. 외부 참여자가 필요한 검증은 미확인으로 별도 기록한다.

## 누락 대조와 변경 통제

- QA 원본 21개는 `QA_FEEDBACK_21.ko.md`의 이전 배포 기록과 현재 검사를 대조한다. 이번 6스탯 이후 인벤토리 수치는 20항목, 실제 스킬 지도는 통합 3계열이다. 과거 기록의 17항목·5계열은 당시 스냅샷이다.
- Dungeon Settlers 46개와 Stoneshard 추가 선택 14개는 중복되므로 60개로 합산하지 않는다. `BENCHMARK_COMPLETION.ko.md`의 모든 미완료·부분 항목을 위 후속 단계에 배정하며, 이미 구현된 항목의 외부 플레이/장기 경제 확인도 남은 검증으로 유지한다.
- QA팀·DB 관리·캐릭터 스프라이트·배경,몬스터 스프라이트·스킬 이펙트·시스템 관리·그래픽 디자인 작업을 대조했다. 동결 뒤 새 인계는 해당 버전에 별도 추가하고 통과한 런타임 파일을 검증 중 수정하지 않는다.
- 각 패치는 자신의 ZIP과 해시를 가지며 이전 배포를 덮어쓰지 않는다. 이행 전 저장 백업을 유지한다. 새 저장을 구 버전에 억지로 되돌리는 대신 이행 전 백업으로 복구한다.
- 각 단계는 검증 가능한 기능 단위로 실행하며, 이 계획의 배정만으로 구현 완료 처리하지 않는다. 정책 보류·원화 선택·외부 검증은 자동 승인 질문을 만들지 않고 명확히 남긴다.
