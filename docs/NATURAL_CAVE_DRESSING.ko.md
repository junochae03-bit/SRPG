# 자연동굴 장식 정리

2026-09-13. 반복 구조물을 줄이고 바위·광물·오래된 몬스터 유해로 던전 분위기를 구성한다. 이 변경은 배경 장식 범위이며 탐사·전투의 미완료 항목을 완료 처리하지 않는다.

## 배치

| 지역 | 일반 산포에 남긴 원화 |
|---|---|
| 수정 동굴 | 석순, 광석 바위, 동굴 버섯 |
| 침수 유적 | 낮은 돌 잔해 |
| 용암굴 | 불씨 결정, 용암 바위 |
| 기계 구역 | 부서진 기어 잔해 |
| 별무리 구역 | 광물 정동, 석영 바위 |
| 심층 핵 | 핵 파편 |

문틀·수레·기둥·작업대·장식 화로 등을 일반 산포에서 제외했다. 제외한 자리를 다른 장식으로 채우지 않는다. 보상 상자·휴식 장소 등 실제 상호작용하는 장소는 별도 기능 배치를 유지한다. 기존 원화 108종은 관리 DB에 사용 여부를 구분해 보존한다.

해골, 갈비뼈, 말라붙은 동굴 도마뱀, 부서진 딱정벌레 껍질의 네 가지 지면 스프라이트를 추가했다. 일반층당 최대 5개, 방당 최대 1개이며 서로 8칸 이상 떨어진다. 방 가장자리 중 상하좌우 1칸이 통행 가능한 곳에만 놓는다. 통로에 충돌을 추가하지 않는다.

입구·출구와 8칸, 기능 장소·비밀방 입구·지름길 끝점과 5칸, 의미가 있는 탐사 흔적과 4.5칸 이상 떨어뜨린다. 실제 처치 시체나 전리품과 연결하지 않으며 이름·체력바·상호작용 표시는 붙이지 않는다. 마을·튜토리얼·레이드 전장에는 추가하지 않는다.

## 성능과 안정성

맵 최초 생성 시 결과를 저장한다. 비밀 통로를 열어 지형과 렌더러가 갱신되더라도 유해가 다른 곳으로 재배치되지 않는다. 같은 시드의 재접속 맵도 초기 배치를 재현한다. 프레임마다 최대 5개에 대해 현재 시야와 화면 범위를 검사하며 텍스처는 캐시한다. 전체 맵 재탐색이나 추가 충돌 처리는 없다.

## 원화와 DB

- 최종 PNG: `game/assets/cave_remains_v06/remains.png`
- 영역·표시 이름: `game/assets/cave_remains_v06/catalog.json`
- 생성 도구·정확한 프롬프트·원본 해시: `game/assets/cave_remains_v06/PROVENANCE.json`
- 관리 DB: `art:cave_remains:*` 4개와 실제 소비 경로, `metadata.cave_remains`, `metadata.cave_remains_source_rules`

PNG는 image_gen 생성 RGBA 원본을 그대로 복사했다. 픽셀 후처리 없이 AtlasTexture 영역으로 읽는다. 신규 원화 1장으로 네 종류를 공유한다. 별도 팀의 능력치·제작·몬스터 설계 DB는 이 작업에 섞지 않는다.

## 확인

집중 검사에서 200개 맵(일반층 180개·보스층 20개)을 확인했다. 일반층 180개 모두에 최종 크기 기준 총 772개가 배치됐으며 최대 개수, 통행, 이격, 결정성, 비밀 통로 개방 후 유지, 안개 속 비표시를 통과했다. 실제 1920×1080 화면은 `artifacts/cave-remains-B12.png`, `cave-remains-B42.png`, `cave-remains-B62.png`에 있다. 캡처는 생성된 맵의 유해가 덜 가려지는 위치로 카메라를 옮긴 정적 장면이며 장시간 플레이 성능 측정은 아니다.

QA팀의 코드 검토에서 산포 풀 누락, 비밀 통로 이격, 통로 개방 시 재배치 문제가 지적되어 수정했다. 최종 전체 검사와 인계 근거는 `docs/qa/natural-cave-dressing-verification.json`에 기록한다.

초기 크기 버전 `cd8e780`의 필수 검사 152개 그룹 / 500,729개 확인을 모두 통과했다. 기존 적용 원화 수의 고정 기대값을 수정한 뒤 실패 지점부터 이어 실행했으므로, 두 실행의 결과를 합친 기록이다. 런타임은 두 실행 사이에 변경하지 않았다. QA 화면 읽기 검토와 DB 관리 정본 인수를 완료했다. 유해 자체의 안개 경계 통과 화면과 장시간 혼전 가독성은 별도 미확인으로 남긴다.

이후 사용자 크기 피드백으로 유해·흔적을 종류별로 확대하고, 육중한 몬스터의 일반/정예 비율과 플레이어 가림을 보완했다. 최종 수치와 후속 검사 범위는 [크기·가림 보완](SCENE_SCALE.ko.md)을 기준으로 한다.
