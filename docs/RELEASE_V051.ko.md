# 스텔알피지 V0.5.1 · 조작과 화면 개선

이번 버전은 화면 가독성, 키 설정, 외형 상점과 첫 표시 때의 처리 부담을 다듬은 오프라인 싱글 플레이 빌드입니다.

- **UI 테두리와 글자**: 종이 질감은 유지하면서 큰 금색 모서리를 얇게 줄였습니다. 버튼·선택 목록의 안쪽 여백을 확보하고 긴 이름과 단축키의 줄바꿈·표시 폭을 조정했습니다. 초상화의 모자·머리가 잘리는 부분과 외형 미리보기의 이름 겹침을 보완했습니다.
- **실제 키 설정**: ESC 또는 시작 화면의 키 설정에서 동작을 선택해 키를 누르거나, 동작을 키보드 그림 위로 끌어 놓아 변경합니다. 같은 키를 지정하면 두 동작의 배치를 교환하며, 적용·취소·기본값을 제공합니다. ESC는 닫기로 고정됩니다. 변경한 키는 HUD에 반영하고, 이름 입력과 모달 화면에서는 전투 입력을 차단합니다.
- **시작과 모험 기록**: 기록 칸에 레벨과 닉네임을 표시하고 긴 이름은 나눠 읽을 수 있게 배치했습니다. 빈 기록은 모험 시작, 기존 기록은 이어서 하기로 구분합니다. 캐릭터의 직업·이름·초기 능력치 10점은 생성 화면에서 정합니다.
- **직업 기본 외형과 코스튬 상점**: 새 캐릭터는 직업 기본 모습과 입문 장비로 시작합니다. 마을 상인의 코스튬 탭에서 대체 기본 외형은 **500G**, 코스튬은 **1,200G**에 구입합니다. 구매와 착용은 별도 동작이며, 가방에서는 소유한 직업 호환 외형을 고릅니다. 상점 도입 전 기록의 착용 외형은 소유 목록으로 이관합니다.
- **외형 표시 이름**: 상점에서 기본 캐릭터·코스튬에 **1~24자** 표시 이름을 붙일 수 있습니다. 미구매 외형에도 이름을 저장할 수 있으며, 원화 ID와 직업별 착용 규칙은 유지합니다. 직업 변경 후 기본 외형 이름도 새 직업에 맞게 갱신합니다.
- **적 피격 판정과 배경 시야**: 몬스터의 피격 허용 범위를 넓혔습니다. 적의 이동 충돌과 공격 사거리는 유지합니다. 배경 장식의 배치 수는 약 **45%** 줄이고, 입구·출구·통행로의 여유 공간을 유지합니다. 장식 종류와 원본 그림은 보존합니다.
- **표시 처리 개선**: 코스튬·교정 이미지·장비의 **41개 시트**는 배경색 제거를 빌드 단계에서 처리한 RGBA 캐시로 읽습니다. 원본 그림과 프레임 영역은 유지하며, 도감은 메타데이터만 먼저 읽고 필요한 그림을 로딩합니다. 스킬 정보·배경 도형·미니맵의 반복 계산도 캐시합니다.

최소 클라이언트는 **StelRPG.exe**, **StelRPG.pck**, `licenses`의 필수 고지와 `saves`로 구성합니다. EXE와 PCK는 같은 폴더에 두며 Godot 설치는 필요 없습니다. 기존 저장을 옮길 때는 원본 바이트를 보존하고, 대상에 이미 파일이 있으면 덮어쓰지 않습니다. 키 배치와 외형 표시 이름은 모험 진행과 별도 파일로 저장합니다.

장비·몬스터·드랍·스킬·원화 관리용 **SQLite/JSON DB는 별도 자료**입니다. 그림의 원본 경로·영역·출처와 실제 RGBA 로딩 캐시의 경로·SHA256을 구분해 조회합니다. 파생 캐시 41개를 새 원화나 프레임으로 중복 집계하지 않습니다.
