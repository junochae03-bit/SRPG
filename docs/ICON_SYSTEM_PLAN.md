# 인게임 아이콘 확장 계획

기준: 최신 확인 main e01b80f. 격리 작업본 `publish/SRPG-icons`, 브랜치 `feature/semantic-icons`. 기존 진행 중인 V0.4/배경/코스튬/이전 publish 작업은 덮어쓰지 않는다.

목표: 사용자가 제공한 참고 이미지의 둥근 갈색 나무 버튼과 크림색 기호로 아이콘을 제작하고 게임에서 의미별로 연결한다. 텍스트/단축키/수치 설명은 가독성을 위해 함께 유지한다. 피해·성장·저장·거래 규칙 및 릴리스 배포는 범위 밖이다.

최종 스타일(사용자): "금속을 별로 안썼음", 첨부 이미지처럼. 둥근 나무 토큰, 단순하고 굵은 크림색 기호, 부드러운 음영, 약간 도톰한 하단 두께. 금속 테두리/보석/번쩍이는 반사광은 사용하지 않는다. 앞선 금테 후보는 폐기하고 전 시트를 이 기준으로 통일한다.

1. 완료 — 전 UI 누락/오용 조사, 7개 주제별 24칸 원화 시트(168종)와 semantic key 목록 확정. `docs/ICON_COVERAGE.md`에 매핑·미적용 범위를 남긴다. 검증: 카탈로그 키 유일성/PNG 크기/영역/투명도 및 모든 시트 육안 확인. 사람 검토 대기 없음.
2. 완료 — `icon_library.gd`, 아틀라스 JSON, `icon_art.gd`에 안전한 의미 기반 조회를 구현하고 스킬의 직업/모드/ID별 오매핑을 해결한다. 검증: `python tools/check_icons.py --import-only` 및 카탈로그/스킬 coverage 검사. 사람 검토 대기 없음.
3. 완료 — HUD/보스 무력화/직업 자원/상태이상/미니맵과 가방/거래/성장/도감/메뉴에 아이콘을 연결한다. 독립 파일별 병렬 작업 후 통합한다. 새 아이콘만 추가하고 기존 사용자 텍스트의 의미를 보존한다. 검증: `python tools/check_icons.py`. 사람 검토 대기 없음.
4. 완료 — 독립 아이콘 갤러리, UI 및 상태별 실제 렌더 캡처. 작은 크기·중첩·잠금/비활성·빈 상태·선택을 확인하고 조정한다. 검증: 같은 전용 검사 및 캡처 육안 확인. 사람 검토 대기 없음.
5. 완료 — `python tools/verify_v01.py` 전체 회귀, 카탈로그 출처/프롬프트/검증 기록/선택 병합 인계를 작성한다. 최종 결과 확인 후 완료 표시. 사람 검토 대기 없음.

실행은 GODOT_EXE를 RPG2/tools/godot/Godot_v4.6-stable_win64.exe로 지정하고, 로그와 검사 저장은 이 작업본 runtime 아래에 격리한다. 승격 검사는 루트가 수행하며 하위 에이전트는 승인 대기 도구를 호출하지 않는다.
