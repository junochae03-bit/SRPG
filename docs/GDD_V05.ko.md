# V0.5 · 별자리의 길과 모험의 시작

현재 빌드는 밝은 판타지 분위기의 싱글 플레이 던전 탐사 RPG다. [V0.2의 직업·장비·100층 던전](GDD_V02.ko.md), [V0.3의 도감·무력화](GDD_V03.ko.md)를 이어받는다. 이번 변경은 성장 선택의 의미와 가독성, 캐릭터 생성, NPC를 만나는 흐름과 준비된 코스튬·배경·몬스터·나무 아이콘의 게임 적용을 다룬다. 온라인 계정·파티·동기화는 후속 작업이다. 소스·원화 통합과 전체 검사·EXE 검증을 마쳤다.

기본 창은 1920×1080, 논리 화면은 1600×900이다. Godot의 `canvas_items` 확대를 사용하며 HUD와 창 UI는 보스 전투 카메라의 확대·축소에 영향을 받지 않는다. 아래 UI 크기는 논리 화면 기준이다.

## 선택으로 전투가 달라지는 성장

[Path of Exile 공식 소개](https://www.pathofexile.com/game)의 연결형 성장과 플레이 방식을 바꾸는 핵심 패시브를 참고한다. 스텔알피지에서는 기존 직업별 기술과 자원을 출발점으로 삼아, 기술 연결·공격 위치·대상 수·기력·재사용 시간 사이에서 선택하도록 구성한다. 시각 표현은 밝은 숲, 종이 지도, 장식 메달과 기존 카툰 분위기를 유지한다.

기존 610개 노드의 ID·최대 랭크·원기술 선행 규칙을 유지하고 직업마다 45개 별자리 특화를 추가한다. 원기술은 `skill_ranks`, 새 특화는 `constellation_allocations`로 분리한다. 900개 특화는 사거리·효율·조건부 보너스와 기존 공격의 행동 변환이며, 추가 액티브 900개를 의미하지 않는다.

| 구분 | 직업 수 | 직업당 원기술 | 직업당 특화 | 직업당 총 노드 |
|---|---:|---:|---:|---:|
| 기본 검사·궁수·마법사 | 3 | 50 | 45 | 95 |
| 기초 도적·격투가 | 2 | 5 | 45 | 50 |
| 계열별 전직 | 15 | 30 | 45 | 75 |
| 합계 | 20 | 610개 원기술 | 900개 특화 | 1,510개 |

직업별 특화는 5개 군집으로 구성한다. 각 군집에 기반 6개·주요 특성 2개·핵심 선택 1개를 배치한다. 기존 사용 기술에서 출발해 이웃 군집으로 연결하고, 일부 갈림길은 선행 중 하나를, 핵심은 두 주요 특성을 모두 요구한다. 도적·격투가를 포함한 모든 직업이 최소 50개의 선택 노드를 갖는다.

| 투자 대상 | 비용 | 제한 |
|---|---:|---|
| 원기술 | 랭크당 1 SP | 기존 해금 레벨·최대 랭크 유지 |
| 기반 | 1 SP | 1랭크, 사거리·반경·속도·효율·지원·무력화 등의 경로 |
| 주요 특성 | 3 SP | 1랭크, 적 상태·이전 행동·실제 적중 조건 |
| 핵심 선택 | 6 SP | 1랭크, 직업별 5개 중 최대 2개 |

레벨당 1 SP를 지급하고 최대 레벨 100에서 총 99 SP를 제공한다. 원기술과 특화가 같은 예산을 사용한다. 핵심 자체의 6 SP 외에 선행 경로 비용도 필요하다. 모든 원기술을 최대 랭크로 올리면서 모든 별자리를 완성할 수 없는 구조다.

## 조건·시너지·기회비용

주요 특성은 다른 기술의 실제 적중 후 연결, 회피 후 공격, 지원기 후 공격, 감속·속박된 적, 체력 30% 미만의 적 등을 조건으로 삼는다. 같은 기술의 반복만으로 다른 기술 연결 조건을 충족하지 않으며, 빗나간 공격은 실제 적중 조건을 만들지 않는다. 첫 적중 보상은 같은 시전의 다단 타격마다 중복 지급하지 않는다.

| 공통 핵심 | 행동 변화 | 기회비용 |
|---|---|---|
| 메아리 | 직접 피해 70% + 0.35초 뒤 같은 위치에 원시전 피해 40% 추가 타격 | 재사용 시간 +15%, 이동한 적은 추가 타격 회피 가능 |
| 단일 결의 | 시전당 한 대상, 피해 +25% | 기력 +25%, 여러 적 동시 공격 불가 |
| 회피의 탄력 | 실제 회피 후 3초 안의 다음 공격 피해 +25%, 시전 시간 절반 | 항상 공격기 기력 +10%, 조건 시간 밖에서는 강화 없음 |

계열별 두 핵심은 다음 전투 방식 중 하나를 고른다. 기본 직업과 해당 계열의 전직이 같은 특화 주제를 공유하고 고유 기술·자원은 유지한다.

| 계열 | 첫 번째 방향 | 두 번째 방향 |
|---|---|---|
| 검사 | 직접 피해를 줄이고 첫 적중에서 전방 파동, 기력 증가 | 지원기 뒤 직접 타격과 자기 위치 파동을 연결, 지원 위력 감소 |
| 궁수 | 직접 피해를 줄이고 새 표적 2명까지 연쇄, 단일 대상에서는 손해 | 첫 적중 위치에 지연 폭발, 재사용 시간 증가 |
| 마법사 | 직접 피해 일부를 지속 피해로 전환, 기력 감소 | 지원기 위치의 문장과 다음 공격 연결, 지원 위력 감소 |
| 도적 | 서로 다른 공격기로 낙인 생성·소비, 항상 공격 피해 감소 | 직접 피해 일부를 독으로 전환하고 이동기·회피로 잔여 독 회수, 기력 증가 |
| 격투가 | 이동 추적 3타로 분배하고 시전 시간 단축, 총 피해 감소 | 한 타격으로 압축하고 피해 증가, 반경 감소·준비 시간 증가 |

메아리와 단일 결의는 배타적이다. 계열별 두 핵심도 함께 선택할 수 없다. 궁수 계열의 단일 결의와 새 표적 연쇄도 함께 사용할 수 없다. 나머지 공통·계열 핵심은 최대 2개 제한 안에서 함께 적용된다.

소환·비공격·패링 준비 기술은 공격 전달 방식 변환 대상에서 제외한다. 지원 위력은 회복·보호막·강화·소환 수치에 적용한다. 지연 타격·지속 피해·연쇄는 원시전의 피해·무력화 배분을 사용하며 추가 타격이 다시 특화 추가 타격을 생성하지 않는다. 보스 무력화 총량을 타수만큼 복제하지 않는다.

## 별자리 지도와 회수

K에서 「스킬 지도 / 능력치 / 직업」을 선택한다. 연결 지도는 다섯 가지 중 하나를 기본으로 펼쳐 한 번에 읽을 노드를 줄인다. 기본 검사·궁수·마법사는 한 가지에 약 19개이며 직업에 따라 개수는 달라진다. 가지 선택과 「전체 지도」로 전체 관계를 한 번에 볼 수 있다. 드래그 이동·휠 확대, 선택 찾기, 이름·효과 검색, 사용 기술·배울 수 있음·성격 필터를 제공한다. 확대 수준에 따라 노드의 이름과 설명 밀도를 조절하고 선택 상세는 고정된 오른쪽 영역에서 읽는다.

기본 가지 화면의 스킬 기호는 최소 48px로 표시하며 전체 지도에서는 확대율에 따라 축소한다. 상세에는 해금 레벨·필요 선행·현재 랭크·비용을 표시한다. 원기술은 현재와 다음 랭크의 실제 프로필을 비교하고, 특화는 얻는 변화·선택의 대가·함께 쓰는 방식·적용 범위를 설명한다. 잠긴 노드는 SP·레벨·선행·배타 선택·핵심 수 제한 중 해당 이유를 보여 준다. 「경로 보기」는 선행 경로와 필요한 SP를 표시한다.

「선택 회수」는 한 랭크를 줄였을 때 선행 조건을 잃는 후속 노드와 정확한 반환 SP를 미리 보여 준다. 확정 시 후속 노드도 함께 회수하고 더 이상 배우지 않은 사용 기술을 슬롯에서 제거한다. 원기술·별자리 전체 초기화도 가능하다. 회수·스킬 초기화·직업 변경은 실제 햇살 마을에서만 허용하며 던전 입구에서는 허용하지 않는다.

환급 뒤에는 남은 시전·투사체·장판·소환·조건부 강화·본인의 지속 피해와 낙인을 정리한다. 이전 선택의 효과를 남겨 둔 채 SP만 되돌리는 상황을 막는다. 직업 변경의 장비 해제에 가방 공간이 부족하면 실제 직업·장비·투자 상태를 바꾸지 않는다.

## 타이틀과 캐릭터 생성

타이틀은 동화책의 숲과 나무 팻말, 게임 이름, 모험 기록 3개, 시작·종료로 구성한다. 닉네임 입력과 긴 조작 설명은 시작 화면에 상시 두지 않는다. 빈 기록은 생성 화면, 기존 기록은 이어 하기로 연결한다. 읽을 수 없는 기록은 덮어써서 새 캐릭터를 만들지 않는다.

생성 화면에서 검사·궁수·마법사·도적·격투가의 기본 5직업과 1~16자의 이름을 선택하고 5종 능력치에 초기 10점을 모두 배분한다. 기본 GAT 외형과 코스튬은 선택 직업의 무기·동작에 맞는 항목만 표시한다. 새 원화 중 플레이어 코스튬 30종은 직업별로 허용 범위가 다르며, NPC 전용 3종은 선택할 수 없다. 외형은 초상 목록과 큰 미리보기로 고르며, 직업 추천 배분과 초기화, 능력치 결과 미리보기를 제공한다. 이름의 제어 문자, 허용되지 않은 직업·외형·능력치, 음수·소수·비유한 값과 예산 불일치는 거부한다.

생성 취소나 잘못된 설정은 저장 파일을 만들지 않는다. 기존 슬롯과 연결 중인 세션에는 새 캐릭터를 생성할 수 없다. 저장에 성공한 후보 캐릭터만 현재 세션으로 확정한다. 생성 시 선택 직업의 일반 등급 무기·머리·상의·신발 4개를 지급하고 해당 장비 칸에 자동 장착한다. 가방의 입문 장비 수령 버튼과 수동 수령 안내는 제거한다. 새 캐릭터는 준비된 상태로 꽃바람 숲에서 시작해 적 5마리 처치 후 햇살 마을로 이동한다.

## 캐릭터·환경 원화 적용

추가 캐릭터 원화 33종은 플레이어 코스튬 30종과 마을 NPC 전용 3종으로 나눠 연결한다. 공통 reader는 각 원화의 이동 4·일반 공격 4·강공격 4·회피 2·피격 1·대기 1, 전체 528프레임을 읽는다. 이 수량에는 NPC 전용 원화의 포즈도 포함하며 모든 프레임을 NPC 행동에 재생한다는 뜻은 아니다. 원본 33시트를 보존하고 민트 여름복·은기사의 겹친 일반 공격 6·7번만 별도 교정 스트립 2장의 영역으로 교체한다. 교체 프레임을 추가 프레임으로 중복 계산하지 않는다. 발 기준점과 자세별 몸체 높이로 캐릭터의 보이는 크기를 맞추고, 파랑·마젠타 배경은 런타임 메모리에서 제거한다. 무기 원화가 코스튬에 포함된 경우 장비 교체가 그 그림을 바꾸지는 않는다.

추가 GAT 외형 24개도 보이는 무기·동작을 검토했다. 새 원화 33개와 합친 57개 검토 규칙을 런타임 외형 허용 목록으로 변환한다. 허용 직업이 없는 외형은 플레이어 선택 목록에 넣지 않는다. 생성 화면·가방뿐 아니라 실제 외형 변경 명령도 동일한 규칙으로 검사한다. 직업 변경 시 호환되지 않는 기본 외형·코스튬은 기본 모습으로 되돌리며 이름·재산·진행 기록은 보존한다.

기본 생태계·던전 확장·레이드·판타지 확장 4개 팩에서 사용 PNG 30장을 연결했다. 배경 장식은 기존 72개와 판타지 확장 36개, 총 108개이며 튜토리얼·마을·10개 생태계의 실제 배치에서 사용한다. 층별 테마가 바닥 보행 마스크 밖의 원화를 선택하며, 출발점 6칸·출구 4칸과 보행 가능 칸 주변 5×5 영역은 비운다. 장식의 큰 그림이 입구와 첫 이동 경로를 가리지 않도록 배치 여유를 두고, 장식 크기를 새로운 충돌체로 사용하지 않는다.

침수·포자·용암·기계·성운·핵심의 6개 생태계에 일반 몬스터 외형 18종과 레이드 외형 6종을 연결한다. 각 종은 대기·공격 키 포즈 2장으로 전체 48프레임이다. 숲·동굴·설원·가을의 4개 생태계는 기존 몬스터 외형을 유지한다. 새 외형은 기존 몬스터 ID·공격·수치·드랍을 그대로 사용하고, 층별 표시명과 도감의 외형 대응을 갱신한다. 키 포즈 전환과 이동·회전 연출을 완전한 보행 프레임 애니메이션으로 설명하지 않는다. [자산과 인계 기준](ASSET_SOURCES.md)

## NPC와 HUD

NPC 가까이에서 E를 누르면 초상·이름·인사가 있는 대화가 열린다. 「마을 이야기」로 짧은 배경 설명을 읽거나 「장비를 맡긴다 / 물건을 살펴본다 / 조합을 부탁한다 / 의뢰를 확인한다 / 쉬어 간다」로 기존 서비스를 연다. 새 NPC 전용 원화 3종은 기계도시 사절·유적 탐사원·유랑 사수로 마을에 배치한다. 대화와 시설 이용 중 전투를 일시 정지한다. 닫기와 다른 화면 전환 시 대화가 겹쳐 남지 않게 처리한다.

HUD의 기본 공격·강공격·회피 버튼은 숨긴 채 입력을 유지한다. 액티브는 위 Q/F/V와 아래 C/Z/X의 96px 스킬 버튼 여섯 개로 배치하고 상시 조작 설명·저장 안내를 덜어낸다. 성장·가방·도감·대화·시설·메뉴 화면은 전투를 일시 정지한다.

가방은 장비·보관 칸·상세의 세 영역으로 넓히고, 60개 보관 칸을 64px로 표시한다. 아이템마다 한 칸을 사용하며 원화 소켓·등급 테두리·장착 배지를 유지한다. 수량과 실제 강화 단계를 표시하고 끌어서 배치하거나 더블클릭으로 장착·물약 사용이 가능하다. 24px 아이템명과 장비 비교·추가 옵션은 상세 스크롤 영역에 두며 장착·사용 버튼은 아래에 고정한다. 현재 기본 외형과 코스튬 착용 여부를 구분하고, 직업별 외형 팝업은 최대 높이 440px와 스크롤을 사용한다. 금속·금색 프레임 안쪽의 여백을 확보해 제목·버튼·팝업 첫 행이 장식에 가리지 않도록 한다.

UI용으로 둥근 갈색 나무 바탕과 크림색 기호의 168개 아이콘을 수록한다. 152개는 현재 기능에 연결하고 16개는 DB에 준비 영역으로 보관한다. 7시트의 명시된 영역을 읽어 기능·가방·전투·상태·직업·모험·능력을 구분한다. 선택한 원기술·장비 칸·상태에 대응하는 의미 키를 사용하며 상태 표시는 실제 남은 효과만 보여 준다. 원화의 크로마 배경은 표시 단계에서 제거한다. 관련 기준은 아이콘 작업 커밋 `9f56910`과 `semantic_catalog.json`이다.

## 저장과 데이터 기준

새 바닥 팩의 숲·석조 던전·사막·얼음·용암·천공 6재료를 생태계별 바닥과 길에 대응시킨다. 원본 PNG의 재료 영역을 월드 좌표에 고정해 카메라 이동 시 미끄러짐을 막고, 반복 경계가 이어지도록 샘플링한다. 기존 방·통로·입구의 보행 마스크와 충돌 규칙은 유지한다. 원본 팩의 벽과 문 TileSet은 이 바닥 적용 범위에 포함하지 않는다.

관리용 SQLite/JSON에 자산 파일·영역·프레임·출처·사용처 관계를 추가한다. 장비·몬스터·캐릭터·배경·타일·아이콘·효과의 실제 런타임 연결만 등록하고 원본 및 배포 파일 SHA256으로 변경을 추적한다. 게임 도감의 장비·드랍·스킬 데이터는 기존 구조를 유지한다.

완료 장비 팩 `be30d7b`의 6개 PNG와 115개 영역을 장비 조회에 연결한다. 직업별 무기 60개, 5계열 방어구 50개, 장신구 5개를 기존 2,500개 장비 정의의 직업·계열·부위·단계에 대응시킨다. 장비 수치·등급·착용 제한·저장은 변경하지 않는다. 미지원 이전 무기 종류에는 기존 그림을 유지한다. 미완성 후속 테마 시트는 이 팩에 포함하지 않는다.

저장 형식 v7은 `skill_build_version=2`, `constellation_allocations`, `creation_points`를 추가한다. 새 생성 캐릭터의 `creation_points`는 10, 기존 캐릭터는 0이다. 기존 저장 v6의 원기술 랭크·배치·능력치·재산·이름·층 진행을 유지하며 강제 스킬 환급은 하지 않는다. v7은 직업·노드 ID·랭크·해금 레벨·선행·공유 SP·배타 선택·핵심 수를 검사한다.

저장 v1~v5의 능력치 환급·장비 변환·던전 초기 진입은 이전 버전부터 있던 마이그레이션 경로다. v6 사용자의 능력치와 던전 기록을 그 규칙으로 다시 초기화하지 않는다. 구버전 파일에 새 필드를 넣어도 생성 포인트나 별자리 투자를 인정하지 않는다.

실행 중 도감과 JSON·SQLite는 같은 카탈로그를 읽는다. `skills`의 원기술 610개와 `constellations`의 특화 900개를 분리하고 `build_nodes`와 연결 관계로 함께 조회한다. 기준 수치는 장비·별자리 없는 참조 캐릭터임을 밝히며, 조건부 효과를 항상 적용된 피해로 표시하지 않는다. [DB 구조·재생성·조회 예제](GAME_DATABASE.ko.md)

## 검증 범위와 기록

선행 경로·SP 예산·배타 선택·회수·기존 랭크 보존, 선택에 따른 실제 시전·타격·지속 피해·무력화 예산, 캐릭터 생성 거부와 저장 실패의 상태 보존, DB 대응, 화면의 탐색·문자 배치와 내보낸 실행 파일을 검사한다. 모델 검사는 정지 표적의 수치 증거이며 모든 실전 빌드의 균형을 보장하지 않는다.

내보낸 EXE의 원화 검사는 플레이어 코스튬 30종을 허용 직업의 저장 기록으로 복원해 실제 화면과 대기 프레임 제출 기록을 남기고, NPC 전용 3종은 마을 배치에서 확인했다. 전체 33종의 나머지 모션 프레임은 소스 reader 검사로 검증한다. 10개 생태계의 첫 전투방 캡처는 카메라만 옮기고 플레이어 위치·HP·전투 상태는 바꾸지 않는다. `art_usage`는 실제 그리기 이후의 코스튬·배경·몬스터 ID와 아이콘 해석·알 수 없는 요청을 기록한다. PNG에서는 9×9 이상의 단색 파랑·마젠타 잔여를 확인하며, 이 검사가 가장자리나 화풍의 육안 검토를 대신하지 않는다. 저장으로 복원한 100층 완료 기록과 소스에서 실제 100개 층을 진행한 검사는 별도 근거로 기록한다. 전체 검사와 EXE 검증 결과는 아래 검증 기록에 확정했다.

[V0.5 검증 기록](VERIFICATION_V05.json)에 전체 검사와 내보내기 결과를 기록했다. 실행·DB 패키지와 서버 배포 해시는 최종 배포 단계에서 기록하며 이 문서에는 미확정 통과 건수나 배포 완료 수치를 적지 않는다. 재현 명령은 [README](../README.md#검증과-재현)에 모은다.
