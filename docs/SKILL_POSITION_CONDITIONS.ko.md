# 스킬 위치 조건과 소모 표시

2026-09-13. C04의 기존 스킬 위치 판정과 대가 전달을 보완했다. 기술 구성이나 기존 계수·소모량은 바꾸지 않았다.

## 실제 판정

시전 시 획득한 적을 따라가는 장판·폭발·제어 지점 기술은 발동 때도 살아 있는 표적, 몬스터 몸체를 포함한 사거리, 벽까지 다시 확인한다. 그 사이 표적이 사라지거나 벽 뒤·사거리 밖으로 벗어나면 효과가 발생하지 않고 해당 플레이어에게 짧은 실패 사유를 보낸다. 표적 없이 조준한 빈 지면에 쓰는 기술은 그대로 허용한다.

같은 검사를 사슬·표적 순간이동에도 적용하지만, 현재 기본 정의는 즉시 발동하므로 지연 이탈 오류의 실전 재현 대상으로 세지 않는다. 실제 입력 재현은 시전 시간이 있는 원소술사 장판과 폭발에서 확인했다.

이미 시전을 시작했다면 취소·피격 중단·발동 실패에도 기력과 재사용 시간을 되돌려 주지 않는다. 처음부터 대상이 사거리 밖인 사슬은 입력을 거절하며 소모하지 않는다. 기존 소모 시점을 유지하고 경계를 검사했다.

정면 방어 버프의 피해 감소와 시전 중단 보호가 같은 정면 조건을 사용한다. 뒤에서 들어온 유효 피해는 방어 버프만으로 시전 중단을 막지 못한다. 보호막으로 피해를 완전히 흡수하거나 별도의 시전 저항이 발동하는 기존 예외는 유지한다.

## 표시

스킬 상세와 퀵슬롯 설명에 표적 추적 조건, 시전 중 이동 비율, 취소 시 소모 유지, 정면 방어 조건을 해당 기술에만 표시한다. 이동 비율은 실제 이동 처리와 같은 함수에서 읽는다. 기존 기본 20%, 저격수의 관련 패시브 랭크당 +4%p를 유지한다. 랭크를 올려도 변하지 않는 값은 같은 문장을 화살표 양쪽에 중복하지 않는다.

## 검증과 한계

집중 검사 83개 확인: 실제 기술 입력 후 직업 시전 스케줄러로 발동을 진행해 사거리 이탈·새로 가로막힌 벽·표적 사망·정상 표적·빈 지면을 검사했다. 몬스터 이동 AI와 플레이어 기력 재생은 이 비교에서 진행하지 않는다. 몸체 사거리 경계, 정면/후면 피격, 실제 취소 입력, 표시와 이동 계수의 일치도 확인한다.

화면 검사 12개 확인은 원소술사·저격수·탱커의 실제 1920×1080 스킬 상세 화면을 사용한다. 스크롤 영역의 가장자리에서 일부 이전 행이 잘려 보이는 것은 스크롤 뷰포트의 정상 동작이며, 조건 본문과 제목의 배치 확인과 구분한다.

관리 DB에는 `metadata.skill_conditions`와 네 소스 규칙을 등록했다. 협동 프로토콜은 14이며 이전 13의 접속을 거절한다. 개인 저장 형식은 변경하지 않았다.

전체 검사 163개 그룹 / 540,887개 확인을 한 실행에서 통과했다. 로컬 6개 독립 ENet 프로세스의 연결·이동·귀환·정원 및 이전 프로토콜 13 거절도 통과했다. 이는 외부 회선에서 표적 이탈 상황을 검증한 것은 아니다. DB 재생성 일치, 소스 374개 해시, SQLite 무결성·외래키와 조건 메타데이터 일치를 로컬에서 확인했다. 기록은 `docs/qa/skill-position-conditions-verification.json`이다. 이번 QA 전달은 자동 승인 검토에서 거절되어 팀 인수를 완료하지 못했다. 이전 단계의 QA 결과를 이번 변경의 인수로 재사용하지 않는다. DB 관리 전달과 main 병합·푸시도 기존 승인 검토 차단이 유지된다.

C04 전체의 직업별 위치 선택·자세 유지에 따른 실전 손익과 장시간 조합 밸런스는 계속 검증해야 한다. 이 수정만으로 해당 항목이나 전체 벤치마킹 목표를 완료 처리하지 않는다.
